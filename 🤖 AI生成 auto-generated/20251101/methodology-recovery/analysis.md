## Model
- **命名与结构约束**：恢复的所有文件需遵循三级目录架构与命名规范，必要时将旧稿迁移至 `专项方法论/` 下并重命名[[🟣 knowledge/05_方法论中心/RULES.md:47-88]]。
- **内容整合原则**：新版 README 宣称 7 大业务域整合，需要确认旧稿是否应并入新版合辑或保留为独立专项，以避免导航重复或缺口[[🟣 knowledge/05_方法论中心/README.md:31-92]][[🟣 knowledge/05_方法论中心/README.md:165-196]]。
- **互链依赖**：Memory-bank 与 Skills README 引用缺失文档（如 `🎯 claudecode-全局设计哲学`）作为 Phase 0 必读，恢复后需同步更新引用与索引，若暂时缺信息以 TODO 标注[[🛠️ 系统管理/memory-bank/README.md:11-75]]。
- **优先级假设**：全局导航文档优先恢复（直接影响 Phase 0），领域专题按“是否已有 20251028 新稿覆盖”决定是否合并；碎片库可先恢复为专题文件夹，后续由领域负责人筛选。

## Compare

| 策略 | 做法 | 优点 | 风险 | 引导动作 |
| --- | --- | --- | --- | --- |
| 方案 A：恢复为独立文档 | 将旧稿直接导入对应目录，按规范改名、补 frontmatter，并在 README 中挂载导航 | 最快恢复知识密度，保留原始细节 | 目录膨胀、重复内容；需手动对齐指标与指标口径 | 适用于全局导航、尚无新版替代的专题 |
| 方案 B：内容迁移至新合辑 | 将旧稿要点合并到现有 20251028 文档（附章节或附录），记录迁移来源 | 保持简洁目录，便于后续维护 | 迁移成本高，需逐段对照；存在遗漏风险 | 适用于已有新版框架的领域（如投资、深度研究合集） |
| 混合策略（推荐） | 全局文档采用方案 A，领域方法论按主题选择 A 或 B；无法立即判定的文档保持在 `专项方法论/`（status: archived）并添加 TODO 等待复核 | 平衡恢复速度与目录治理，保留追踪能力 | 需维护清单与 TODO，避免遗漏后续迁移 | Step 1 输出映射清单，后续步骤按清单执行 |
