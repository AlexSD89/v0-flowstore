## 📋 业务场景差异化识别方法论

### 🎯 场景分类原则

#### 层次1：业务模式识别
```python
# 伪代码：业务模式识别算法
def identify_business_model(answers):
    if has_shopping_center() and has_office_building():
        return "大型商业地产"
    elif has_residential_rental() and has_property_agency():
        return "个人住宅服务"
    elif has_mixed_operations():
        return "混合经营模式"
    else:
        return "需要进一步分析"
```

#### 层次2：子业务细分
```python
# 伪代码：子业务细分算法
def identify_sub_business(business_model, answers):
    if business_model == "大型商业地产":
        sub_businesses = [
            "购物中心商铺",
            "写字楼租赁",
            "专业市场",
            "产业园区"
        ]
    elif business_model == "个人住宅服务":
        sub_businesses = [
            "住宅租赁",
            "房产中介服务",
            "短租民宿",
            "物业管理"
        ]
    return filter_relevant_sub_businesses(sub_businesses, answers)
```

### 📊 业务权重计算模型

#### 权重分配公式
```
业务权重 = (业务收入占比 × 0.6) + (战略重要性 × 0.3) + (增长潜力 × 0.1)
```

#### 实际应用示例
```
示例1：商业地产为主
- 商业地产收入：80%，住宅收入：20%
- 商业权重：(0.8 × 0.6) + (0.7 × 0.3) + (0.6 × 0.1) = 0.71
- 住宅权重：(0.2 × 0.6) + (0.6 × 0.3) + (0.8 × 0.1) = 0.34

示例2：住宅服务为主
- 商业地产收入：30%，住宅收入：70%
- 商业权重：(0.3 × 0.6) + (0.8 × 0.3) + (0.7 × 0.1) = 0.43
- 住宅权重：(0.7 × 0.6) + (0.9 × 0.3) + (0.9 × 0.1) = 0.75
```

## 🔥 痛点量化分析方法论

### 🎯 痛点识别框架

#### 痛点分类矩阵
```
痛点类型 × 影响程度 × 紧急程度 = 痛点优先级分数
```

#### 痛点量化公式
```
痛点分数 = (业务影响 × 0.4) + (发生频率 × 0.3) + (解决成本 × 0.2) + (客户影响 × 0.1)
```
