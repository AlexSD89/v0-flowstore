## 🎯 项目定位与功能

### 核心概念
PokeLLMon是一个基于大语言模型(LLM)的宝可梦对战AI系统，结合了OpenAI GPT模型和宝可梦对战引擎。

### 主要功能特性
1. **AI对战系统**: 使用LLM进行宝可梦对战决策
2. **本地对战引擎**: 集成Pokémon Showdown本地服务器
3. **OpenAI API集成**: 利用GPT模型进行智能决策
4. **实时对战**: 支持与AI或其他玩家进行实时对战

## 🏗️ 技术架构分析

### 技术栈构成
```
Frontend/Interface: HTML + JavaScript (Pokémon Showdown)
Backend Logic: Python (3.8+)
AI/ML Engine: OpenAI GPT API
Local Server: Pokémon Showdown Node.js服务器
Configuration: YAML配置文件
```

### 项目结构
```
PokeLLMon/
├── src/
│   ├── client/           # 客户端逻辑
│   ├── config/           # 配置文件
│   ├── data/            # 数据处理

│   ├── finetune_ppo.py  # PPO微调算法
│   ├── infer_gpt.py     # GPT推理逻辑
│   └── concurrency.py   # 并发处理

```
