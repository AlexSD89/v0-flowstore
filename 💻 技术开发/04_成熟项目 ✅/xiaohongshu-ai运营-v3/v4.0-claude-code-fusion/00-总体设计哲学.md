### 🏛️ 四根核心支柱

#### 1. 证据账本 (Evidence Ledger)
**哲学基础：证据优先于直觉，先构建证据账本，再给出判断与承诺**

**核心原则**：
- **信息定义**：信息 = 事实 × 语境 × 意图
- **证据金字塔**：一方行为 > 受控实验 > 准实验 > 面板 > 二手资料
- **三角校验**：至少两类独立来源相互印证
- **可追溯性**：每个洞察保留出处、时间戳、置信度、时效期

**实现理念**：
```python
class EvidenceLedger:
    """证据账本系统 - 所有决策和洞察的可追溯来源"""
    
    def __init__(self):
        self.evidence_pyramid = EvidencePyramid()      # 证据等级体系
        self.triangulation_engine = TriangulationEngine()  # 三角校验引擎
        self.confidence_scorer = ConfidenceScorer()       # 置信度评分
        self.traceability_manager = TraceabilityManager() # 可追溯性管理
    
    async def record_evidence(self, claim, sources, context):
        """记录证据到账本"""
        evidence_strength = self.evidence_pyramid.evaluate(sources)
        triangulation_score = await self.triangulation_engine.validate(sources)
        confidence_level = self.confidence_scorer.calculate(claim, evidence_strength)
        
        evidence_entry = {
            'claim': claim,
            'sources': sources,
            'context': context,
            'strength': evidence_strength,
            'triangulation': triangulation_score,
            'confidence': confidence_level,
            'timestamp': datetime.now(),
            'expires_at': self.calculate_expiry(evidence_strength)
        }
        
        return await self.traceability_manager.record(evidence_entry)
```

#### 2. 自主等级系统 (Level of Autonomy, LOA)
**哲学基础：可逆优先于可控，人类掌管价值与风格，AI放大效率与洞察**

**五级自主等级**：
- **LOA0 建议**：纯建议性质，人类完全决策
- **LOA1 备选方案**：提供多个选项与理由
- **LOA2 低风险自动执行**：自带回滚/速率限制/灰度
- **LOA3 守护栏内自动执行**：带看门人报警与熔断
- **LOA4 人类专属**：公关回应、大额预算、价值立场

**决策矩阵**：
```python
class AutonomyLevelManager:
    """自主等级管理系统 - 智能决策边界控制"""
    
    def __init__(self):
        self.impact_assessor = ImpactAssessor()        # 影响评估
        self.reversibility_analyzer = ReversibilityAnalyzer() # 可逆性分析
        self.risk_calculator = RiskCalculator()        # 风险计算
        self.context_analyzer = ContextAnalyzer()      # 上下文分析
    
    def determine_loa(self, decision_type, context, constraints):
        """确定决策的自主等级"""
        
        # 影响评估：业务影响、财务影响、声誉影响
        impact_score = self.impact_assessor.calculate(decision_type, context)
        
        # 可逆性分析：可回滚程度、修正成本、时间成本
        reversibility_score = self.reversibility_analyzer.analyze(decision_type)
        
        # 风险计算：失败概率、损失程度、影响范围
        risk_score = self.risk_calculator.assess(decision_type, context)
        
        # 上下文稳定性：环境变化频率、数据质量、模型可靠性
        context_stability = self.context_analyzer.evaluate(context)
        
        # LOA决策矩阵
        if impact_score >= 0.8 or risk_score >= 0.9:
            return 'LOA4'  # 人类专属
            
        elif impact_score >= 0.6 or risk_score >= 0.7:
            return 'LOA3'  # 守护栏内自动执行
            
        elif impact_score >= 0.4 or risk_score >= 0.5:
            return 'LOA2'  # 低风险自动执行
            
        elif reversibility_score >= 0.7:
            return 'LOA1'  # 备选方案
            
        else:
            return 'LOA0'  # 纯建议
```

#### 3. 评测优先体系 (Evaluation-First)
**哲学基础：永续学习，一切输出沉淀为可检索、可复用、可评测的资产**

**评测原则**：
- **黄金样本集**：建立高质量的标准评测集
- **任务级评测**：针对不同任务类型的专项评测
- **质量评分**：多维度的质量评估体系
- **持续改进**：基于评测结果的持续优化

**评测框架**：
```python
class EvaluationFirstSystem:
    """评测优先系统 - 所有AI输出必须经过严格评测"""
    
    def __init__(self):
        self.golden_set_manager = GoldenSetManager()      # 黄金样本集
        self.task_evaluator = TaskEvaluator()              # 任务评测器
        self.quality_scorer = QualityScorer()              # 质量评分器
        self.performance_tracker = PerformanceTracker()    # 性能追踪器
    
    async def evaluate_output(self, output, task_type, context):
        """评测AI输出质量"""
        
        # 黄金样本对比
        golden_comparison = await self.golden_set_manager.compare(
            output, task_type, context
        )
        
        # 任务特定评测
        task_scores = await self.task_evaluator.evaluate(
            output, task_type, context
        )
        
        # 综合质量评分
        quality_score = await self.quality_scorer.calculate_composite(
            golden_comparison, task_scores
        )
        
        # 性能追踪
        await self.performance_tracker.record_performance(
            output, quality_score, task_type
        )
        
        return {
            'quality_score': quality_score,
            'golden_comparison': golden_comparison,
            'task_scores': task_scores,
            'approval_status': self.determine_approval_status(quality_score),
            'improvement_suggestions': await self.generate_improvement_suggestions(
                quality_score, task_scores
            )
        }
```

#### 4. 资产化沉淀 (Asset Capitalization)
**哲学基础：一切输出沉淀为可检索、可复用、可评测的资产**

**资产类型**：
- **知识资产**：洞察、模式、策略、方法论
- **内容资产**：成功案例、失败案例、最佳实践
- **模型资产**：训练好的模型、提示词模板、算法
- **流程资产**：工作流模板、自动化脚本、检查清单

**资产管理系统**：
```python
class AssetCapitalizationSystem:
    """资产化沉淀系统 - 知识和经验的持续积累"""
    
    def __init__(self):
        self.knowledge_graph = KnowledgeGraph()          # 知识图谱
        self.template_library = TemplateLibrary()         # 模板库
        self.case_repository = CaseRepository()           # 案例库
        self.performance_database = PerformanceDatabase() # 性能数据库
        self.asset_tagger = AssetTagger()                # 资产标签器
    
    async def capitalize_experience(self, execution_result, feedback):
        """将执行经验转化为可复用资产"""
        
        # 提取成功模式
        success_patterns = await self.extract_success_patterns(execution_result)
        
        # 更新知识图谱
        knowledge_updates = await self.knowledge_graph.update_knowledge(
            success_patterns, feedback
        )
        
        # 生成可复用模板
        templates = await self.template_library.generate_templates(
            execution_result, success_patterns
        )
        
        # 沉淀案例
        case_study = await self.case_repository.create_case_study(
            execution_result, feedback, success_patterns
        )
        
        # 更新性能数据
        performance_update = await self.performance_database.update_performance(
            execution_result, feedback
        )
        
        # 资产标签和索引
        tagged_assets = await self.asset_tagger.tag_and_index({
            'knowledge_updates': knowledge_updates,
            'templates': templates,
            'case_study': case_study,
            'performance_update': performance_update
        })
        
        return tagged_assets
```

## 🎭 六大维度哲学体系

### 1. 信息哲学 (Information Philosophy)
**核心命题：信息即证据，验证即真理**

**关键原则**：
- **最小必要采集**：只收集必要的信息，明确数据最小化原则
- **真实性优先**：把"真实感"建模为合规与审美的综合特征
- **三角验证**：强制要求至少两个独立来源的相互印证
- **时效性管理**：所有证据都有明确的时效期和衰减机制

### 2. 决策哲学 (Decision Philosophy)
**核心命题：决策即责任，透明即信任**

**关键原则**：
- **影响可逆性矩阵**：按影响程度和可逆性划分决策边界
- **双钥匙机制**：高风险决策采用"AI建议 + 人类批准"模式
- **决策日志**：每个决策都记录推理过程、证据依据、预期结果
- **反馈纪律**：每个决策都绑定实验编号和回写责任

### 3. 自动化哲学 (Automation Philosophy)
**核心命题：自动化即效率，边界即安全**

**关键原则**：
- **三层自动化栈**：感知层→生产层→分发层
- **风险速率限制**：平台行为随机化、人类节奏模拟
- **影子模式先行**：重大变更前先在影子模式下验证
- **护栏内执行**：宁可降低短期效率，不透支账号信用

### 4. 协作哲学 (Collaboration Philosophy)
**核心命题：协作即互补，透明即共赢**

**关键原则**：
- **角色责任明确**：AI担任研究员/助手，人类担任总编辑/守门人
- **接口契约清晰**：任何工作都有明确的Brief和交付标准
- **解释性要求**：AI输出必须附"为何如此"的可解释摘要
- **信用积分机制**：AI建议的历史命中率和稳定性影响其自主等级

### 5. 进化哲学 (Evolution Philosophy)
**核心命题：进化即学习，失败即智慧**

**关键原则**：
- **双回路学习**：不只修正做法，还要质疑假设和规则本身
- **投资组合视角**：以"探索/利用"比例分配资源
- **脆弱性预算**：为平台政策变化预留适应空间
- **鲁棒性设计**：设计冗余和降级路径

### 6. 价值哲学 (Value Philosophy)
**核心命题：价值即复利，增长即意义**

**关键原则**：
- **可信赖增长**：合规、稳定、可解释的增长
- **合格意向产出率**：真实互动且高转化潜力的曝光占比
- **阶段化权重**：不同发展阶段侧重不同的价值指标
- **长期主义**：重视品牌资产沉淀而非短期效果

## 🔄 实现方法论

### Phase 0: 外部大脑加载
每个任务开始前必须完成：
- [ ] 读取根级文档：CLAUDE.md、AGENTS.md、RULES.md
- [ ] 加载目标域配置：README、CLAUDE、RULES、USEME
- [ ] 检索现有资产：memory-bank、support_modules
- [ ] 标记风险边界：权限、数据、时间节点、依赖缺失

### Collect → Model → Compare → Align → Deliver → Archive
标准工作流六阶段：
1. **Collect**：明确目标、输入、约束，记录缺口责任人
2. **Model**：问题拆解、关键假设、推理链设计
3. **Compare**：生成候选方案，对比优劣和风险
4. **Align**：目标/方案/风险/TODO总结，确认依赖和责任人
5. **Deliver**：根据复杂度选择交付形式
6. **Archive**：回顾决策链路，更新知识资产

### Level S/M/L分级处理
- **Level S**：直接对话，1-2个推理步骤+结论
- **Level M**：搜索驱动，需求解构+2方案对比+选择理由  
- **Level L**：结构化执行，完整思维分析+多方案对比+风险预案

## 🎯 质量保障体系

### 决策质量控制
- **准确性检查**：事实性与逻辑性验证
- **完整性检查**：需求覆盖度评估
- **一致性检查**：多服务输出一致性
- **可用性检查**：结果可理解性和可操作性

### 风险缓解策略
- **技术风险**：分阶段验证，完善回滚机制
- **业务风险**：渐进式升级，业务零中断
- **合规风险**：规则内置，合规即设计
- **运营风险**：实时监控，自动降级

### 持续改进机制
- **反馈循环**：每个输出都有反馈收集点
- **学习优化**：基于反馈的模型和策略优化
- **版本管理**：所有资产都有版本控制和变更追踪
- **知识更新**：定期审查和更新知识资产
