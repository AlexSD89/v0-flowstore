## 📋 项目概览

### 🎯 核心愿景
将Claude Code作为**操作系统**，在其能力结构之上构建完全智能化的**证据驱动叙事—意向匹配引擎**，实现从客户MD文件编辑到端到端智能运营的无人化闭环。

## 🎛️ 核心设计哲学

### 证据驱动的叙事—意向匹配引擎

**四大支柱支撑**：
1. **证据账本**：所有决策和洞察的可追溯来源
2. **自主等级(LOA)**：智能决策边界的精细化控制
3. **评测优先**：一切输出必须经过严格评测验证
4. **资产化沉淀**：知识和经验的持续积累与复用

**元原则**：
- 证据优先于直觉
- 可逆优先于可控
- 人类掌管价值与风格
- 永续学习与进化
- 合规与信任内嵌化
