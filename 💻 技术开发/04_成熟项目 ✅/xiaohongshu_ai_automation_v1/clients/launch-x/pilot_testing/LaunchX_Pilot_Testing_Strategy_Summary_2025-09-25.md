## 🎯 质量基准体系

### 1. 移动端优化标准 (Technical Excellence)

#### 图片技术规格
```yaml
分辨率要求:
  - 最小分辨率: 1080px
  - 推荐比例: 9:16 (主feed) / 1:1 (备选)
  - 文件大小: ≤10MB
  - 格式标准: PNG优先，JPG备选

视觉可读性:
  - 对比度比: >4.5:1 (WCAG AA标准)
  - 最小字体: 18pt (手机端可读)
  - 标题字体: 24-32pt
  - 行间距: 1.4倍字号

信息架构:
  - 信息层次: ≤3层
  - 留白比例: ≥30%
  - 视觉焦点: 1主+2次
  - 标题长度: ≤25字符
```

#### 内容结构优化
```yaml
移动端适配原则:
  上部区域(40%): 主标题 + 品牌标识 + 视觉吸引
  中部区域(40%): 核心数据 + 功能亮点 + 对比信息  
  下部区域(20%): 品牌标识 + 行动号召 + caption预留

信息密度控制:
  主标题: 1行 (最多20字符)
  副标题: 2行内 (每行15字符)
  数据点: 2-3个核心数据
  元素间距: 8px的倍数
```

### 2. 品牌整合标准 (Brand Excellence)

#### 必需品牌元素
```yaml
强制性要求:
  - LaunchX主标签: 100%内容包含
  - 品牌色彩: #4A90E2 (LaunchX蓝)
  - 品牌标识: 视觉位置明显
  - 品牌声音: 专业亲和，权威可信

标签策略:
  品牌标签: #LaunchX + #LaunchX评测/#LaunchX推荐
  功能标签: #AI工具横评 + #效率工具测评
  热门标签: 基于2025年9月趋势数据
  长尾标签: 具体工具名 + 使用场景
```

#### 内容调性统一
```yaml
写作风格:
  - 第一人称真实体验分享
  - 数据支撑 + 情感化表达
  - 专业术语通俗化解释
  - 客观评价 + 主观推荐

结构模板:
  开头: 痛点共鸣 + 身份认同
  正文: 功能解析 + 数据验证 + 对比分析
  结尾: 总结推荐 + 互动引导 + 品牌回归
```

### 3. 内容质量标准 (Content Excellence)

#### 信息完整性
```yaml
必备信息要素:
  - 工具基本信息: 名称、官网、价格、核心功能
  - 使用数据: 具体数字、测试周期、样本规模
  - 对比分析: 竞品横评、优缺点客观评价
  - 使用建议: 适用场景、目标人群、选择标准

数据可信度:
  - 测试方法明确
  - 数据来源可追溯
  - 结论有理有据
  - 避免夸大宣传
```

#### SEO优化标准
```yaml
标签策略:
  数量控制: 8-12个标签
  分布策略: 40%热门 + 40%精准 + 20%品牌
  组合模式: 平衡型 (推荐) / 保守型 / 进攻型

关键词优化:
  标题植入: 自然融入LaunchX品牌和核心卖点
  首段优化: 关键词密度适中，搜索友好
  结尾回归: 品牌标签集中，利于关联搜索
```
