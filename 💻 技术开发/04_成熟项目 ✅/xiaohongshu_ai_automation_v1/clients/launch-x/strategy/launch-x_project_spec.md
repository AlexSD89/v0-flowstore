# 项目需求说明 / Project Specification

## 背景 / Context
- 客户: LaunchX
- 项目目标: 通过小红书构建企业AI功能评测与撮合的权威渠道
- KPI / 成功指标: 粉丝增长30%+/月、咨询线索≥50条/月、GMV 年化1000万

## 核心用户场景 / Core Scenarios
1. 评测企业级应用中的核心AI功能
2. 撮合企业需求与AI功能开发商
3. 发布行业趋势洞察与案例

## 关键约束 / Constraints
- 时间窗口: 启动-权威建设(0-3月) -> 生态转化(4-6月) -> 标准制定(7-12月)
- 资源限制: 人工审核≤1人天/周，预算聚焦内容品控
- 平台组合: 小红书为主，知乎/B站/微博为跨平台延展

## 交付清单 / Deliverables
- 周期性交付: 周策略、AI内容包、互动脚本、数据周报
- 一次性交付: 品牌宪章、全托管SOP、首轮评测白皮书
- 报告格式: Markdown 主体 + CSV/PNG 附件

## 依赖与风险 / Dependencies & Risks
- 外部依赖: Rube API、XHS 登录态、Claude 密钥、图像模型许可证
- 主要风险: 平台风控、素材侵权、企业案例保密
- 缓解措施: 模拟真人行为、保留授权函、敏感内容脱敏
