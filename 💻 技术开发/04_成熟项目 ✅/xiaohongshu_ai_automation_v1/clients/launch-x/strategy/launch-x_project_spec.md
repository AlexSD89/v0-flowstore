# 项目需求说明 / Project Specification

## 背景 / Context
- 客户: Example Client
- 项目目标: 搭建企业应用 AI 功能评测的权威账号矩阵
- KPI / 成功指标: 粉丝增长、咨询线索、GMV 转化

## 核心用户场景 / Core Scenarios
1. AI 功能深度评测
2. 企业选型决策指导
3. 生态合作线索撮合

## 关键约束 / Constraints
- 时间窗口: T0+90 天三阶段里程碑
- 资源限制: 人工审核 ≤ 1 人天/周
- 平台组合: 小红书 主阵地，微博/B站 备选

## 交付清单 / Deliverables
- 周期性交付: 周度策略 + AI 内容包 + 报告
- 一次性交付: 品牌宪章、全托管 SOP
- 报告格式: Markdown + 图表附件

## 依赖与风险 / Dependencies & Risks
- 外部依赖: Rube 工具、XHS 登录态、图像模型
- 主要风险: 平台风控、素材版权、模型漂移
- 缓解措施: 加强反检测、保留素材授权、定期复训
