## 🎯 移动端图片质量标准

### 1. 技术规格要求

#### 分辨率与尺寸 ⚡
```yaml
主feed图片:
  - 9:16 竖版: 1080×1920px (推荐)
  - 1:1 方版: 1080×1080px (备选)
  - 最小分辨率: 720p
  - 最大文件大小: 10MB
  - 格式: PNG/JPG (PNG优先，保证质量)

质量要求:
  - 压缩率 < 80% (保证画质)
  - DPI: 300 (印刷品质)
  - 色彩模式: RGB
```

#### 信息密度控制 🔍
```yaml
移动端适配原则:
  - 信息层次: ≤ 3层
  - 主标题: 1行 (最多20字符)
  - 副标题: 2行内 (每行15字符)
  - 数据点: 2-3个核心数据

字体规范:
  - 最小字号: 18pt (手机可读)
  - 标题字号: 24-32pt
  - 正文字号: 18-22pt
  - 行间距: 1.4倍字号
```

#### 视觉对比度 🌈
```yaml
对比度要求:
  - 文字背景对比: > 4.5:1 (WCAG AA标准)
  - 主要元素对比: > 3:1
  - 颜色测试工具: WebAIM Contrast Checker

色彩规范:
  - 主色: LaunchX蓝 (#4A90E2)
  - 辅色: 灰色系 (#666666, #CCCCCC)
  - 背景: 白色/浅灰 (#FFFFFF, #F8F8F8)
  - 警告色: 橙色 (#FF9500)
  - 成功色: 绿色 (#34C759)
```

### 2. 内容布局要求

#### 信息架构 📐
```yaml
上部区域 (40%):
  - 主标题/核心卖点
  - 品牌logo/标识
  - 视觉吸引元素

中部区域 (40%):
  - 核心数据/图表
  - 功能亮点展示
  - 对比信息

下部区域 (20%):
  - LaunchX品牌标识
  - 行动号召
  - 留白空间 (caption预留)
```

#### 版式设计原则 ✨
```yaml
排版要求:
  - 视觉焦点: 1个主焦点 + 2个次焦点
  - 留白比例: ≥ 30%
  - 对齐方式: 统一左对齐或居中
  - 元素间距: 8px的倍数

图标使用:
  - 风格统一: 线性图标/面性图标保持一致
  - 大小规范: 24px/32px/48px
  - 色彩一致: 与品牌色系保持统一
```

## 🔧 自动化质检工具

### 技术检测项目

#### Python自动检测脚本
```python
import cv2
import numpy as np
from PIL import Image, ImageFont, ImageDraw
import pytesseract

def mobile_image_quality_check(image_path):
    """移动端图片质量自动检测"""
    
    checks = {
        'resolution_check': False,
        'aspect_ratio_check': False,
        'contrast_check': False,
        'text_density_check': False,
        'file_size_check': False
    }
    
    # 1. 分辨率检查
    img = cv2.imread(image_path)
    h, w = img.shape[:2]
    
    if (w >= 1080 and h >= 1080):
        checks['resolution_check'] = True
    
    # 2. 宽高比检查
    ratio = h / w
    if ratio >= 1.7 or ratio == 1.0:  # 9:16 或 1:1
        checks['aspect_ratio_check'] = True
    
    # 3. 对比度检查
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    contrast = gray.std()
    if contrast > 50:  # 对比度阈值
        checks['contrast_check'] = True
    
    # 4. 文字密度检查 (OCR)
    text = pytesseract.image_to_string(img, lang='chi_sim')
    text_density = len(text.strip()) / (w * h) * 1000000
    if text_density < 50:  # 文字密度不能过高
        checks['text_density_check'] = True
    
    # 5. 文件大小检查
    import os
    file_size = os.path.getsize(image_path) / (1024*1024)  # MB
    if file_size <= 10:
        checks['file_size_check'] = True
    
    return checks
```

## 🚨 质量问题处理

### 常见问题分类

#### A类问题 (严重) 🔴
```yaml
技术缺陷:
  - 分辨率不达标
  - 宽高比错误
  - 文件格式错误
  - 压缩质量差

内容错误:
  - 品牌元素缺失
  - 信息错误/过时
  - 文字错误/乱码
  - 色彩搭配不当

处理方式:
  - 立即退回重做
  - 不计入交付周期
  - 记录严重违规
  - 影响合作评级
```

#### B类问题 (一般) 🟡
```yaml
设计优化:
  - 视觉效果一般
  - 排版可以更好
  - 色彩搭配平淡
  - 创意度不够

体验问题:
  - 移动端体验一般
  - 信息层次不够清晰
  - 视觉焦点分散
  - 留白处理不当

处理方式:
  - 提供改进建议
  - 允许修改完善
  - 记录改进要点
  - 用于后续培训
```
