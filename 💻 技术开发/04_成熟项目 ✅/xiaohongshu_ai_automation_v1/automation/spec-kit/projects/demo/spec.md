# 项目需求说明 / Project Specification

## 背景 / Context
- 客户: Demo Fashion
- 项目目标: 打造“都市轻盈穿搭”主题月度 campaign，在 4 周内累计曝光 ≥ 60 万
- KPI / 成功指标: 单篇平均点赞 ≥ 250、收藏 ≥ 150、粉丝增长 8%

## 核心用户场景 / Core Scenarios
1. 白领工作日穿搭灵感
2. 周末松弛风混搭
3. 商务旅行行李清单

## 关键约束 / Constraints
- 时间窗口: 2025-10-01 至 2025-10-31
- 资源限制: 每周运营人力 4 小时、素材图片 30 张
- 平台组合: 小红书为主渠道，后续可扩展至微博

## 交付清单 / Deliverables
- 周期性交付: 每周 5 篇图文 + 1 份表现追踪
- 一次性交付: 月度 campaign 总结报告 + 次月提案
- 报告格式: Markdown + 图表截图

## 依赖与风险 / Dependencies & Risks
- 外部依赖: 供应链提供新品图 48 小时内到位
- 主要风险: 小红书审核收紧、行业话题热度波动
- 缓解措施: 准备 2 套备选主题、密切关注平台公告
