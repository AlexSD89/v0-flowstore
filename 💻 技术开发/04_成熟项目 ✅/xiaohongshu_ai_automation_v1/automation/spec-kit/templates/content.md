# 小红书AI自动化内容生成模板

## 移动端优化指导原则

### 📱 视觉布局要求
- **单列结构**: 避免复杂的多列布局，确保手机端阅读流畅
- **留白充足**: 段落间距不少于16px，行间距1.6倍，提升阅读体验
- **字号限制**: 正文最小14px，标题最小18px，确保清晰可读
- **图片规格**: 优先使用3:4比例，分辨率1080×1440，适配小红书展示

### 🎨 色块化信息卡片设计
```yaml
信息卡片结构:
  标题区: "简洁有力的功能标题 + 震惊表达"
  数据区: "具体量化数据 + 权威来源标注"
  对比区: "与竞品/过往的明确对比"
  行动区: "获取方式 + 互动引导"
```

## 文案结构补齐核心信息

### ✨ 必填内容模块
1. **功能亮点**
   - 3-5个核心功能点，每个用数据说话
   - 格式：`📈 [功能名]：[具体数据] ([数据来源])`
   - 示例：`📈 效率提升：87%用户报告生产力显著提升 (CB Insights 2025)`

2. **差异化优势**
   - 与竞品的明确对比数据
   - 独家技术或方法论优势
   - 格式：`⚡ vs [竞品]：[我们的优势] vs [竞品数据]`

3. **获取方式/地址**
   - 明确的访问路径或下载方式
   - 特殊渠道或优惠码
   - 格式：`🔗 获取方式：[具体路径/链接]`

4. **最新市场表现**
   - 近期融资、用户增长、市场份额等关键数据
   - 时间标注确保时效性
   - 格式：`📊 最新数据：[关键指标] (截至[时间])`

5. **头部信号引用**
   - 知名企业使用案例
   - 权威机构认证或推荐
   - 格式：`🏆 权威认证：[知名企业/机构]已采用`
