# LaunchX「企业AI武器库」系列制作规范

> Updated: 2025-09-25  
> Owner: LaunchX 自动化团队

## 1. 系列定位
- **目标读者**: 数字化负责人、销售 VP、企业创新团队
- **核心价值**: 基于真实企业链路的全栈 AI 评测，可直接复制到销售闭环
- **发布节奏**: 每周三 18:00（必要时突发热点加更）
- **色彩体系**: LaunchX Deep Blue `#1B6BFF` + Signal Gold `#F2B705`

## 2. 内容框架（小红书）
1. **系列开场白**: `LaunchX「企业AI武器库」DayX｜核心问题`，必须落地到企业痛点。
2. **链路设定**: 场景、团队规模、目标、评估方法，四行内说明。
3. **节点拆解**: 线索捕获 → 互动培育 → 成交辅导 → 团队扩编 → 数据回流，每段必须包含：
   - 工具背景速览（定位、典型客户、行业口碑）
   - 一句话定位（解决的核心痛点）
   - 三步即用指南（入口路径、配置动作、验证指标）
   - LaunchX 实测数据/指标 & 评分（可口语化）
   - 客户在乎的风险/合规提醒
4. **节点清单（当前默认）**: Synkli｜Uniform｜WisdomSnap｜GPT Realtime｜AI Resume Screener，可按项目替换但须保持链路覆盖。
4. **七维评分雷达**: 表格形式，必须有简评；综合评分 + 推荐等级。
5. **部署建议**: 按团队规模给三档组合。
6. **风险提醒 & 合规建议**: 至少 3 条。
7. **互动引导**: 引导评论 + 关注，含下期预告。
8. **标签矩阵**: 10 条内；`#LaunchX` + 系列固定标签 + 当期热点。

## 3. 视觉与素材
- **封面**: 系列标贴 + 7 维雷达图或链路图；对比度 > 4.5:1。
- **辅助图**: 流程图 + 数据条形图；字号 ≥ 18pt。
- **图像生成流程**:
  1. 调用 `image-mcp.generate` 使用 `content_modes.hot_topic` 参数；
  2. 验证分辨率、logo、水印；
  3. 如不达标，启用品牌图库模板。

## 4. RUBE 主控与 MCP 节点协同
- **主控流程**：RUBE 负责情报收集 → 分派至各 MCP 节点 → 汇总指标 → 触发质检。
- **节点角色**：Synkli（线索捕获）｜Uniform（互动培育）｜WisdomSnap（内容沉淀）｜GPT Realtime（成交辅导）｜AI Resume Screener（团队扩编）。可按项目替换，但必须覆盖五段链路。
- **Claude 定位**：作为指挥官，负责编写提示词、整合数据、输出行动项。
- **同一篇内容**：每个节点都需“背景速览 + 三步即用 + 核心指标 + 风险提醒”。

## 5. 自动化提示词要求
- Claude `ask` 步骤必须包含：
  - 系列名称/Day 标
  - 链路五段 + 系列配色
  - 必备结构模块、Hook、互动触发、引用来源
  - `series_opening_template` 作为开头语
- 生成 JSON 内需返回：标题、正文（含节点小标题）、标签数组、建议图像描述。

## 6. 质量稽核清单
执行前确认：
- `execution/launch-x_quality_checklist.md` 全部勾选；链路步骤出现完整。
- `automation/run_client.py --client launch-x --dry-run` 成功。
- `verification_tracker` 里涉及的工具/数据源状态为 `verified` 或附待确认说明。

发布后 48 小时内：
- 在 `clients/launch-x/reports/LaunchX_Content_Performance_<date>.md` 回填 CTR / 完读率 / 标签曝光。
- 表现 < 阈值的 Hook、标签写入 `series_retrospective`（可新建表格）。
- 更新 `content_modes`（例如热点标签优先级），并 `bootstrap_client.py --force` 再次刷新模板。
