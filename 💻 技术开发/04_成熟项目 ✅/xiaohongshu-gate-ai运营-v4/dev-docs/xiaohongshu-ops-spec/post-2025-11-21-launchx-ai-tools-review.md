# 小红书单篇内容 Spec · LaunchX AI 工具评测示例

> 说明：本 Spec 示例对应一篇面向「企业数字化负责人」的 AI 工具评测类小红书笔记，用于演示 Post Spec 的完整填写方式。

## 1. 基本信息

- `client_slug`：launch-x
- 账号名称 / ID：LaunchX 企业AI评测官（示意）
- 所属项目 / 客户：LaunchX AI评测平台
- 计划发布时间（本地时区）：2025-11-23 20:00（工作日黄金时段测试）
- 当前内容所属阶段：
  - [x] 本周侧重点（周主题：企业效率提升场景评测）

- 对应运营目标（引用 Client Spec 中编号）：
  - O-2025Q4-01「提升 LaunchX 在企业 AI 工具评测垂直的权威度」
  - O-2025Q4-02「在小红书每周获取 ≥10 个来自企业侧的咨询线索」

## 2. 标题设计

- 标题候选（至少 3 个）：
  1. 「3 个AI工具，让你的销售团队效率翻2倍」
  2. 「踩过无数坑后，我只给销售团队留了这3个AI神器」
  3. 「别再乱买AI软件了，这3个工具真正在帮销售赚钱」

- 标题范式（从 Pattern Library 选择，可多选）：
  - [x] P-Title-02：数字清单型（候选 1）
  - [x] P-Title-03：对比/踩坑型（候选 2、3）
  - [ ] P-Title-01：痛点 + 结果型
  - [ ] P-Title-04：场景 + 冲突型
  - [ ] 其他：

- 标题约束：
  - 字数范围：22–28 字；
  - 必须包含关键词：`AI工具`、`销售团队`、`效率`；
  - 禁止出现的词：`保底收益`、`稳赚`、任何类似「割韭菜」暗示。

> 初步选择：候选 2 作为主推标题，用候选 1 作为 A/B 对照。

## 3. 封面与图片规划

- 封面类型：
  - [x] 使用场景（办公室桌面 + 仪表盘）
  - [ ] 人物出镜
  - [ ] 产品特写
  - [ ] 信息型封面（带文案）

- 封面设计要点：
  - 画面焦点：一位销售经理在大屏前查看 AI 辅助销售看板，旁边显示三个工具的 Logo 或抽象图标；
  - 主色调 / 氛围：赛博蓝 + 清晨暖光，呼应品牌宪章中的视觉风格；
  - 封面文案（如有）：
    - 「销售团队效率翻2倍的3个AI工具」

- 内页图片说明：
  - 预期图片张数：4–6 张
  - 每张图片的内容与顺序：
    - 图 1：整体封面场景（与封面呼应，适度放大细节）；
    - 图 2：工具 A 的核心界面（标注「线索自动打分」场景）；
    - 图 3：工具 B 的使用前后对比（如跟进节奏 / 提醒效率）；
    - 图 4：工具 C 的团队视图（整体销售漏斗看板）；
    - 图 5：（可选）简单表格对比三款工具的优缺点；
    - 图 6：（可选）LaunchX 评测方法截图，突出专业性。

## 4. 正文结构

- 第一屏（前 2–3 行，钩子）：
  - 针对的用户画像：中小企业销售负责人 / 销售 VP / 增长负责人；
  - 提出什么冲突/问题：
    - 「买了很多 AI 工具，却发现销售团队并不爱用、效率也没真的提升。」

  草稿示意：
  > 「花了大价钱上AI工具，但销售还是靠群里吼？
  >  踩过一圈坑之后，我终于只给销售团队留下了3个真的能用的AI神器。」

- 主体结构（建议 3–5 段，每段 2–4 行）：

  1. 场景描述：
     - 「一家典型 B2B 团队的日常：混乱的 Excel、跟不完的线索、被老板催的日报。」

  2. 冲突/痛点：
     - 「工具太多太杂、体验不好、培训成本高，销售宁愿自己记本子。」

  3. 解决思路或拆解：
     - 引入 LaunchX 的评测方法：从【线索优先级】【跟进节奏】【团队协作】【数据回看】四个维度评估工具。

  4. 具体步骤/细节：
     - 依次介绍 3 个工具：每个 3–4 行描述「适用类型 + 关键优势 + 明确适合/不适合的人」；

  5. 结果/反馈（如有）：
     - 引用真实试用数据（可匿名），例如「团队每日有效触达提升 40%，跟进延迟减少 60%」。

- 结尾（CTA）：
  - 想让读者做什么：
    - [x] 收藏  [x] 评论  [x] 私信  [ ] 点赞  [ ] 关注（默认伴随）
  - CTA 文案候选：
    - 「想看完整评测表格，评论区留个『想看』。」
    - 「有哪款AI工具你也在用？评论区分享一下经验。」
    - 「如果你在搭销售团队的AI栈，可以私信我【销售AI】，我把完整评测报告发你。」

- Markdown / 文本约束：
  - 单段不超过 3 行，尽量短句；
  - 使用 `##` 小标题区分「3 个工具」部分；
  - 避免重复堆叠「AI」「神器」等词；
  - 保持专业语气，避免夸张承诺。

## 5. 标签与话题（Tag Engine）

> 标签组合参照 LaunchX 的 SEO 策略文档，并选择平衡型模式。

- 组合模式：
  - [ ] Conservative（保守型）
  - [x] Balanced（平衡型）
  - [ ] Aggressive（进攻型）

- 品牌标签（Brand Tags，通常必选 1–2 个）：
  - `#LaunchX`
  - `#LaunchX评测`

- 功能定位标签（Function Tags）：
  - `#AI工具评测`
  - `#效率工具测评`
  - `#企业AI应用`

- 热门流量标签（Hot Tags）：
  - `#AI工具推荐`
  - `#办公神器`
  - `#效率提升`

- 长尾精准标签（Long-tail Tags）：
  - 行业标签：`#企业数字化`、`#销售团队`、`#B2B销售`
  - 功能标签：`#销售自动化`、`#线索管理`、`#CRM集成`

- 标题/正文中的自然植入策略（简要说明）：
  - 标题中自然放入「AI工具」「销售团队」「效率」等词；
  - 正文首段提到 LaunchX 的评测身份一次；
  - 结尾 CTA 中提醒「更多评测在 LaunchX 账号中」。

## 6. 实验设定（Experiment Settings）

- 实验编号：EXP-LX-2025-11-23-001
- 实验类型：
  - [x] 标题 A/B 测试（候选 1 vs 候选 2）
  - [ ] 封面 A/B 测试
  - [ ] 内容结构对比
  - [ ] CTA 类型实验
  - [x] 标签组合实验（平衡型 vs 轻微进攻型）

- 实验假设（1–2 句）：
  - 「对于企业销售负责人，‘踩坑型’标题的评论率高于‘数字清单型’标题，但收藏率相近。」
  - 「在品牌标签不变的前提下，适度加入 `#办公神器` / `#效率提升` 等热门标签，可以提升曝光与点击。」

- 目标指标与预期变化（对比基线）：
  - 曝光：较同类评测内容提升 ≥ 20%；
  - 点赞：提升 ≥ 15%；
  - 收藏：提升 ≥ 20%；
  - 评论：提升 ≥ 30%（重点观察 A/B 差异）；
  - 私信/线索：至少获取 5 条相关咨询。
