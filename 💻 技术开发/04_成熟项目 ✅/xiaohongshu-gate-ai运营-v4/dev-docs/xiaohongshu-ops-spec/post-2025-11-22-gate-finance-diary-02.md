# Gate 场景日记 02｜一个财务总监，把月底结账从 5 天压到 2 小时

## 1. 标题

Gate 场景日记 02｜一个财务总监，把月底结账从 5 天压到 2 小时

## 2. 正文草稿

先说完这句话，再讲故事：

> “以前每到月底，我都不敢跟孩子约周末。”  
> —— 这是这家企业财务总监跟我们第一次聊 Gate 时说的原话。

她所在的是一家年销售几个亿的制造业公司，  
每个月的最后一周，财务部的画面大概是这样：

- 📊 三个系统三种口径：ERP、银行流水、薪酬系统各讲各的数字；  
- 📥 报销单一摞摞堆在桌子上：有人没贴发票，有人忘了走审批；  
- 📧 Excel 报表在各个邮箱和群里飞来飞去：各部门填数据，财务合并，领导最后再“手改一版”；  
- ⏰ 晚上 11 点，还有人在群里问：“这笔到底挂哪儿？”  
- 😵 最扎心的是：月底 5 天，几乎每天都是 12 小时起步。

她说了一句很真实的话：

> “我们不是不专业，是这个流程太不讲人性了。”

她来找 Gate 时，只提了两个要求：

1. 月底不要再是灾难；  
2. 不要再把最贵的财务人力用在「搬数据 + 对账」上。

---

### 01｜我们没有先聊 AI，先聊的是“到底哪里在浪费命”

我们习惯的第一步，不是推荐哪套 AI 系统，  
而是把时间线拉开，把人一天的动作拆出来看。

我们跟她和团队一起，把“月底结账”拆成几块：

1. **数据收集**  
   从 ERP、Excel、银行流水、第三方系统把数据拉齐——全靠“人记得去导一遍”。

2. **对账 & 勾稽**  
   手工对账：这个数字为什么对不上？  
   打电话、发微信、进会议，问“这笔到底是什么？”

3. **报销 + 单据检查**  
   报销单、发票、附件，一张一张看；  
   有的发票抬头不对，要重开；有的申请没审批完，又被退回。

4. **报表出数 & 汇报**  
   各部门版本不一致；  
   老板要的是另一种维度的拆分；  
   最后一刻还在改 Excel 里面的公式。

我们只问她一句话：

> “如果这 4 步里，只能先用 Gate 帮你改一块，你最想先动哪里？”

她想了 5 秒：

> “对账和拉数。搞清楚数字，其他我来。”

这句话，直接决定了 Gate 在这个项目里的第一版设计。

---

### 02｜Gate 在这个场景里，实际上就干了三件事

我们没有上来就搞一个“很酷”的大系统，  
而是围绕她的那句话，做了三件非常具体的事情。

#### ✅ 第 1 件事：所有结账相关数据，只进 Gate 一次

对她的团队来说，只是两件小变化：

- 把 ERP、银行流水、报销系统的出口路径接到 Gate 上；  
- 不再要求财务同事手动导出、发 Excel、拼表。

财务团队看到的变化是：

- 有一个「月底结账」视图；  
- 所有关键数据源都在一个面板里；  
- 每个数据源的刷新状态一目了然。

她说：

> “我第一次知道，原来有一天可以不用再说‘谁帮我导一下这个数据’了。”

#### ✅ 第 2 件事：让 Gate 帮她“先对两遍账”

第二件事，我们让 Gate 帮她做“预对账”。

Gate 会在后台自动跑几件事：

- ERP 和 银行流水之间的勾稽校验；  
- 应收/应付和实际到账/支出之间的差异；  
- 异常交易（金额/时间/对象异常）的标记。

结果变成：

- 以前是：财务拉完数据，一条一条看哪儿不对；  
- 现在是：Gate 先把“明显不对的地方”圈出来，  
  财务只需要看这几十条，而不是在几千条里盲找。

她的反馈是：

> “以前要花 3 天对账，现在 1 天就能把最麻烦的地方解决掉。”

#### ✅ 第 3 件事：报表出数，从“手改 Excel”变成“解释变化”

最后一件事，我们把“给老板看的那份报表”做了一个小手术：

- 和老板一起定义了一版固定结构的「月度视图」；  
- 把口径、拆分方式、关键指标全部写死在 Gate 的工作流里；  
- 每个月，Gate 自动填数，我们只在边上写注释和解释变化。

对她来说，月底的体验是：

- 以前：月底 = 「做表 + 改表 + 被追问」；  
- 现在：月底 = 「看 Gate 给的数对不对 + 解读这个月发生了什么」。

她用一句话总结：

> “我第一次在月度会上有精力讲‘为什么’，  
>  而不是解释‘这个数是不是错了’。”

---

### 03｜5 天变 2 小时，对她来说意味着什么？

我们不做虚假的夸张，就按她自己的说法来：

- 以前：  
  - 月底结账 = 5 天 + 每天 10–12 小时 + 一堆群消息和电话；  
- 现在：  
  - 月底结账：  
    - 前几天 Gate 自动帮忙拉数、预对账；  
    - 正式“出月报”的那天，她用 2 小时过一遍 Gate 的结果和异常点；  
    - 剩下时间拿着这套视图跟老板、业务聊“这个月到底发生了什么”。

生活层面的变化：

- 不再为了月底结账拒绝所有周末安排；  
- 不再怕老板问“这个数是不是有问题”；  
- 开始有余力推进预算、预测、分析，而不是被日常流程吃死。

她说：

> “以前我是系统里的最后一个螺丝，  
>  现在我终于像个财务总监了。”

### 04｜如果你也在经历类似的“月底地狱”

这条日记不是教你怎么用某个软件，  
只是把一个非常具体的画面摆在你面前：

- 每个喊“AI 转型”的公司里，  
  都藏着一堆没人愿意写方案的小流程；  
- 它们不够“战略级”，但每天都在消耗团队的耐心和生命力。

如果你自己就是财务负责人 / 运营负责人 / 创始人，可以在评论里简单写一句：

> 行业 + 大概规模 + 你每月最怕的那条流程

比如：

- 「SaaS 公司 / 50 人，每月最怕对订阅平台和财务系统的账」  
- 「传统外贸 / 几千单量，最怕月底勾发票和报关单」  
- 「连锁零售 / 多门店，最怕统一盘点和费用摊销」

我们后面的 Gate 场景日记，可以挑一两个真实场景拆开讲：

- 如果换成 Gate，我们会把这条流程拆成哪几个节点？
- Gate 帮你做哪一段？
- 人类只在最后哪几个地方做判断？
