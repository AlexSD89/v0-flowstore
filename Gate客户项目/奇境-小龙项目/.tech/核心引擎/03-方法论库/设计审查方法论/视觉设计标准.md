# 视觉设计审查标准方法论

## 🎯 方法论目标

建立标准化的风控设计稿审查流程，确保特化2-风控设计质量审查器能够系统性地评估H5和微报设计稿，提供高质量的修改建议。

## 📋 核心审查原则

### 1. 渠道差异化审查
```yaml
channel_differentiation:
  h5_design_focus:
    - "多屏适配和响应式布局"
    - "分阶段信息展示设计"
    - "CTA分布优化"
    - "动效节制和加载优化"

  weixin_report_focus:
    - "单图或短长图优化"
    - "同屏信息整合"
    - "文字可读性增强"
    - "社交媒体适配优化"
```

### 2. 三级质量门禁
```yaml
quality_gates:
  gate1_design_review:
    threshold: "≥0.85分"
    focus: "视觉设计基础质量"
    criteria: "层级关系、留白、对比度、排版、视觉层次"

  gate2_brand_consistency:
    threshold: "≥0.85分"
    focus: "品牌规范一致性"
    criteria: "品牌色板、Logo使用、字体标准、安全区域"

  gate3_client_approval:
    threshold: "≥0.90分"
    focus: "客户需求和合规要求"
    criteria: "客户意见、法务合规、业务目标、发布核验"
```

### 3. 风控合规优先
```yaml
compliance_priority:
  regulatory_requirements:
    - "金融法规遵循"
    - "风险警示显著性"
    - "信息披露完整性"
    - "误导性表达检查"

  platform_constraints:
    - "H5技术限制"
    - "微报尺寸要求"
    - "平台审核标准"
    - "格式规范遵循"
```

## 🔧 标准审查流程

### Phase 1: 设计识别（10分钟）
```yaml
design_recognition:
  channel_detection:
    input: "设计图片文件"
    analysis: "识别H5设计vs微报设计"
    confidence: "≥90%"

  stage_inference:
    pattern_recognition: "版本标识分析（v0/v1/vF）"
    iteration_history: "修改历史追踪"
    current_stage: "初稿/修改/终稿判断"

  compliance_context:
    industry_type: "风控行业特征识别"
    risk_level: "风险等级评估"
    regulatory_scope: "合规要求范围"
```

### Phase 2: 差异化分析（15分钟）
```yaml
differentiation_analysis:
  h5_specific_review:
    responsive_design: "响应式设计检查"
    multi_screen_adaptation: "多屏适配验证"
    interaction_flow: "交互流程合理性"
    loading_performance: "加载性能影响"

  weixin_specific_review:
    information_density: "信息密度控制"
    social_sharing: "社交媒体适配"
    readability_optimization: "可读性优化"
    compression_quality: "压缩后质量"

  quality_differences:
    technical_constraints: "技术约束差异"
    user_behavior_patterns: "用户行为模式差异"
    content_organization: "内容组织差异"
    compliance_display: "合规展示差异"
```

### Phase 3: 综合质量评估（15分钟）
```yaml
comprehensive_assessment:
  visual_appeal:
    aesthetics_score: "视觉美感评分"
    color_harmony: "色彩搭配分析"
    typography_quality: "字体排版质量"
    image_clarity: "图片清晰度"

  brand_consistency:
    logo_usage: "Logo使用规范检查"
    color_application: "品牌色彩应用验证"
    typography_standard: "字体标准统一检查"
    visual_style: "视觉风格一致性"

  user_experience:
    interaction_fluidity: "交互流畅性评估"
    click_efficiency: "点击效率分析"
    response_time: "响应时间考虑"
    mobile_adaptation: "移动端适配检查"

  compliance_adherence:
    regulatory_compliance: "法规遵循检查"
    risk_disclosure: "风险披露评估"
    platform_compatibility: "平台兼容性验证"
    information_completeness: "信息完整性确认"
```

### Phase 4: 修改建议生成（5分钟）
```yaml
modification_recommendations:
  priority_classification:
    p0_critical: "合规要求缺失、品牌严重不一致"
    p1_important: "设计质量优化、用户体验改进"
    p2_improvement: "细节优化、风格微调"
    p3_enhancement: "创新建议、差异化改进"

  suggestion_formatting:
    problem_identification: "清晰描述问题"

    solution_recommendation: "具体解决方案"
    implementation_guide: "实施步骤指导"
    expected_outcome: "预期改善效果"
```

## 📚 应用指南

### 新设计稿审查
1. **文件上传** → 设计稿自动识别
2. **渠道分类** → H5/微报差异化处理
3. **质量评估** → 三级门禁审查
4. **问题识别** → 关键问题优先级排序
5. **建议生成** → 可操作修改建议
6. **反馈记录** → 学习优化数据积累
