# 人机交互系统架构设计 - 第二季项目分类系统

> **设计理念**: 从技术驱动转向人类友好，让AI系统成为真正的协作者而非工具
> **核心创新**: 项目分类自动识别 + 特化微调文档生成 + Skills化自动化 + 基础层代码深埋
> **用户体验**: 上传即分类，分类即微调，微调即自动化，自动化即交付

## 🎯 设计原则

### 人类优先原则
- **直观操作**: 减少学习成本，符合直觉操作习惯
- **渐进披露**: 信息分层展示，避免认知过载
- **智能辅助**: AI主动提示和建议，而非被动等待指令
- **容错设计**: 允许试错，提供明确的恢复路径

### 分类驱动原则
- **自动识别**: 系统自动判断项目类型和复杂度
- **特化适配**: 不同类型项目匹配专门的处理流程
- **微调生成**: 自动生成项目特定的微调配置
- **知识沉淀**: 每个项目都丰富系统能力

### 技能化原则
- **技能复用**: 基于Skills生态系统实现专业能力复用
- **渐进披露**: 复杂技术细节对普通用户透明
- **模块组合**: 像搭积木一样组合不同技能
- **持续学习**: 每次使用都优化技能表现

## 🎯 核心组件设计

### 1. 项目分类器 (Project Classifier)

#### 自动分类逻辑
基于Excel数据分析结果，建立智能分类模型：

```python
# 分类维度
classification_dimensions = {
    "数据类型": ["Excel表格", "设计图片", "需求文档", "混合数据"],
    "业务复杂度": ["S-简单", "M-中等", "L-复杂"],
    "处理特化": ["特化1-Excel分析", "特化2-设计审查", "特化3-项目协调"],
    "交付要求": ["标准化报告", "定制化方案", "自动化流程"]
}

# 自动分类算法
def classify_project(uploaded_files, metadata):
    # 基于文件类型、大小、内容特征自动分类
    if has_excel_files(uploaded_files):
        complexity = analyze_excel_complexity(uploaded_files)
        return "特化1-Excel分析", complexity
    elif has_design_files(uploaded_files):
        design_type = detect_design_type(uploaded_files)
        return "特化2-设计审查", design_type
    elif has_complex_requirements(metadata):
        return "特化3-项目协调", "L-复杂"
    else:
        return "需要人工分类", "M-中等"
```

#### 分类界面设计
- **拖拽上传**: 直观的文件上传界面
- **实时预览**: 上传即显示分类结果
- **人工调整**: 允许用户修正分类结果
- **历史记录**: 显示相似项目的处理结果

### 2. 特化微调器 (Specialization Fine-tuner)

#### 微调文档生成
基于项目特征自动生成特化配置：

```yaml
# 特化1-Excel分析器微调配置示例
specialization_config:
  project_type: "特化1-Excel分析器"
  industry: "电商/零售"
  complexity: "M-中等"

  # 业务规则微调
  business_rules:
    quality_threshold: 0.90  # 从默认0.95调整为0.90
    focus_areas: ["品牌完整性", "营销文案", "SEO优化"]
    output_format: "中文报告 + 英文翻译"

  # AI参数微调
  ai_parameters:
    analysis_depth: "中等"
    language_model: "gpt-4-turbo"
    temperature: 0.3

  # 客户偏好微调
  customer_preferences:
    report_style: "简洁明了"
    include_recommendations: true
    urgency_level: "正常"
```

#### 微调界面
- **智能推荐**: 基于历史数据推荐最佳配置
- **参数调节**: 滑块式调节关键参数
- **实时预览**: 修改即时显示效果
- **模板管理**: 保存和复用微调配置

- **向后兼容**: 新版本兼容旧配置
