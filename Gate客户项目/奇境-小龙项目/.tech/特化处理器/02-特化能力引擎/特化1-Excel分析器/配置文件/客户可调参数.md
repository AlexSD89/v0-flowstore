# 特化1：Excel品牌信息分析器 - 客户可调参数

## 🎯 快速调整指南

**修改这里的参数会立即影响Excel分析器的行为**，无需技术知识，直接修改数值即可。

---

## 📊 质量标准参数

### 数据完整度要求
```yaml
completeness_threshold: 85      # 默认：85% (可调整范围：70-95)
# 说明：要求客户填写的字段完整度，低于此值会提醒客户补充
# 调整建议：制造业建议90%，服务业建议80%

translation_threshold: 90      # 默认：90% (可调整范围：75-100)
# 说明：英文翻译的覆盖率要求
# 调整建议：外贸业务建议95%，国内业务可放宽到80%

brand_consistency: 100         # 默认：100% (不可调整)
# 说明：品牌一致性必须100%满足
# 调整建议：保持100%，这是硬性要求

seo_optimization_target: 85    # 默认：85% (可调整范围：70-95)
# 说明：SEO优化程度的目标分数
# 调整建议：线上业务建议90%，内部使用可放宽到75%
```

### 评分权重配置
```yaml
scoring_weights:
    completeness_weight: 0.25       # 默认：0.25 (可调整范围：0.15-0.40)
    # 说明：数据完整度在总分中的权重
    # 调整建议：制造业可提高到0.30，服务业可降低到0.20

    translation_weight: 0.30         # 默认：0.30 (可调整范围：0.20-0.45)
    # 说明：翻译质量在总分中的权重
    # 调整建议：外贸业务可提高到0.40，国内业务可降低到0.20

    brand_weight: 0.25              # 默认：0.25 (可调整范围：0.15-0.35)
    # 说明：品牌一致性在总分中的权重
    # 调整建议：品牌重要客户可提高到0.35

    seo_weight: 0.20                 # 默认：0.20 (可调整范围：0.10-0.30)
    # 说明：SEO优化在总分中的权重
    # 调整建议：线上业务可提高到0.30，传统业务可降低到0.10
```

## 🚨 质量门禁配置

### 自动通过条件
```yaml
auto_approval_conditions:
    # 同时满足以下条件可自动通过
    conditions:
        overall_score: ">=90分"      # 综合评分
        completeness_score: ">=85%"   # 完整度
        translation_score: ">=90%"    # 翻译质量
        brand_consistency: "100%"     # 品牌一致性
    
    # 满足自动通过条件的文件会直接生成最终报告
    # 不满足的会标记为需要人工复核
```

### 人工复核触发条件
```yaml
manual_review_triggers:
    # 以下情况会触发人工复核
    triggers:
        overall_score: "<85分"       # 综合评分过低
        critical_fields_missing: true # 关键字段缺失
        data_quality_issues: true     # 数据质量问题
        content_concerns: true        # 内容疑虑
```

## 📝 修改说明

### 如何修改参数
1. **直接编辑**：打开此文件，修改对应的数值
2. **保存文件**：保存后参数立即生效
3. **查看效果**：下次处理Excel文件时使用新参数

### 参数修改建议
- **保守调整**：每次只调整1-2个参数，观察效果
- **记录对比**：记录修改前后的处理效果差异
- **逐步优化**：根据实际效果逐步调整到最佳值

### 注意事项
- 修改参数后建议先用测试文件验证效果
- 极端参数值可能导致处理异常，建议在合理范围内调整
- 如不确定参数影响，可咨询技术支持
