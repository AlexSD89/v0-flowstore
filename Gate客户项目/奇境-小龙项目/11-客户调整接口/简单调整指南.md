# 简单调整指南

## 📝 什么文档？

这是我这次学习案例后生成的一套规则、逻辑和流程。您可以直接修改，我下次就会按照您的修改来工作。

## 🎯 我学到了什么？

### 客户修改逻辑
我从您的数据中发现：

**P0级修改（最重要）**
- 设计风格和版式
- 品牌规范（Logo、颜色、字体）
- 合规要求（风险警示、限制用词）

**P1级修改（重要）**
- 体验和转化效果
- CTA按钮清晰度
- 技术可行性

### 数据处理模式
1. **品牌信息收集表**：条目化设计，双语支持
2. **旺铺展示需求**：内容大纲+素材上传
3. **设计迭代流程**：初稿→修改→终稿

### 复杂度判断规则
- **简单任务**（15-30分钟）：单一文件，标准模板
- **复杂任务**（1-2小时）：多文件，定制需求
- **战略任务**（3-6小时）：L级复杂度，需要协调多个系统

## 🔧 您可以调整的地方

### 1. 质量标准（改数字就行）
```yaml
# 当前设置
质量要求:
  视觉质量: 85分
  翻译准确率: 95%
  客户满意度: 95%

# 想更严格就改这里
质量要求:
  视觉质量: 90分
  翻译准确率: 98%
  客户满意度: 98%
```

### 2. 复杂度阈值（改分数就行）
```yaml
# 当前设置
复杂度分类:
  研究型: ≥80分
  设计开发: 60-79分
  质量保障: 40-59分

# 想更严格就改这里
复杂度分类:
  研究型: ≥85分
  设计开发: 65-79分
  质量保障: 45-59分
```

### 3. 行业模板（改重点就行）
```yaml
# 当前优先级
制造业重点:
  - 技术展示
  - 品牌国际化
  - 认证管理

# 想调整优先级就改这里
制造业重点:
  - 品牌国际化
  - 技术展示
  - 认证管理
```

### 4. 处理时间（改时间就行）
```yaml
# 当前时间设置
处理时间:
  Excel分析: 30分钟
  质量检查: 15分钟
  内容生成: 45分钟

# 想更快就改这里
处理时间:
  Excel分析: 20分钟
  质量检查: 10分钟
  内容生成: 30分钟
```

## 📋 具体怎么修改？

### 步骤1：找到要改的部分
- 打开这个文档
- 找到上面对应的YAML代码块

### 步骤2：直接修改数值或文字
- 改数字（比如 85 → 90）
- 改文字（比如"高" → "中"）
- 改时间（比如"30分钟" → "20分钟"）

### 步骤3：保存文档
- 保存修改
- 下次我就会用新配置

## 🎯 修改后会怎样？

- **更严格的质量标准** → 产出质量更高，但可能需要更多时间
- **更快的处理时间** → 速度更快，但可能深度分析不够
- **调整行业重点** → 更符合您的业务需求
- **改变复杂度阈值** → 影响任务分类和资源分配
