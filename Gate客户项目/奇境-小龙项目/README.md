# 奇境-小龙项目 - Gate OS系统

## 🎯 项目概述

**Gate OS**：客户主导的AI自动化系统，客户只需注入认知和逻辑，系统自动封装为技能并持续学习优化。

## 📁 简化项目结构

```

├── 🤖 gate/                       # 自动化逻辑（技术细节）

├── 📤 output/                     # 输出结果
```

## 🚀 核心理念

### 客户主导 + AI执行
- **客户**：提供初始认知、业务逻辑和反馈
- **AI**：自动执行、学习优化、持续改进
- **透明**：完全可视化的执行过程

### Gate OS 5层架构
1. **认知注入层**：客户输入业务认知
2. **技能封装层**：自动生成可执行技能
3. **工作流模板层**：标准化执行流程
4. **模板要求层**：质量保障体系
5. **持续更新层**：学习优化系统

## 📋 技能系统

### 技能特性
- **人类可读**：技能用Markdown编写，客户可直接阅读和理解
- **自动化执行**：技能由gate/automation/自动发现和执行
- **持续学习**：基于每次使用结果优化技能参数

### 核心技能

#### 1. Excel分析技能 (`skills/excel分析技能.md`)
- **业务模式识别**：自动识别B2B2C分层服务模式
- **数据结构分析**：深度理解数据组织和逻辑
- **自动化就绪评估**：评估AI化可行性

#### 2. 设计生成技能 (`skills/设计生成技能.md`)
- **三段式迭代**：初稿→修改→终稿流程
- **渠道差异化**：H5、微报等不同设计要求
- **质量保障**：品牌一致性、合规性检查

#### 3. 质量保障技能 (`skills/质量保障技能.md`)
- **多维度评估**：设计、品牌、用户体验、合规性
- **自动化门禁**：实时质量监控和预警
- **客户可配置**：个性化质量标准和阈值
