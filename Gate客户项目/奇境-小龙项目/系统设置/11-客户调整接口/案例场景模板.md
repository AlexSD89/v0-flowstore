## 🔧 客户修改指南

### 如何修改案例配置

1. **找到对应的案例**：根据您的具体需求匹配最相似的案例
2. **理解当前配置**：查看我识别的模式和执行方案
3. **修改关键参数**：直接修改YAML配置中的数值和选项
4. **保存修改**：保存修改后的案例文档
5. **重新执行**：下次我会按照您的修改执行

### 常见修改类型

#### 调整质量标准
```yaml
# 想要更严格的质量
质量门槛: 85分 → 95分

# 想要更快的处理
处理时间: "3-6小时" → "2-4小时"
```

#### 调整工作重点
```yaml
# 想要优先品牌建设
优先级1: "技术展示" → "品牌国际化"

# 想要强调合规
迭代重点: "合规检查" → "合规与发布"
```

#### 调整输出格式
```yaml
# 想要更详细的报告
输出范围: "基础报告" → "完整报告+实施指南"
```

## 📝 案例模板使用说明

### 为客户创建新案例

1. **收集客户需求**
2. **我自动分析生成案例MD**
3. **客户阅读理解案例配置**
4. **客户修改完善配置**
5. **我按修改后配置执行**

### 案例模板结构

每个案例包含：
- **客户原始需求**：客户的具体要求
- **我的自动化分析**：我识别的模式和业务意图
- **执行方案**：具体的执行计划和时间安排
- **可修改配置**：客户可以调整的参数
- **修改指南**：如何修改和验证效果

---

**这个模板让每个具体案例都有对应的可修改文档，真正做到案例→文档→配置→执行的完整闭环！**
