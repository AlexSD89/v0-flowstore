# 项目分类规则

## Excel文件分类规则
- 文件大小 > 1MB → 复杂项目
- 包含"品牌"关键词 → 品牌分析
- 数据列数 > 20列 → 高复杂度
- 包含"门赢"、"领航会员" → 客户Onboarding项目

## 图片文件分类规则
- 包含"H5" → H5设计审查
- 包含"微报" → 微报设计审查
- 分辨率 > 1920x1080 → 高质量要求
- 包含"风控"、"审核" → 风控审查项目

## 设计稿分类规则
- 文件名包含"初稿" → 设计初稿阶段
- 文件名包含"修改" → 设计修改阶段
- 文件名包含"终稿" → 设计终稿阶段
- 第XX期命名 → 期刊项目管理

## 自动化分类优先级
1. 客户数据文件（Excel、PDF、图片）
2. 设计稿文件（JPG、PNG、PSD）
3. 配置文件（YAML、JSON、MD）
4. 技术文档（API文档、技术方案）

## 分类调整方式
用户可以在系统中调整分类规则，系统会根据历史数据学习和优化分类准确性。
