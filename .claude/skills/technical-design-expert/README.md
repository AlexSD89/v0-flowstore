## 🎯 技能概述

技术设计专家聚焦企业AI化与复杂系统的技术落地，面向功能设计、架构模式、技术栈选型与非功能需求治理，帮助团队在方案层面提前规避技术债与扩展瓶颈。知识来源包含：

- 💻 技术开发/实战经验 —— 典型架构案例与代码规范。
- 🔬 Deep study/技术分析 —— 深度研究与性能优化经验。
- 🏢 Gate-OS —— 企业AI操作系统设计模式。
- 🔟 AI产品化策略 —— 产品级交付与商业化路径。

## 🧱 核心能力

### 技术方案设计
- 输出系统架构分层、模块职责、通信与数据流。
- 明确性能、安全、可观测性等非功能指标。
- 结合项目约束提供多方案对比与评估矩阵。

### 模式与组件指导
- 推荐适配的设计/架构模式并示范代码骨架。
- 定义接口契约、数据模型、跨模块边界。
- 指导自研组件、第三方服务的集成策略。

### AI 产品化支持
- 结合业务场景提出模型选型、训练、部署方案。
- 提供推理成本、MLOps、数据治理建议。
- 与项目架构规划师协同落地执行路线。

## 🚀 快速使用

```bash
# 企业AI平台技术方案
/skill technical-design-expert "为制造业企业搭建AI质检平台的技术方案"

# 设计模式选型
/skill technical-design-expert "评估事件驱动架构在实时数据处理中的适用性"

# 推理性能优化
/skill technical-design-expert "降低大语言模型在生产环境推理的成本并保持SLA"
```

## 📥 输入要点
- 目标业务功能与关键用户路径。
- 约束条件：性能指标、预算、团队能力、合规要求。
- 现有系统或资产：代码仓库、服务接口、部署架构。
- 期望输出：架构图、组件清单、技术选型表、风险分析等。

## 📤 输出格式
- 执行摘要 + 架构概览（文本 + 图示建议）。
- 技术选型评估表（含评估维度、决策理由、替代方案）。
- 模式/组件设计清单 + 接口/数据结构说明。
- 风险与回滚策略 + 与其他技能协作触发点。

## 🤝 协同建议
- **项目架构规划师**：前期统一目录和流程，后续根据方案反馈迭代。
- **商业决策支持专家**：当技术方案影响投入/ROI 时共同评估。
- **知识管理大师**：将设计结果沉淀到知识库并建立索引。
- **深度学习专家**：涉及模型研发与部署时提供专项支持。
