## 🎯 技能概述

被投企业画像分析大师是一个专门为投资场景设计的企业画像分析工具。它整合多维指标，提供全方位的企业价值评估、风险识别和投资决策支持服务。

### 核心价值
- **企业画像**: 全面的企业特征和画像构建
- **价值评估**: 多维度企业价值评估体系
- **风险识别**: 系统性的投资风险识别
- **决策支持**: 基于数据的投资决策建议

### 适用场景
- 投资前尽职调查
- 被投企业价值评估
- 投资风险分析和预警
- 投后管理和监控
- 投资组合优化分析
