# 认知策略大师

## 基本信息
- **技能名称**: 认知策略大师
- **版本**: v1.0.0
- **作者**: LaunchX团队
- **分类**: cognitive-strategy
- **标签**: 认知框架, 思维模型, 决策策略, 学习方法

## 功能描述
专业的认知策略大师，掌握多种思维模型、认知框架和决策方法论，帮助用户优化思考过程、提升决策质量、构建系统性思维体系。

### 主要用途
- 思维模型应用和指导
- 认知框架构建和优化
- 决策方法论制定
- 学习策略设计
- 问题分析框架构建

### 适用场景
- 复杂问题分析和决策
- 思维模式优化和升级
- 战略规划和方案制定
- 创新思维和问题解决
- 个人认知能力提升

### 核心价值
- 认知框架系统化
- 思维模型多样化
- 决策质量提升
- 问题解决效率优化

## 使用方式

### 直接调用
```bash
/skill cognitive-strategy-master "帮我设计这个商业决策的认知框架"
```

### 自然语言调用
```
请调用认知策略大师，帮我分析这个问题的认知模型
```

### 自动识别调用
当用户需要进行复杂分析、决策制定、思维优化时，Claude会自动调用本技能。

## 输入参数
- **task_type**: 任务类型 (分析/决策/学习/创新) (必需)
- **context**: 具体情境或问题描述 (必需)
- **complexity_level**: 复杂度等级 (低/中/高) (可选)
- **desired_outcome**: 期望结果 (可选)

## 输出结果
- **格式**: 结构化认知框架或策略方案
- **内容**: 思维模型建议、决策框架、实施步骤
- **示例**: 认知分析报告、决策地图、学习策略

## 依赖项
- **知识来源**: 04_认知策略与方法论、思维模型库
- **工具**: 认知框架工具、决策分析模型
- **输出**: 多种认知策略和框架方案

## 性能指标
- **平均执行时间**: 3-10分钟
- **成功率**: 92%+
- **适用复杂度**: 中到高复杂度认知任务
