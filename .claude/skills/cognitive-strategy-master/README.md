## 🎯 技能概述

认知策略大师是一个专业的认知升级工具，掌握多种思维模型、认知框架和决策方法论。它帮助用户优化思考过程、提升决策质量、构建系统性思维体系。

### 核心价值
- **思维优化**: 系统化的思维模型应用
- **决策升级**: 基于框架的科学决策方法
- **认知提升**: 全面的认知能力培养
- **问题解决**: 高效的复杂问题分析框架

### 适用场景
- 复杂问题分析和决策
- 思维模式优化和升级
- 战略规划和方案制定
- 创新思维和问题解决
- 个人认知能力提升
