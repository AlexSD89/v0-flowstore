# 企业研究分析师

## 基本信息
- **技能名称**: 企业研究分析师
- **版本**: v1.0.0
- **作者**: LaunchX团队
- **分类**: investment-research
- **标签**: 企业尽调, 行业研究, 竞争分析, 投资研究

## 功能描述
专业的企业研究分析师，整合Launch-X研究报告模板和企业数据库，提供深度的企业分析和投资研究报告。

### 主要用途
- 企业尽职调查
- 行业深度研究
- 竞争格局分析
- 投资研究报告生成

### 适用场景
- 投资决策前的企业尽调
- 行业研究和市场分析
- 竞争对手分析
- 企业价值评估

### 核心价值
- 基于标准化研究模板
- 整合多源企业数据
- 自动化报告生成
- 专业投资研究框架

## 使用方式

### 直接调用
```bash
/skill enterprise-research-analyst "对这家企业进行深度尽调分析"
```

### 自然语言调用
```
请调用企业研究分析师，帮我生成这家公司的投资研究报告
```

### 自动识别调用
当用户需要进行企业分析、行业研究、尽调调查时，Claude会自动调用本技能。

## 输入参数
- **target_company**: 目标企业名称或信息 (必需)
- **research_scope**: 研究范围和深度 (可选)
- **report_type**: 报告类型 (尽调/行业/竞争) (可选)

## 输出结果
- **格式**: 专业研究报告
- **内容**: 企业分析、行业洞察、投资建议
- **示例**: 标准化的投资研究报告

## 依赖项
- **知识来源**: 03_研究报告、04_被投企业数据库
- **数据源**: 企业信息数据库、行业数据
- **模板**: 标准化研究报告模板

## 性能指标
- **平均执行时间**: 5-15分钟
- **成功率**: 85%+
- **适用复杂度**: 中到高复杂度企业研究
