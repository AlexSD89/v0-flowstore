# README.md · LaunchX Skills生态系统配置管理

> **核心理念**：Skills系统是LaunchX三位一体架构(Claude + Skills + Hooks)的专业能力执行单元，负责标准化业务操作和专业能力的自动化激活。

---

## 🎯 Skills系统架构概述

### 设计原则
1. **专业能力模块化**：每个Skill对应一个专业领域，具备独立的分析和执行能力
2. **自动激活机制**：基于skill-rules.json的三层检测引擎实现智能技能匹配
3. **Token效率优化**：通过渐进式披露和智能选择实现40-60%的性能提升
4. **配置一致性管理**：本地开发验证 → 系统根目录同步，保持双目录一致性

### 系统架构
```
Skills生态系统 (12个专业技能)
├── 业务分析域 (3个技能)
│   ├── business-decision-support - 商业决策支持
│   ├── enterprise-research-analyst - 企业研究分析师
│   └── invested-enterprise-portrait-master - 投资企业画像大师
├── 技术实现域 (5个技能)
│   ├── project-architect - 项目架构师
│   ├── technical-design-expert - 技术设计专家
│   ├── deep-learning-expert - 深度学习专家
│   ├── git-collaboration-expert - Git协作专家
│   └── codex - Codex集成专家
├── 认知策略域 (2个技能)
│   ├── cognitive-strategy-master - 认知策略大师
│   └── knowledge-master - 知识管理大师
├── 市场情报域 (1个技能)
│   └── market-intelligence-expert - 市场情报专家
└── 企业级平台域 (1个技能)
    └── gate-os-enterprise-expert - Gate-OS企业专家
```

## ⚙️ 自动激活机制

### 三层检测引擎
1. **关键词匹配** (权重: 0.3)
   - 用户输入中的关键词识别
   - 预定义的关键词-技能映射

2. **文件路径分析** (权重: 0.4)
   - 当前工作目录和文件类型分析
   - 项目特征识别

3. **内容模式识别** (权重: 0.3)
   - 文档内容分析和模式匹配
   - 任务复杂度评估

### 激活流程
```javascript
// 技能激活流程示例
用户输入 → 关键词提取 → 文件路径分析 → 内容模式识别
    ↓
技能匹配评分 → 排序和选择 → 自动激活最优技能组合
    ↓
Token效率优化 → 渐进式披露 → 执行结果返回
```

### 性能优化指标
- **激活准确率**: ≥95%
- **Token效率提升**: 40-60%
- **响应时间**: <3秒
- **技能覆盖率**: 8大业务域100%覆盖

## 📊 配置管理最佳实践

### 开发工作流
1. **本地开发**: 在本地目录开发新技能或优化现有技能
2. **功能验证**: 测试新技能的稳定性和准确性
3. **价值评估**: 评估技能的实际价值和适用场景
4. **系统同步**: 确认价值后同步到系统根目录
5. **质量检查**: 确保符合LaunchX标准

### 版本管理策略
- **功能优先**: 确保两个目录都有相同的核心功能
- **实现差异**: 允许不同的实现方式作为技术探索
- **版本记录**: 记录每个版本的功能差异和适用场景
- **回滚机制**: 保持多版本备份，支持快速回滚

### 质量保障机制
- **一致性检查**: 定期验证两个目录的配置一致性
- **功能测试**: 确保所有技能的核心功能正常工作
- **性能监控**: 监控技能激活的性能指标
- **用户反馈**: 收集使用反馈指导优化

## 🚨 配置变更管理

### 变更流程
1. **需求分析**: 明确变更需求和目标
2. **本地实施**: 在本地目录进行变更实施
3. **功能验证**: 验证变更的稳定性和价值
4. **系统同步**: 将验证通过的变更同步到系统根目录
5. **文档更新**: 更新相关文档和配置说明
6. **质量验证**: 执行完整的质量检查流程

### 风险控制
- **备份策略**: 重要变更前创建完整备份
- **测试验证**: 本地充分测试后再系统同步
- **回滚机制**: 准备快速回滚到稳定版本
- **变更记录**: 详细记录配置变更历史和原因
