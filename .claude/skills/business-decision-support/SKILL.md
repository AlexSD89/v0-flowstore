# 商业决策支持专家

## 基本信息
- **技能名称**: 商业决策支持专家
- **版本**: v1.0.0
- **作者**: LaunchX团队
- **分类**: business-intelligence
- **标签**: 商业分析, 投资决策, ROI评估, 风险分析

## 功能描述
专业的商业决策支持专家，基于Launch-X投资分析框架，提供深度的项目价值评估、企业画像分析和投资决策支持。整合企业尽调、财务分析和风险评估能力。

### 主要用途
- 投资项目价值评估和ROI计算
- 企业画像分析和尽调支持
- 商业决策支持分析
- 风险评估和缓解建议
- 投资组合优化建议

### 适用场景
- AI项目投资决策
- 初创企业价值评估
- 企业战略制定
- 产品商业价值分析
- 市场机会评估

### 核心价值
- 整合多维度数据分析
- 基于标准化方法论
- 提供量化决策依据
- 专业风险评估框架

## 使用方式

### 直接调用
```bash
/skill business-decision-support "分析这个AI项目的投资价值"
```

### 自然语言调用
```
请调用商业决策支持专家，帮我评估这个商业机会
```

### 自动识别调用
当用户询问投资分析、商业建议、ROI评估等问题时，Claude会自动调用本技能。

## 输入参数
- **query**: 商业分析或投资决策问题 (必需)
- **data_source**: 数据来源或分析范围 (可选)
- **analysis_depth**: 分析深度 (标准/深度) (可选)

## 输出结果
- **格式**: 结构化分析报告
- **内容**: 价值评估、风险分析、决策建议
- **示例**: 专业的投资分析报告

## 依赖项
- **知识来源**: 02_分析与洞察、05_方法论中心、c_AI投资研究
- **分析工具**: 数据分析框架、评估模型
- **决策模板**: ROI计算、风险评估模板

## 性能指标
- **平均执行时间**: 3-8分钟
- **成功率**: 90%+
- **适用复杂度**: 中到高复杂度商业分析
