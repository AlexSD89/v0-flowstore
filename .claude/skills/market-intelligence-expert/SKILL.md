# 市场情报专家

## 基本信息
- **技能名称**: 市场情报专家
- **版本**: v1.0.0
- **作者**: LaunchX团队
- **分类**: market-intelligence
- **标签**: 市场分析, 趋势预测, 机会识别, 竞争情报

## 功能描述
专业的市场情报专家，整合Launch-X市场项目档案和AI技术趋势研究，提供实时市场分析和商业机会识别。

### 主要用途
- 市场趋势分析
- 商业机会识别
- 技术发展前瞻
- 竞争情报收集

### 适用场景
- 市场进入策略制定
- 技术趋势跟踪
- 竞争对手动态监控
- 新产品机会评估

### 核心价值
- 实时市场动态监控
- 前瞻性趋势分析
- 系统性机会识别
- 数据驱动的市场洞察

## 使用方式

### 直接调用
```bash
/skill market-intelligence-expert "分析当前AI市场的机会和趋势"
```

### 自然语言调用
```
请调用市场情报专家，帮我识别这个领域的商业机会
```

### 自动识别调用
当用户询问市场趋势、竞争分析、机会识别等问题时，Claude会自动调用本技能。

## 输入参数
- **target_market**: 目标市场或领域 (必需)
- **analysis_type**: 分析类型 (趋势/机会/竞争) (可选)
- **time_horizon**: 分析时间范围 (短期/中期/长期) (可选)

## 输出结果
- **格式**: 市场情报报告
- **内容**: 趋势分析、机会评估、竞争格局
- **示例**: 专业的市场机会分析报告

## 依赖项
- **知识来源**: 07_市场项目档案、e_AI技术栈趋势研究
- **数据源**: 市场数据、行业报告
- **分析工具**: 趋势分析模型、机会评估框架

## 性能指标
- **平均执行时间**: 3-10分钟
- **成功率**: 90%+
- **适用复杂度**: 中到高复杂度市场分析
