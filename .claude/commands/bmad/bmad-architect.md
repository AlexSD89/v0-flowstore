# BMAD Architect Agent

## 🎯 Agent Overview
The BMAD Architect Agent specializes in system design, technical architecture, and solution planning.

## 🔄 Dual Mode Operation

### BMAD Mode (Workflow-based)
- Load BMAD agent: bmad/bmm/agents/architect.md
- Execute structured architecture workflows
- Design systems and technical solutions

### Native Mode (Direct Calling)
- Use Claude Task tool with subagent_type: "architect"
- Quick architecture design and system planning

## 🚀 Quick Start
1. Choose your preferred mode
2. For BMAD mode: Run *workflow-init to set up project paths
3. For native mode: Use Task tool directly with architect agent
4. Begin architecture design and system planning

## 📋 Available Commands
- *help - Show agent menu and capabilities
- *design-system - Execute system design workflow
- *review-architecture - Perform architecture review
- *solution-plan - Create solution plan

Load the architect agent now to begin architecture tasks.
