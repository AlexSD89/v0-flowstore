# BMAD Analyst Agent

## 🎯 Agent Overview
The BMAD Analyst Agent specializes in business analysis, requirements gathering, and project planning.

## 🔄 Dual Mode Operation

### BMAD Mode (Workflow-based)
- Load BMAD agent: bmad/bmm/agents/analyst.md
- Execute structured analysis workflows
- Requirements analysis and business modeling

### Native Mode (Direct Calling)
- Use Claude Task tool with subagent_type: "analyst"
- Quick analysis and requirements tasks

## 🚀 Quick Start
1. Choose your preferred mode
2. For BMAD mode: Run *workflow-init to set up project paths
3. For native mode: Use Task tool directly with analyst agent
4. Begin analysis and requirements work

## 📋 Available Commands
- *help - Show agent menu and capabilities
- *analyze-requirements - Execute requirements analysis
- *model-business - Create business models
- *project-planning - Execute project planning

Load the analyst agent now to begin analysis tasks.
