# BMAD Master Control

## 🎯 BMAD System Overview
BMAD (Build-Monitor-Auto-Deploy) is a comprehensive agentic development system with dual-mode operation support.

## 🚀 Available Agents

### Development & Engineering
- **/bmad-dev** - Development agent for implementation tasks
- **/bmad-architect** - Architecture agent for system design
- **/bmad-analyst** - Business analyst for requirements and planning

### Management & Process
- **/bmad-pm** - Project management
- **/bmad-sm** - Scrum master for agile processes
- **/bmad-tea** - Technical evangelist and architect

### Creative & Innovation
- **/bmad-storyteller** - Creative storytelling
- **/bmad-innovation** - Innovation strategy
- **/bmad-design-thinking** - Design thinking coach

## 🔄 Dual Mode Operation

### BMAD Mode (Structured Workflows)
- Load agents through BMAD workflow system
- Follow structured processes and menus
- Use commands like *workflow-init, *develop-story

### Native Mode (Direct Calling)
- Use Claude Task tool with subagent_type
- Quick tasks and flexible workflows
- Direct agent invocation

## 📋 Quick Start
1. Choose an agent from the list above
2. Use the corresponding slash command (e.g., /bmad-dev)
3. Follow the agent-specific instructions
4. Choose between BMAD workflow mode or native calling mode

## 🛠️ System Configuration
- **IDE**: Claude Code (pre-configured)
- **Mode**: Dual-mode support enabled
- **Location**: ./bmad/ directory
- **Version**: BMAD Method v6.0
