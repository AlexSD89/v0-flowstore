## 🎯 技能概述

LaunchX Codex Execution Skill 是 Claude Code 与 Codex CLI 的安全集成接口。该技能确保命令审批、最小权限与验证闭环，严格遵循 LaunchX 的 `Collect → Align → Deliver → Archive` 流程。

### 核心价值
- **安全执行**: 通过 Guardrails 确保命令执行安全
- **审批机制**: 多层审批和权限控制
- **沙箱隔离**: 最小权限原则的沙箱执行
- **审计追踪**: 完整的执行日志和审计记录

### 适用场景
- 需要外部AI模型辅助的代码生成
- 复杂技术问题的分析和解决
- 大规模代码重构和优化
- AI辅助的系统设计和架构
