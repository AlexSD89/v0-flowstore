# 知识管理大师

## 基本信息
- **技能名称**: 知识管理大师
- **版本**: v1.0.0
- **作者**: LaunchX团队
- **分类**: knowledge-management
- **标签**: 知识整理, 内容创作, 自动化报告, 信息管理

## 功能描述
专业的知识管理大师，整合Launch-X知识传播体系和运营管理机制，提供智能化的知识整理和内容创作服务。

### 主要用途
- 知识内容智能整理
- 周报月报自动生成
- 品牌内容创作支持
- 信息管理和优化

### 适用场景
- 定期报告撰写和自动化
- 知识库内容整理和优化
- 品牌内容创作和发布
- 信息收集和分类管理

### 核心价值
- 知识管理自动化
- 内容创作效率提升
- 信息结构化整理
- 知识价值最大化

## 使用方式

### 直接调用
```bash
/skill knowledge-master "帮我整理这个月的知识内容并生成报告"
```

### 自然语言调用
```
请调用知识管理大师，帮我创作品牌宣传内容
```

### 自动识别调用
当用户需要内容创作、知识整理、报告生成时，Claude会自动调用本技能。

## 输入参数
- **content_type**: 内容类型 (报告/整理/创作) (必需)
- **time_range**: 时间范围或周期 (可选)
- **target_audience**: 目标受众 (可选)

## 输出结果
- **格式**: 结构化内容或报告
- **内容**: 整理后的知识、创作的内容、生成的报告
- **示例**: 月度知识报告、品牌宣传文案

## 依赖项
- **知识来源**: 08_知识传播与品牌、09_周报月报、01_Inbox
- **工具**: 内容模板、报告格式、分类体系
- **输出**: 多格式内容生成能力

## 性能指标
- **平均执行时间**: 2-8分钟
- **成功率**: 95%+
- **适用复杂度**: 中到高复杂度知识管理
