## 🎯 技能概述

知识管理大师聚焦 Launch-X 知识资产的采集、整理、生成与归档，内建“判断 → 趋势 → 结论”闭环，帮助团队在 24 小时内完成知识沉淀与回写。技能驱动来源覆盖：

- 🟣 knowledge/08_知识传播与品牌 —— 品牌叙事与内容风格。
- 🟣 knowledge/09_周报月报 —— 周期性报告模版与指标。
- 🟣 knowledge/01_Inbox —— 原始素材快速分类与清洗。
- `🟣 knowledge/07_市场项目档案/综合分析/20251024-品牌传播型_vs_开发者大会案例对照.md` —— 双类型事件案例基线，支撑多场景内容复用。

## 🔧 核心能力

### 知识资产整理
- 自动分类 + 标签映射，输出结构化目录。
- 重复/过期内容检测与归档建议。
- 知识图谱节点补全与关联提示。

### 高效内容生成
- 周报/月报、复盘、知识脉络摘要一键输出。
- 面向不同受众（内部、外部）的语气与格式调优。
- 引用回链与出处标注自动化。

### 运营支持
- 支持多渠道分发规划（站内、Newsletter、社媒）。
- 提供内容复用与组合策略建议。
- 输出后续行动清单与维护节奏。

## 🚀 快速使用

```bash
# 整理 Inbox，生成周报初稿
/skill knowledge-master "整理本周Inbox内容并输出结构化周报"

# 生成外发内容指南
/skill knowledge-master "为Launch-X十月内容运营制定多渠道发布计划"

# 创建知识图谱索引
/skill knowledge-master "梳理AI投资方法论相关文档并输出知识图谱节点"
```

## 📥 输入要点
- 明确内容来源：提供目录、标签或具体文档列表。
- 设定输出格式：报告/清单/图谱等结构需求。
- 标注目标受众：内部运营/对外传播/管理层复盘。
- 指定时效约束：明确数据统计区间与归档期限。

## 📤 输出格式
- 执行摘要 + 结构化正文（含引用与回链）。
- TODO/Next Step 列表，包含负责人与截止时间。
- 更新 `related` 字段所需的引用清单建议。
- 视需求同步生成 frontmatter 草案。

## 🤝 协同建议
- **与商业决策支持专家**：提供企业档案与关键洞察，反哺知识库。
- **与项目架构规划师**：统一文件夹规范与命名策略。
- **与技术设计专家**：在技术方案落地后同步知识库回写。

## 🔄 回滚策略
- 所有自动生成内容先写入 `🤖 AI生成 auto-generated/YYYYMMDD/`。
- 发现质量问题时使用 `history/` 中的快照恢复，并记录在测试计划回归表。
- 重大结构调整需提前在 `plans/` 中提报审批。
