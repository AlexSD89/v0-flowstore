# 设计稿智能分析技能

> **技能等级**: Level M
> **核心能力**: 设计稿深度分析、版本对比、质量评估、优化建议

## 🎯 技能概述

### 技能定位
基于AI视觉分析技术，为设计稿提供智能化的质量分析、版本对比和优化建议，特别适用于产品详情页、商家PC页面等专业设计场景。

### 核心能力矩阵
```
🔍 视觉分析能力    | 📊 质量评估能力    | 🔄 对比分析能力    | 💡 智能建议能力
构图平衡识别        | 设计规范检查        | 版本差异检测        | 具体改进方案
色彩和谐分析        | 品牌一致性验证      | 变化趋势分析        | 最佳实践推荐
字体排版评估        | 可访问性测试        | 优化方向建议        | 创新机会识别
```

## 📊 分析维度详解

### 1. 视觉构图分析
```yaml
黄金比例分析:
  检测点:
    - 主体区域是否在黄金分割点
    - 整体比例是否接近1:1.618
    - 空间分布是否协调
  评分标准:
    - 完全符合: 9-10分
    - 基本符合: 7-8分
    - 部分符合: 5-6分
    - 不符合: 1-4分

三分法分析:
  检测点:
    - 重要元素是否在交叉点上
    - 水平线是否在1/3或2/3处
    - 视觉流动是否顺畅
  评估维度:
    - 构图稳定性
    - 视觉引导性
    - 动态平衡感
```

### 2. 色彩和谐分析
```yaml
色彩搭配评估:
  和谐模式识别:
    - 类似色和谐
    - 互补色和谐
    - 三色和谐
    - 四色和谐
  情绪表达:
    - 色彩情绪对应
    - 品牌调性匹配
    - 目标用户适配
  技术指标:
    - 对比度WCAG AA: ≥4.5:1
    - 对比度WCAG AAA: ≥7:0:1
    - 色盲友好性
```

### 3. 字体排版分析
```yaml
层级结构:
  标题层级:
    - H1: 2.5rem, 700 weight
    - H2: 2rem, 600 weight
    - H3: 1.5rem, 500 weight
    - Body: 1rem, 400 weight
  间距规范:
    - 行高: 字体大小的1.4-1.6倍
    - 字间距: 根据字体大小调整
    - 段落间距: 1.5-2倍行高
  可读性指标:
    - 行长: 45-75字符
    - 字体大小: 最小14px
    - 背景对比度: 符合WCAG标准
```

### 4. 品牌一致性分析
```yaml
品牌VI检查:
  色彩使用:
    - 主色彩应用正确性
    - 辅助色彩搭配合理性
    - 色彩使用范围合规性
  字体规范:
    - 品牌字体使用正确
    - 字体层级符合规范
    - 特殊字体应用恰当
  视觉元素:
    - Logo使用规范
    - 图标风格一致性
    - 整体调性统一
```
