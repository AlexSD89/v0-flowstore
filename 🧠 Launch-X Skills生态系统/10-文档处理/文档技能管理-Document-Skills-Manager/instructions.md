# document-skills 使用说明（面向 Claude）

本文件说明 **Claude 如何使用 document-skills 来协调各类文档技能**。

## 1. 触发条件

在以下情况优先考虑调用本技能：

- 用户需求涉及多种文档格式（Word / PDF / PPT / Excel 任意组合）；
- 用户只描述了“报告/表格/演示文稿”，但未明确文件类型；
- 用户希望将数据流转成一整套文档（如：数据 → 报告 → 演示）；
- 用户提到“批量处理/归档/汇总多份文档”等复杂场景。

若用户明确指定了某一具体技能且任务简单，可直接调用对应单一技能。

## 2. 使用步骤

1. **分析用户需求**  
   - 提取目标（阅读 / 编辑 / 汇总 / 转换 / 对比等）。  
   - 列出涉及的文件及其格式（若不清楚则先追问或做合理假设）。

2. **匹配底层技能**  
   - 将每种文档类型映射到对应技能：`docx` / `pdf` / `pptx` / `xlsx`。  
   - 参考 `SKILL.md` 中的“技能路由表”。

3. **设计编排流程**  
   - 按步骤列出端到端工作流，并在每步中说明：
     - 使用哪个技能；
     - 需要的输入（文件名/内容类型）；
     - 预期输出形式。

4. **生成回答**  
   - 用自然语言解释整体工作流；
   - 明确指出在哪些步骤需要调用哪些技能；
   - 对潜在风险（如覆盖原文件、批量删除等）给出提示。

## 3. 与其他技能的接口约定

- 对于每个底层技能，保持“指挥层”语气：
  - 使用表达如“此处应使用 `pdf` 技能抽取表格数据”，而不是重写其内部实现。
- 若需要结合 LaunchX Dev Docs 模板生成项目文档：
  - 在步骤中引用对应模板路径（见 `SKILL.md` 的集成小节）。
- 如需调用 MCP/bmad/Agent：
  - 在回答中以 `TODO｜待 Claude 调用 ...` 的形式标注，不在本技能内直接执行自动化。

## 4. 输出格式建议

- 优先采用“分步 + 小节”的结构：
  - 第一部分：整体方案概览；
  - 第二部分：详细步骤（含技能路由）；
  - 第三部分：风险提示与后续可扩展方向。
- 对多文件/多格式任务，可附一个简单表格，总结每个文件的处理方式。
