# 被投企业画像分析大师

## 基本信息
- **技能名称**: 被投企业画像分析大师
- **版本**: v1.0.0
- **作者**: LaunchX团队
- **分类**: enterprise-portrait
- **标签**: 企业画像、投资分析、尽职调查、价值评估

## 功能描述
专业的被投企业画像分析大师，整合企业多维数据分析能力，帮助投资方全面了解被投企业的综合状况、发展潜力和投资价值。

### 主要用途
- 企业综合画像构建和分析
- 多维度企业竞争力评估
- 投资价值和风险分析
- 企业发展潜力预测
- 投资决策支持报告生成

### 适用场景
- 风险投资决策分析
- 并购收购目标企业评估
- 竞争对手深度分析
- 行业龙头企业研究
- 新兴企业投资机会挖掘

### 核心价值
- 企业画像系统化构建
- 多维度综合分析能力
- 投资价值科学评估
- 风险识别和预警
- 投资决策质量提升

## 使用方式

### 直接调用
```bash
/skill invested-enterprise-portrait-master "全面分析这家被投企业的投资价值"
```

### 自然语言调用
```
请调用被投企业画像分析大师，帮我评估这家科技初创企业的投资潜力
```

### 自动识别调用
当用户需要进行企业投资分析、竞争对手研究、尽职调查时，Claude会自动调用本技能。

## 输入参数
- **analysis_type**: 分析类型 (全面/快速/专项) (必需)
- **company_info**: 企业基本信息 (必需)
- **analysis_depth**: 分析深度 (基础/深入/全面) (可选)
- **industry_context**: 行业背景信息 (可选)
- **investment_focus**: 投资关注点 (技术/市场/团队/财务) (可选)

## 输出结果
- **格式**: 结构化企业画像分析报告
- **内容**: 企业综合评估、投资价值分析、风险评估、发展预测
- **示例**: 企业画像报告、投资决策建议、风险预警报告

## 依赖项
- **知识来源**: 05_方法论中心/被投企业画像方法论、06_投资研究案例库
- **工具**: 企业分析模型、价值评估框架、风险评估工具
- **输出**: 多格式企业画像和投资分析报告

## 性能指标
- **平均执行时间**: 5-15分钟
- **成功率**: 90%+
- **适用复杂度**: 中到高复杂度企业分析
