## 数据文件说明

### investment-analysis-config.json
商业决策分析的核心配置文件，包含：

#### 评估标准配置
- **权重分配**: 市场潜力(25%) + 团队质量(20%) + 技术优势(20%) + 商业模式(15%) + 财务指标(20%)
- **评分阈值**: 优秀(90+)、良好(80+)、一般(70+)、低于平均(60+)

#### 风险评估配置
- **风险类别**: 市场、技术、财务、运营、监管、团队风险
- **风险等级**: 5个等级，从低到高，对应不同颜色编码

#### 投资阶段基准
- **种子轮**: 50-200万投资，10-20%股权，500-2000万估值
- **Pre-A轮**: 200-1000万投资，5-15%股权，2000万-1亿估值
- **A轮**: 1000-5000万投资，3-10%股权，1-5亿估值
- **B轮**: 5000万-2亿投资，2-8%股权，5-20亿估值

## 模板文件说明

### investment-analysis-report.md
标准投资分析报告模板，采用8段式结构：

1. **执行摘要**: 项目概览和核心发现
2. **项目基础分析**: 基本信息、商业模式、团队背景
3. **市场分析**: 市场规模、竞争分析、市场机会
4. **技术评估**: 技术优势、壁垒、风险
5. **财务分析**: 收入模型、成本结构、盈利能力、投资指标
6. **风险分析**: 风险矩阵、主要风险、风险等级
7. **投资建议**: 投资评级、方案、成功因素、关注要点
8. **投后管理**: 监控指标、里程碑计划、增值服务

#### 模板变量
- `{{project_name}}`: 项目名称
- `{{overall_score}}`: 综合评分
- `{{investment_grade}}`: 投资等级
- `{{generation_time}}`: 生成时间
- `{{version}}`: 报告版本

```json
    "weights": {
      "market_potential": 0.30,
      "team_quality": 0.25,
      "technology_advantage": 0.25,
      "business_model": 0.20

  }

```

## 分析方法论

### Launch-X投资分析方法论
基于Launch-X验证的6步投资分析流程：

1. **项目筛选**: 基于基础条件的快速筛选
2. **深度分析**: 多维度深入评估
3. **风险识别**: 全面风险识别和评估
4. **价值评估**: 综合价值量化分析
5. **投资建议**: 基于数据的投资建议
6. **持续监控**: 投后跟踪和动态调整

### 评分模型
- **加权评分**: 基于权重的综合评分模型
- **动态调整**: 根据行业和阶段动态调整权重
- **基准对比**: 与行业基准进行对比分析
- **趋势分析**: 基于历史数据的趋势预测

### 风险评估框架
- **多维度风险**: 市场、技术、财务、运营、监管、团队
- **风险量化**: 基于概率和影响的风险量化
- **风险缓释**: 针对性风险缓释策略
- **风险监控**: 持续风险监控和预警

## 故障排除

### 常见问题

#### 问题1: 数据源连接失败
**解决方案**:
1. 检查数据源API密钥配置
2. 验证网络连接状态
3. 确认数据源API权限
4. 尝试备用数据源

#### 问题2: 分析结果异常
**解决方案**:
1. 检查输入数据格式和完整性
2. 验证配置文件参数设置
3. 查看分析日志定位问题
4. 使用示例数据对比验证

#### 问题3: 评分模型偏差
**解决方案**:
1. 检查权重分配合理性
2. 验证基准数据准确性
3. 调整评分模型参数
4. 进行模型回测验证

#### 问题4: 报告生成失败
**解决方案**:
1. 检查模板文件完整性
2. 验证数据变量替换
3. 确认输出目录权限
4. 查看详细错误日志
