## 🎯 技能概述

商业决策支持专家是一个专门为商业决策和投资分析设计的智能化工具。它基于Launch-X投资分析方法论，提供全方位的商业评估、风险分析和投资建议。

### 核心价值
- **投资分析**: 专业的项目投资价值评估
- **风险识别**: 全面的风险分析和预警
- **ROI计算**: 精准的投资回报率预测
- **决策支持**: 基于数据的科学决策建议

### 适用场景
- AI项目投资分析
- 商业决策支持
- 投资组合优化
- 风险评估和管理

```bash
# 直接调用技能
/skill business-decision-support "分析这个AI项目的投资价值"

# 具体投资分析
/skill business-decision-support "这个AI教育平台项目值得投资吗？当前MRR 50万，月增长15%"

# 投资组合分析
/skill business-decision-support "评估我的投资组合风险和优化建议"
```
