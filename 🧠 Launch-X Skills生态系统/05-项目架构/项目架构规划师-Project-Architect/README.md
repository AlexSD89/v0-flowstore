> **版本**: v1.0.0

## 🎯 技能概述

项目架构规划师面向 Launch-X 的技术与业务团队，提供从项目立项、架构选型到协作流程的全链路规划。技能以 study/ 项目规划资产和 💻 技术开发经验为核心背书，确保方案既符合工程实践又兼顾战略落地。

## 🧱 核心能力

### 架构蓝图设计
- 输出项目整体结构、模块边界与依赖关系。
- 提供技术栈选择与替代方案对比。
- 分析性能、安全、合规等非功能需求。

### 开发协同规范
- 建立分支、代码评审、CI/CD 的操作准则。
- 配置环境区分（dev/staging/prod）与发布节奏。
- 提供日志、监控、告警的基线设置。

### 路线规划与风险控制
- 拆解里程碑与资源需求。
- 列出关键风险及回滚策略。
- 给出与其他技能协同的触发点。

## 🚀 快速使用

```bash
# 新项目初始化架构
/skill project-architect "为AI客服SaaS项目设计文件夹结构与开发规范"

# 重构规划
/skill project-architect "评估现有数据平台架构并给出重构路线图"

# 协作流程设计
/skill project-architect "制定Launch-X自动化实验室的CI/CD流程草案"
```

## 📥 输入要点
- 项目目标、范围与关键里程碑。
- 现有技术栈或既有资产（如 monorepo、微服务）。
- 团队规模、角色分工与协同工具。
- 性能、合规、预算等约束条件。

## 📤 输出格式
- 架构概览（文本 + 可视化建议 + 目录草案）。
- 技术选型清单，含优缺点与评估指标。
- 开发流程与责任矩阵（RACI / Checklist）。
- 风险与回滚策略说明。

## 🤝 协同建议
- **技术设计专家**：在架构方案敲定后进入具体技术设计与实现级别的补充。
- **知识管理大师**：将架构文档归档并同步到知识库索引。
- **商业决策支持专家**：当架构决策影响成本或业务路线时，协作评估商业影响。

## 🔄 回滚策略
- 重大架构调整先在 `plans/` 提报评审，再更新技能内容。
- 生成文档统一落地 `🤖 AI生成 auto-generated/YYYYMMDD/`，复核后再归档。
- 必要时引用 `resources/rollback/` 中的历史架构基线进行恢复。
