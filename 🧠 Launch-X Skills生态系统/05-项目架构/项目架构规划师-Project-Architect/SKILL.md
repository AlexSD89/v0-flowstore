# Project Architect

Comprehensive project architecture specialist for designing development structures and establishing architectural baselines.

## Workflow Decision Tree

### New Project Setup
Use "Project Structure Design" workflow below

### Architecture Design
Use "System Architecture" workflow

### Workflow Planning
Use "Development Process" workflow

### Best Practices Implementation
Use "Standards Establishment" workflow

## Project Structure Design

### Directory Architecture
1. **Source Code Organization**: Module structure, package organization, component hierarchy
2. **Configuration Management**: Environment configs, build configurations, deployment scripts
3. **Documentation Structure**: API documentation, user guides, technical specifications
4. **Testing Architecture**: Unit tests, integration tests, end-to-end tests

### Technology Stack Planning
- **Frontend Architecture**: Framework selection, component library, state management, build tools
- **Backend Architecture**: Service design, database selection, API patterns, security layers
- **Infrastructure Architecture**: Cloud services, containerization, CI/CD pipelines, monitoring systems
- **DevOps Integration**: Version control, automated testing, deployment strategies

### Team Collaboration Framework
- **Code Organization**: Module boundaries, interface definitions, dependency management
- **Development Standards**: Coding conventions, documentation requirements, quality gates
- **Review Processes**: Code review guidelines, testing requirements, approval workflows
- **Communication Protocols**: Project status updates, decision documentation, issue tracking

## System Architecture

### Architecture Patterns
1. **Layered Architecture**: Presentation, business logic, data access, infrastructure layers
2. **Microservices Design**: Service boundaries, communication patterns, data consistency
3. **Event-Driven Architecture**: Event sourcing, message queues, event orchestration
4. **Domain-Driven Design**: Bounded contexts, aggregates, domain services

### Design Principles
- **Separation of Concerns**: Clear module boundaries, single responsibility, dependency inversion
- **Scalability Design**: Horizontal scaling, load balancing, caching strategies
- **Security Architecture**: Authentication, authorization, data encryption, threat modeling
- **Performance Optimization**: Response time optimization, resource utilization, database tuning

### Integration Patterns
- **API Design**: RESTful principles, GraphQL alternatives, versioning strategies
- **Data Integration**: Database design, data transformation, ETL processes
- **Service Integration**: Service mesh, API gateways, circuit breakers
- **Third-party Integration**: External API management, rate limiting, error handling

### Deployment Architecture
- **Container Strategy**: Docker containers, orchestration platforms, image management
- **Cloud Architecture**: Multi-cloud strategy, service selection, cost optimization
- **Monitoring and Observability**: Application monitoring, log aggregation, distributed tracing
- **Disaster Recovery**: Backup strategies, failover mechanisms, data replication

## Development Process

### Development Lifecycle
1. **Requirements Analysis**: Feature specification, acceptance criteria, technical constraints
2. **Design Phase**: Architecture decisions, interface definitions, component design
3. **Implementation**: Development sprints, code reviews, continuous integration
4. **Testing Phase**: Unit testing, integration testing, acceptance testing
5. **Deployment**: Release management, rollback procedures, post-deployment monitoring

### Quality Assurance
- **Code Quality**: Static analysis, code coverage, security scanning
- **Testing Strategy**: Test automation, test environments, test data management
- **Performance Testing**: Load testing, stress testing, capacity planning
- **Security Testing**: Vulnerability scanning, penetration testing, security audits

### Project Management
- **Agile Practices**: Sprint planning, backlog management, velocity tracking
- **Risk Management**: Risk identification, mitigation strategies, contingency planning
- **Resource Planning**: Team allocation, skill requirements, timeline estimation
- **Stakeholder Communication**: Progress reporting, requirement changes, feedback collection

## Standards Establishment

### Coding Standards
- **Language-Specific Guidelines**: Naming conventions, code organization, documentation practices
- **Design Patterns**: Standard patterns usage, anti-patterns avoidance, best practices
- **Security Standards**: Secure coding practices, vulnerability prevention, data protection
- **Performance Standards**: Optimization guidelines, resource management, scalability requirements

### Documentation Standards
- **Code Documentation**: Inline comments, API documentation, architecture diagrams
- **Process Documentation**: Development workflows, deployment procedures, troubleshooting guides
- **User Documentation**: Installation guides, user manuals, training materials
- **Maintenance Documentation**: Change logs, update procedures, support information

### Testing Standards
- **Test Coverage**: Minimum coverage requirements, critical path testing, edge case handling
- **Test Organization**: Test structure, test data management, test environment setup
- **Automation Standards**: CI/CD integration, test scheduling, result reporting
- **Quality Metrics**: Defect density, test execution rates, release quality gates

## Implementation Guidelines

### Tool Selection
- **Development Tools**: IDE configuration, version control, build automation
- **Testing Tools**: Testing frameworks, test management, performance monitoring
- **Deployment Tools**: Infrastructure as code, containerization, orchestration
- **Monitoring Tools**: Application monitoring, log aggregation, alerting systems

### Framework Integration
- **Frontend Frameworks**: Component libraries, state management, routing solutions
- **Backend Frameworks**: Service frameworks, ORM libraries, API development tools
- **Database Systems**: Database selection, migration tools, connection pooling
- **Message Queues**: Queue implementation, message serialization, consumer patterns

### Migration Strategies
- **Legacy Systems**: Assessment methodology, migration planning, risk mitigation
- **Database Migration**: Schema changes, data transformation, downtime minimization
- **Application Migration**: Feature migration strategies, rollback procedures, user training
- **Infrastructure Migration**: Cloud migration planning, cost optimization, performance tuning
