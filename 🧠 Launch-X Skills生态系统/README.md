### 🎯 核心理念：知识驱动的技能网络
```yaml
传统状态:
  知识域: 12 个分散目录
  方式: 人工检索 + 手动组合
  交付: 文档型成果

Skills 模式:
  核心技能: 7 个单一职责 Skill
  方式: 标准化提示 + 自动化脚本
  交付: 结构化输出 + 工作流联动
```

### 🌐 设计原则
- **单一职责**：每个 Skill 聚焦一个明确的业务场景或角色能力。  
- **双向回写**：所有输出需回写知识库，保证知识 → 能力 → 知识的循环。  
- **标准化交付**：Frontmatter + README + instructions + scripts + resources + tests 架构统一。  
- **可验证性**：每个 Skill 至少保留一份手动测试脚本或自动化验证入口。

## 技能能力卡

### Skill 1 商业决策支持专家
- **定位**：整合投资方法论、企业画像与风险模型的决策顾问。  
- **目录**：`1️⃣ 商业决策支持专家/`  
- **代表脚本**：`scripts/main.py` 进行项目分析与 ROI 估算。  
- **使用示例**：`/skill business-decision-support "评估AI客服SaaS的投资价值与风险"`  
- **测试入口**：`tests/test-plan.md`，覆盖投资分析、组合优化等场景。

### Skill 2 企业研究分析师
- **定位**：专业尽调与行业研究引擎。  
- **核心流程**：企业档案 → 行业扫描 → 竞争对标 → 风险评估。  
- **资源亮点**：`resources/templates/` 提供研究报告 skeleton。  
- **协同建议**：与 Skill 1 联动形成“投资 + 尽调”闭环。

### Skill 3 市场情报专家
- **定位**：市场趋势、竞品动态与机会识别的雷达。  
- **特色资源**：`resources/data/` 中的市场快照与案例库。  
- **推荐提示**：`/skill market-intelligence-expert "比较Photoroom与Canva在AI设计工具市场的差异"`  
- **测试计划**：强调趋势扫描、行业深潜、竞品对比三类用例。

### Skill 4 知识管理大师
- **定位**：知识资产整理、内容生成与归档自动化。  
- **关键脚本**：`scripts/` 包含索引同步、frontmatter 生成工具。  
- **测试关注**：Inbox 去重、周报生成、知识图谱节点输出。  
- **协作节点**：所有 Skill 输出需通过本技能回写知识库。

### Skill 5 项目架构规划师
- **定位**：项目立项、结构规划、流程治理的标准制定者。  
- **核心产物**：文件夹基线、RACI 表、CI/CD 流程建议。  
- **典型指令**：`/skill project-architect "给AI听众服务平台设计开发结构与里程碑"`  
- **测试计划**：覆盖项目初始化、重构评估、流程规范三种场景。

### Skill 6 技术设计专家
- **定位**：技术架构、模式选型、非功能指标设计专家。  
- **知识触发**：结合 Gate-OS、AI 产品化策略与 Deep Study 案例。  
- **输出模板**：技术选型矩阵、架构草图、风险与回滚方案。  
- **协同建议**：与 Skill 5 / Skill 8 协同，支持端到端技术交付。

### Skill 8 深度学习专家
- **定位**：模型研发、训练优化与学习路径规划教练。  
- **资源亮点**：`resources/` 包含学习路线、训练配置、评估指标模板。  
- **典型指令**：`/skill deep-learning-expert "为NLP团队设计LLM推理成本优化方案"`  
- **测试计划**：学习路径、训练优化、部署指导三大类验证。

## 协同工作流

### 1️⃣ 投资决策闭环
```yaml
触发: 投资/估值/风险相关需求
流程:
  1. 商业决策支持专家 → 价值评估与ROI测算
  2. 企业研究分析师 → 企业档案与行业深潜
  3. 市场情报专家 → 市场趋势与竞品对比
  4. 知识管理大师 → 生成综合决策报告并回写知识库
输出: 投资建议 + 风险缓释方案 + 待跟踪指标
```

### 2️⃣ AI 产品化交付流
```yaml
触发: 企业AI化或新产品落地
流程:
  1. 项目架构规划师 → 项目结构与流程基线
  2. 技术设计专家 → 技术方案、模式选型、非功能指标
  3. 深度学习专家 → 模型方案、训练计划、部署策略
  4. 知识管理大师 → 归档交付物、生成维护SOP
输出: 端到端技术方案包 + 执行路线 + 知识库回写
