## Skill 1: 商业决策支持专家

### 📋 技能定义
```yaml
技能名称: 商业决策支持专家
版本: v1.0.0
分类: business-intelligence
标签: 商业分析, 投资决策, ROI评估, 风险分析
```

### 🎯 核心功能
- **投资项目价值评估**: 基于Launch-X投资分析框架
- **商业决策支持分析**: 整合多维度数据分析能力
- **ROI计算和价值量化**: 量化投资回报和成本效益
- **风险评估和建议**: 全面的风险识别和缓解策略

### 💡 使用示例
```bash
# 投资分析
/skill business-decision-support "分析这个AI项目的投资价值和风险"

# 商业决策
/skill business-decision-support "我们公司是否应该投入资源开发AI产品？"
```

## 工作流程设计

### 🔄 技能协同机制

#### 1. 投资决策支持工作流
```yaml
触发: 用户询问投资相关问题时
流程:
  1. 商业决策支持Skill → 初步分析和价值判断
  2. 企业研究分析师Skill → 深度尽调和企业分析
  3. 市场情报专家Skill → 市场环境和竞争分析
  4. 知识管理大师Skill → 整合报告和决策建议

输出: 综合投资决策支持报告
```

#### 2. 企业咨询服务工作流
```yaml
触发: 用户需要企业咨询时
流程:
  1. 企业研究分析师Skill → 企业现状分析
  2. 市场情报专家Skill → 行业地位和机会分析
  3. 商业决策支持Skill → 战略建议和ROI分析
  4. 知识管理大师Skill → 咨询报告整理和输出

输出: 专业企业咨询方案
```
