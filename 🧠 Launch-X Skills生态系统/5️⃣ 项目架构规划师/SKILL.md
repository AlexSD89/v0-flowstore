# 项目架构规划师

## 基本信息
- **技能名称**: 项目架构规划师
- **版本**: v1.0.0
- **作者**: LaunchX团队
- **分类**: project-architecture
- **标签**: 项目规划, 架构设计, 文件夹结构, 最佳实践

## 功能描述
基于Launch-X开发实战经验的项目架构规划专家，专门负责项目结构设计、规划逻辑和最佳实践指导。

### 主要用途
- 项目文件夹结构设计
- 开发规划逻辑制定
- 架构决策支持
- 最佳实践应用

### 适用场景
- 新项目初始化和结构设计
- 项目重构和架构优化
- 开发流程规范化
- 团队协作框架设计

### 核心价值
- 基于实战经验的结构化方案
- 可复用的架构设计模式
- 清晰的规划逻辑框架
- 经过验证的最佳实践

## 使用方式

### 直接调用
```bash
/skill project-architect "帮我设计一个新项目的文件夹结构"
```

### 自然语言调用
```
请调用项目架构规划师，为这个AI项目制定开发架构
```

### 自动识别调用
当用户询问项目结构、架构设计、开发规划时，Claude会自动调用本技能。

## 输入参数
- **project_type**: 项目类型 (AI项目/Web应用/移动应用等) (必需)
- **tech_stack**: 技术栈 (可选)
- **team_size**: 团队规模 (可选)
- **complexity**: 项目复杂度 (简单/中等/复杂) (可选)

## 输出结果
- **格式**: 项目架构方案
- **内容**: 文件夹结构、规划逻辑、最佳实践建议
- **示例**: 完整的项目初始化方案

## 依赖项
- **知识来源**: study/、💻 技术开发/项目经验
- **实战案例**: Launch-X项目结构模板
- **设计模式**: 经过验证的架构模式

- **平均执行时间**: 2-5分钟
- **成功率**: 95%+
