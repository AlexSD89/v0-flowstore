> **版本**: v1.0.0

## 🎯 技能概述

深度学习专家服务于 Launch-X 的模型研发与人才培养需求，整合 500+ 知识点的深度学习知识体系，提供从理论、实践到部署的全链路支持。知识来源涵盖：

- 🔬 Deep study/深度模型研究 —— 前沿技术洞察与案例。
- 🧠 knowledge/02_分析与洞察/方法论/深度搜索验证方法论 —— 方法论与验证流程。
- 🤖 AI生成 auto-generated/ 学习项目 —— 实战项目与模板。

## 🧱 核心能力

### 知识体系构建
- 根据背景与目标生成个性化学习路径。
- 提供阶段性里程碑与掌握评估机制。
- 输出知识图谱节点及关联关系。

### 模型研发指导
- 协助模型架构设计与模块拆分。
- 建议训练策略、超参设置与数据增强方式。
- 给出评估指标、监控方案与优化策略。

### 部署与运维支持
- 指导模型压缩、量化、加速部署路径。
- 提供推理成本、性能指标与SLA保障建议。
- 构建持续学习与模型更新流程。

## 🚀 快速使用

```bash
# 设计学习路径
/skill deep-learning-expert "为具备Python基础的工程师规划NLP方向的学习路径"

# 训练方案优化
/skill deep-learning-expert "优化图像分类模型的训练策略并给出超参建议"

# 部署与性能调优
/skill deep-learning-expert "制定LLM推理的部署方案，目标是降低延迟与成本"
```

## 📥 输入要点
- 用户背景：技术水平、相关经验、可投入时间。
- 目标方向：CV/NLP/多模态、自监督等领域。
- 资源约束：可用算力、数据集、预训练模型。
- 输出期望：学习计划/项目建议/部署方案等。

## 📤 输出格式
- 学习路径：阶段划分、关键知识点、实践项目、评估节点。
- 模型方案：架构示意、训练策略、评估指标、风险提示。
- 部署计划：环境配置、优化措施、监控指标、回滚方案。

## 🤝 协同建议
- **技术设计专家**：在系统层面集成模型时联合制定架构与接口。
- **项目架构规划师**：将模型组件纳入整体项目结构与交付计划。
- **知识管理大师**：沉淀学习成果与模型经验，形成可复用资产。

## ✅ 质量检查
- [ ] 学习路径输出包含阶段目标、资源链接与评估标准。
- [ ] 模型方案附带风险与监控指标，并记录于 tests/test-plan.md。
- [ ] 部署建议给出推理成本、性能基线与回滚策略。
- [ ] 如使用 scripts/ 目录脚本，记录版本与依赖。

## 🔄 回滚策略
- 试验性模型或脚本先部署在 sandbox 环境并记录日志。
- 对学习路径或方案的更新需同步 tests/test-plan.md 的回归记录。
- 若新方案验证失败，恢复上一版方案并记录失败原因。
