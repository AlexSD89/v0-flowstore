## 数据文件说明

### enterprise-research-config.json
企业研究分析的核心配置文件，包含：

#### 分析框架配置
- **Launch-X方法论**: 基于Launch-X验证的6步企业研究流程
- **数据源整合**: 内部数据库、公开报告、专家网络、行业基准
- **质量控制**: 多源验证、交叉检验、同行评议机制

#### 行业基准数据
- **科技行业**: 平均增长25%，利润率20%，估值倍数8.0x
- **教育行业**: 平均增长15%，利润率25%，估值倍数6.0x
- **医疗行业**: 平均增长18%，利润率30%，估值倍数10.0x
- **金融行业**: 平均增长12%，利润率15%，估值倍数4.0x

#### 风险评估配置
- **风险权重**: 市场30% + 财务30% + 运营20% + 监管20%
- **风险等级**: 4个等级，从低到高，对应不同颜色和行动建议
- **风险因子**: 每个风险类别包含具体的风险因素和评分机制

#### 估值方法配置
- **DCF估值**: 权重40%，折现率12%，5年预测期
- **可比公司**: 权重30%，最少3家可比公司
- **先例交易**: 权重20%，24个月回溯期
- **资产基础**: 权重10%，流动性折扣30%

## 模板文件说明

### enterprise-research-report.md
标准企业研究报告模板，采用8段式结构：

1. **执行摘要**: 项目概览和核心发现
2. **企业概况**: 基本信息、商业模式、发展历程
3. **财务分析**: 营收表现、盈利能力、行业对比
4. **竞争分析**: 市场地位、竞争优势、竞争格局
5. **风险评估**: 风险矩阵、主要风险、缓解措施
6. **投资建议**: 评级建议、估值分析、投资理由
7. **尽调清单**: 法律、财务、技术、商业尽调要点
8. **投后管理**: 监控指标、里程碑、增值服务

#### 模板变量
- `{company_name}`: 企业名称
- `{overall_score}`: 综合评分
- `{investment_recommendation[rating]}`: 投资评级
- `{generation_time}`: 生成时间
- `{version}`: 报告版本

## 分析方法论

### Launch-X企业研究方法论
基于Launch-X验证的6步研究流程：

1. **项目筛选**: 基于基础条件和企业画像
2. **深度分析**: 多维度深入评估和分析
3. **竞争研究**: 全面竞争格局和地位分析
4. **风险评估**: 系统性风险识别和量化
5. **价值评估**: 综合估值和投资价值分析
6. **投资建议**: 基于数据的投资决策建议

### 评分模型
- **加权评分**: 基于权重的综合评分模型
- **动态调整**: 根据行业和发展阶段动态调整
- **基准对比**: 与行业基准进行对比分析
- **趋势分析**: 基于历史数据的趋势预测

### 风险评估框架
- **多维度风险**: 市场、财务、运营、监管风险
- **风险量化**: 基于概率和影响的风险量化
- **风险缓释**: 针对性风险缓释策略
- **风险监控**: 持续风险监控和预警机制

## 故障排除

### 常见问题

#### 问题1: 企业数据不完整
**解决方案**:
1. 检查数据源API连接状态
2. 验证企业基本信息格式
3. 使用默认数据补充缺失字段
4. 标注数据完整性等级

#### 问题2: 行业基准缺失
**解决方案**:
1. 检查行业分类准确性
2. 使用相近行业基准数据
3. 调整行业参数配置
4. 标注基准数据可靠性

#### 问题3: 估值计算异常
**解决方案**:
1. 验证财务数据合理性
2. 检查估值模型参数设置
3. 调整估值方法权重
4. 进行敏感性分析验证

#### 问题4: 报告生成失败
**解决方案**:
1. 检查模板文件完整性
2. 验证数据变量替换
3. 确认输出目录权限
4. 查看详细错误日志

### 调试模式
启用详细调试日志：
```bash
export ENTERPRISE_DEBUG=true
python3 scripts/main.py "企业名称" --debug
```
