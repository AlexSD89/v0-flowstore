> **数据来源**: 🟣 knowledge/04_被投企业数据库, 🟣 knowledge/03_研究报告

## 概述

企业研究分析师是基于Launch-X研究框架的专业企业分析技能，专注于提供全面、深入的企业研究和投资分析服务。该技能整合了标准化的尽调流程、专业的分析方法和丰富的行业经验，为投资决策提供可靠的数据支撑和分析洞察。

## 核心功能

### 🔍 企业深度分析
- **基本面分析**: 业务模式、产品服务、市场地位评估
- **财务分析**: 营收增长、盈利能力、现金流健康状况
- **竞争分析**: 市场份额、竞争优势、行业地位
- **风险分析**: 经营风险、财务风险、市场风险识别

### 📊 行业研究
- **行业规模和增长趋势**: 定量分析行业发展现状和前景
- **竞争格局**: 主要参与者、市场集中度、进入壁垒
- **价值链分析**: 产业链上下游关系和价值分布
- **政策环境**: 相关政策法规对行业的影响

### 🎯 投资评估
- **投资价值评估**: 基于多维度的企业价值评估
- **风险评估**: 系统性风险和特殊性风险识别
- **投资建议**: 明确的投资评级和建议理由
- **后续跟踪**: 投资后的监控和评估计划

## 使用方式

### 直接调用
```
"分析这家AI教育公司的投资价值"
"对新能源汽车行业进行深度研究"
"评估这个SaaS公司的竞争优势"
```

### 自然语言调用
```
"帮我研究一下字节跳动的业务模式和发展前景"
"我想了解AI芯片行业的竞争格局"
"这家公司的财务状况怎么样，值得投资吗？"
```

### 自动识别触发词
`企业分析` `尽调` `研究` `评估` `行业分析` `竞争对手` `投资价值`

## 输入参数

### 必需参数
- **分析目标**: 具体的企业名称或行业领域
- **分析类型**: 企业分析/行业研究/竞争分析/投资评估

### 可选参数
- **分析深度**: 快速评估/标准分析/深度研究
- **数据来源**: 指定的数据源或信息渠道
- **时间范围**: 分析的时间跨度和历史数据要求
- **关注重点**: 特定的分析维度或关注领域

## 故障排除

### 常见问题
1. **数据不足**: 明确信息缺口，建议补充调研方向
2. **数据质量存疑**: 标注数据可靠性，建议进一步验证
3. **分析结论矛盾**: 重新检查数据和分析逻辑
4. **时效性问题**: 标注数据时效性，建议定期更新

### 解决方案
- **信息缺口**: 提供明确的调研建议和数据需求清单
