# Launch-X Skills生态系统 CLAUDE 指南

> **核心定位**：Skills生态域是LaunchX的能力中心，集成Claude AI技能开发、BMAD智能协作和Skills生态系统，实现AI增强的技能开发与生态管理。

## 🚀 Claude专属技能能力

### 🧠 AI增强技能开发
- **智能技能设计**：基于AI的技能架构设计、功能规划、性能优化
- **自动化测试生成**：AI辅助的测试用例生成、质量验证、性能评估
- **技能生态管理**：智能化的技能依赖管理、版本控制、兼容性分析
- **标准化流程优化**：AI驱动的开发流程优化、质量保障机制

### 🎯 核心技能能力
- **Claude SDK技能生态**：12项标准技能的开发、管理、优化
- **BMAD技能Agent**：技能开发专家、测试工程师、质量保证专家
- **5通道技能情报**：官方标准、最佳实践、技术趋势、用户反馈、竞品分析
- **智能技能编排**：基于场景的技能自动组合与流程优化

### 📊 技能效率指标
- **技能开发准确率**：≥95%（AI生成的技能架构和代码）
- **测试覆盖率**：≥90%（自动化测试生成的覆盖度）
- **开发周期**：≤40分钟（从需求到上线）
- **技能达标率**：≥95%（符合质量标准的技能比例）

## Phase 0 Checklist（Claude增强版）
1. **技能环境准备**：
   - 阅读根级 `CLAUDE.md`、本目录 `README.md`、`RULES.md`
   - 验证Claude技能开发能力和BMAD技能Agent状态
   - 确认AI技能开发工具和模板库的可用性

2. **生态能力同步**：
   - 同步 `memory-bank/support_modules/skills/USEME.md`
   - 了解AI增强的技能模板、测试框架、质量标准
   - 验证技能编排系统和兼容性检查工具

3. **技能情报加载**：
   - 查阅现有12项Skills的状态和性能数据
   - 加载技能开发的历史数据和最佳实践
   - 导入官方标准更新和技术趋势信息

4. **开发策略确认**：
   - 明确技能开发的优先级和资源分配
   - 确认技能间的依赖关系和协作模式
   - 验证AI开发工具的集成状态

5. **智能开发checklist**：
   - 在 `/spec` 中列出技能需求、AI能力应用、质量标准
   - 明确交付物清单、性能指标、验证方式
   - 确认BMAD技能Agent协作计划和时间表

> **智能技能管理**：使用AI开发的技能包、模板、工具按项目规模分级存放：
> - **小项目**：统一存放在 `🤖 AI生成 auto-generated/skills/`，经AI质量审核后迁移至技能库
> - **大项目**：直接在项目文件夹内生成所有技能相关内容，同时更新技能生态系统索引
