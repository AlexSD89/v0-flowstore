# README.md · 多模态数据理解技能概览

> **技能简介**: LaunchX首个专门处理Excel、图片设计、人类交互模式的多模态数据理解专家，为奇境-小龙项目提供精准客户需求分析能力。

---

## 🎯 技能定位

### 核心价值主张
- **多模态整合**: 统一处理Excel表格、图片设计、交互数据
- **业务逻辑深度理解**: 超越表面数据，理解背后的商业逻辑
- **客户需求精准洞察**: 基于多源数据生成深度客户洞察
- **行动导向分析**: 所有分析结果都导向可执行的行动建议

### 独特优势
1. **跨格式理解能力**: 同时支持结构化数据(Excel)和非结构化数据(图片、文档)
2. **业务逻辑推理**: 能够从数据中推理出业务规则和流程
3. **模式识别专长**: 擅长发现数据中的重复模式、异常模式和优化机会
4. **Codex协作优化**: 与Claude认知指导和Codex执行能力完美配合

## 🚀 使用指南

### 快速开始
1. **准备数据**: 将Excel、图片、文档放入项目目录
2. **激活技能**: 系统自动识别或手动调用技能
3. **定义分析**: 明确分析目标和关注重点
4. **执行分析**: 技能自动执行四阶段分析流程
5. **获取报告**: 收到结构化分析报告和建议

### 最佳实践
1. **数据准备**: 确保数据完整性和格式规范性
2. **目标明确**: 清晰定义分析目标和期望产出
3. **迭代优化**: 基于初步结果调整分析策略
4. **结果验证**: 关键结论进行人工验证确认
5. **行动跟进**: 及时将分析建议转化为实际行动

### 常见问题
**Q: 支持哪些文件格式?**
A: Excel(.xlsx, .xls), 图片(.jpg, .png, .gif), 文档(.docx, .pdf, .txt)

**Q: 分析需要多长时间?**
A: 简单分析1-2分钟，复杂分析5-10分钟，大型项目可能需要更长时间

**Q: 分析结果的准确性如何保证?**
A: 多重质量检查机制，关键结论人工验证，持续优化算法模型

**Q: 如何处理敏感数据?**
A: 严格的数据安全协议，本地处理，数据不外传，用后即删
