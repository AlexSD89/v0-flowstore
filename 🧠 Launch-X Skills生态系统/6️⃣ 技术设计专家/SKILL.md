# 技术设计专家

## 基本信息
- **技能名称**: 技术设计专家
- **版本**: v1.0.0
- **作者**: LaunchX团队
- **分类**: technical-design
- **标签**: 代码设计, 技术架构, 设计模式, 最佳实践

## 功能描述
基于Launch-X技术开发和企业AI化经验的专业技术设计专家，提供代码设计、架构模式、技术选型和企业AI转型指导。

### 主要用途
- 代码架构设计和优化
- 设计模式选择和应用
- 技术选型建议
- 企业AI转型策略制定
- 技术实现方案设计

### 适用场景
- 技术方案设计
- 代码重构和优化
- 架构模式选择
- 企业AI系统规划和设计
- 开发标准制定
- AI产品化技术架构

### 核心价值
- 基于实战项目的设计经验
- 经过验证的技术模式
- 清晰的设计决策逻辑
- 可复用的设计框架

## 使用方式

### 直接调用
```bash
/skill technical-design-expert "帮我设计这个AI系统的代码架构"
```

### 自然语言调用
```
请调用技术设计专家，为这个功能模块选择合适的设计模式
```

### 自动识别调用
当用户询问技术设计、代码架构、设计模式等问题时，Claude会自动调用本技能。

## 输入参数
- **requirement**: 功能需求或技术问题 (必需)
- **tech_stack**: 技术栈或现有代码环境 (可选)
- **constraints**: 技术约束或限制条件 (可选)
- **quality_level**: 质量要求 (快速原型/生产级) (可选)

## 输出结果
- **格式**: 技术设计方案
- **内容**: 架构设计、代码结构、设计模式应用
- **示例**: 具体的技术实现方案

## 依赖项
- **知识来源**: 💻 技术开发/实战经验、🔬 Deep study技术分析
- **设计模式库**: 经过验证的设计模式集合
- **技术案例**: Launch-X项目的技术实现经验

## 性能指标
- **平均执行时间**: 3-8分钟
- **成功率**: 90%+
- **适用复杂度**: 中到高复杂度技术设计
