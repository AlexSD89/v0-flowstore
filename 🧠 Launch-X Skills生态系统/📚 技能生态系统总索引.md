## 🚀 使用指南

### 1. 技能激活
在Claude对话中直接提及功能需求，系统自动识别并激活相应技能。

### 2. 分类浏览
通过分类目录快速定位所需技能：
```bash
# 查看分类统计
./scripts/skills-manager.sh stats

# 搜索特定技能
./scripts/skills-manager.sh search "pdf"
```

#### 📊 企业研究类 (02-企业研究)
- **企业研究分析师** (`企业研究分析师-Enterprise-Research-Analyst/`) - 深度企业分析和尽职调查

- **AI项目录入引擎** (`AI项目录入引擎-AI-Project-Intake-Engine/`) - ⭐ **AI原生v3.0-已验证**: 智能项目信息录入与维护系统，严格遵循"查重→采集→生成→交付"四步闭环，SERVAL项目验证通过，94分质量标准

### 3. 生态系统管理
定期同步和维护生态系统状态：
```bash
# 同步GitHub技能
./scripts/skills-ecosystem-sync.sh sync

# 完整性验证
./scripts/skills-manager.sh validate
```

## 🔄 更新流程

### 1. 新增技能
1. 评估技能价值和分类
2. 安装到 `.claude/skills/categories/`
3. 更新分类索引
4. 同步到生态系统备份

### 2. 技能更新
1. 在分类目录中更新
2. 验证功能完整性
3. 同步更新到生态系统

### 3. 生态系统维护
- 定期运行同步脚本
- 验证技能完整性
- 更新索引文档
