# Git协作专家

> 专业的Git版本控制和团队协作管理专家，基于实战经验提供标准化工作流程

## 🚀 功能特性

### 核心能力
- **分支管理**: 主流分支策略（GitFlow、GitHubFlow、GitLabFlow）实施
- **冲突解决**: 标准化冲突处理流程和预防机制
- **团队协作**: 多人协作最佳实践和沟通机制
- **工作流程**: 定制化Git工作流程设计和优化
- **安全管控**: 数据安全保障和风险防范措施

### 智能分析
- **现状评估**: Git工作流程成熟度分析
- **风险预警**: 操作风险评估和防范建议
- **效率优化**: 协作效率瓶颈识别和改进方案
- **合规检查**: Git规范执行和质量监控

## 📋 使用指南

### 快速开始
```bash
# 分析当前Git工作流程
/skill git-collaboration-expert "分析我们团队的Git工作流程，提供优化建议"

# 处理分支冲突
/skill git-collaboration-expert "解决合并冲突，确保代码完整性"

# 建立标准流程
/skill git-collaboration-expert "为10人团队建立Git协作规范，采用适合的分支策略"
```

### 参数配置
| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| 任务类型 | string | ✅ | 分支管理/代码同步/冲突解决/工作流程/团队协作 |
| 项目路径 | string | ❌ | Git项目路径，默认当前目录 |
| 分支策略 | string | ❌ | GitFlow/GitHubFlow/GitLabFlow/自定义 |
| 团队规模 | string | ❌ | 小型/中型/大型 |
| 紧急程度 | string | ❌ | 紧急/常规/低优先级 |

## 🎯 解决方案

### 常见问题场景

#### 场景1: 分支混乱
**问题**: 多人开发导致分支管理混乱，合并困难
**解决方案**:
- 实施标准化分支命名规范
- 建立清晰的分支生命周期管理
- 配置分支保护规则
- 提供自动化工具支持

#### 场景2: 冲突频发
**问题**: 代码合并冲突频繁，解决效率低下
**解决方案**:
- 建立代码区域划分机制
- 实施持续集成和频繁合并策略
- 提供冲突解决工具和培训
- 优化开发协作流程

#### 场景3: 版本管理
**问题**: 版本发布流程不规范，回滚困难
**解决方案**:
- 建立版本标签管理规范
- 实施自动化发布流程
- 配置快速回滚机制
- 制定发布检查清单

#### 场景4: 团队协作
**问题**: 团队Git使用水平不统一，协作效率低
**解决方案**:
- 制定统一的Git协作规范
- 提供团队培训和指导
- 建立代码审查机制
- 配置协作工具和通知
