# 业务服务｜业务转型与AI共创方法论

> **核心定位**：帮助企业以 AI 共创为驱动完成业务转型，从战略诊断到收益验证形成闭环。
>
> **适用场景**：中大型企业数字化升级、AI 驱动的业务重构、被投企业的能力重塑、咨询团队的共创交付项目。

## 1. 方法论全景

### 1.1 三层目标
- **战略层**：明确业务价值主张与增长模型，定位可放大的 AI 贡献（营收、效率、风险）。
- **运营层**：设计跨部门协同机制与收益权结构，确保执行过程中责任清晰。
- **交付层**：构建 Collect → Model → Compare → Align → Deliver → Archive 闭环，对应产品、流程与数据回写。

### 1.2 成功指标
| 维度 | 指标口径 | 目标值 |
| --- | --- | --- |
| 收益验证 | 12 个月累计新增收益 or 节省成本 | ≥ 18% |
| 转型落地 | 关键里程碑按期完成率 | ≥ 90% |
| 人机协作 | AI 共创任务成功率（一次交付过审） | ≥ 85% |
| 风险控制 | 重大偏差数（>15%） | ≤ 1 次/季度 |

## 2. Phase A｜诊断与定位

### 2.1 业务现状快速体检
1. **业务漏斗拆解**：拉通需求 → 方案 → 交付 → 复购四个环节，量化当前瓶颈。
2. **能力成熟度评分**：依据《垂直专业简介》中的指标，对组织、流程、工具、数据四象限打分（1-5级）。
3. **市场基准比对**：复用 archive 中的《投资行业趋势研究》章节获取行业对标指标，确认差距与机会。

> 提醒：无数据的环节以 TODO｜待补充 形式标记，责任人同级确定，避免在执行阶段重新拉通。

### 2.2 被服务对象画像
- 客户/业务单元的角色地图（采购→运营→老板）与核心诉求。
- 核心交易结构：签约模式、收益分成、交付责任。
- 可迁移资产清单：现有 SOP、数据资源、历史案例、可复用模型。

### 2.3 转型北极星
结合 SPELO（Strategy、Product、Execution、Link、Outcome）框架，提炼 3-5 条必须达成的北极星指标，并在 `/spec` 中冻结，作为跨部门协作的唯一裁判。

## 3. Phase B｜方案设计与收益结构

### 3.1 双轨设计框架
| 轨道 | 关键交付 | 要点 |
| --- | --- | --- |
| **业务轨** | 新业务模型、客户旅程、收益分配 | 引入“收益权转移方案”模板，明确新增收益归属、保障条款与 KPI 绑定。 |
| **技术轨** | AI 能力组合、BMAD 连接点、数据治理方案 | 确定 AI 服务角色（分析、创作、执行、监督），拆解输入输出。 |

### 3.2 共创治理机制
- **三层组织**：转型指挥部、业务域小队、AI 工程组。
- **例会节奏**：周 Collect → Model、双周 Compare → Align、月度 Deliver Review。
- **决策快线**：关键指标偏差 >10% 触发快速回路，参考《Collect→Align→Deliver》标准流程处理。

### 3.3 风险与保障
- **业务风险**：收益兑现延迟 → 设置里程碑验证节点，挂载在 Archive 复盘。
- **技术风险**：AI 模型不稳定 → 预置 A/B 模式与 fallback 流程。
- **合规风险**：数据跨境、隐私问题 → 引入《RULES.md》中的合规清单。

## 4. Phase C｜落地执行与验收

### 4.1 执行节奏
1. **启动月（M0）**：完成数据接入、流程梳理、目标冻结。
2. **共创月（M1-M2）**：交付 MVP 场景，验证收益权转移机制。
3. **扩展月（M3-M4）**：将成功场景复制至其他业务单元，建立跨域知识回写。
4. **固化月（M5+）**：将成功经验写入规则、技能、memory-bank，形成可复制资产。

### 4.2 工具矩阵
- **方法论资产**：本文件 + 《业务服务_企业AI共创服务方法论_V1.0_20251028.md》组成“方案设计 + 执行治理”组合。
- **项目工具**：Deliver 阶段使用 `🧩 bmad` 的监控脚本，Archive 阶段同步 memory-bank 索引。
- **验证脚本**：ROI 仪表板、OODA 实时监控、风险雷达。

### 4.3 验收标准
- 北极星指标达成情况（含偏差解释）。
- 共创成果包：协议 / SOP / 模型 / 评测脚本。
- 组织能力提升：新规则数量、技能升级清单、团队评价。

## 5. 角色与协作
| 角色 | 核心职责 | 关键交付 |
| --- | --- | --- |
| 域负责人 | 明确北极星、批准收益结构 | `/spec`、互链清单 |
| 方案架构师 | Collect → Model → Compare，沉淀方案 | 方案包、风险登记表 |
| AI 工程组 | 构建 BMAD 接口、质量保障 | 执行脚本、测试记录 |
| 业务运营 | 执行与反馈、指标看板维护 | KPI 仪表、复盘报告 |
| Memory Curator | 归档、互链、todo 跟进 | memory-bank 更新、Archive 说明 |
