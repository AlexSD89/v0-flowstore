# 深度研究域总览

## 使命与范围
- 承担长周期、高复杂度的专题研究（技术演进、行业重构、体系设计）。
- 生成高置信度的洞察、策略与原型，为业务、投资、技术决策提供支撑。
- 管理研究资料、数据脚本、复盘日志，形成可复用的分析框架。

## 目录地图
| 目录 | 功能 |
| --- | --- |
| `mauns研究` | 重点课题（示例：MAUNS）研究材料、推演与实验记录 |
| `投资公司新业务重塑与执行策略 (1)` | 特定主题研究（可按项目拆分） |
| 其余子目录 | 根据课题建立，命名采用 `YYYY-主题` 或团队约定格式 |

## 工作流
0. **草稿缓存**：初步访谈摘要、灵感笔记可暂存 `🤖 AI生成 auto-generated/日期`，24 小时内整理入正式目录。
1. **立项**：在 `/spec` 说明背景、问题、关键假设、成果形态，确认资源与时间表。
2. **资料构建**：收集底层数据、建立引用索引、同步知识域以避免重复。
3. **分析推演**：使用结构化模型（系统动力学、Scenario Planning 等），记录推理链路。
4. **验证回路**：与业务、技术、设计域共创试点，记录反馈与指标。
5. **归档复盘**：产出报告/白皮书/执行框架，回写 `memory-bank` 与方法论库。

## 协同依赖
- **知识域**：共享五通道成果、历史案例、外部研究引用。
- **技术域**：验证技术可行性、提供实验脚本、支持原型。
- **业务域**：评估商业落地路径与市场影响。
- **设计域**：可视化框架、产出传播物料。
- **自动化实验室**：与 `🧩 bmad` 协作，沉淀数据处理脚本与实验任务。
