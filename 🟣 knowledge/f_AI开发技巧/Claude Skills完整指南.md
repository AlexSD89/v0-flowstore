# Claude Skills 完整指南

## 概述

Claude Skills 是**模块化的能力扩展**，通过有组织的文件夹包含指令、脚本和资源来增强Claude的功能。Skills是Claude Code的核心扩展机制，让用户能够封装专业知识和工作流程。

## 核心定义

### Claude Skills 真实形态
> **Skills are modular capabilities that extend Claude's functionality through organized folders containing instructions, scripts, and resources.**

**Claude Skills 是文件夹形式的模块化能力，包含：**
- **指令文件** (instructions.md) - 核心逻辑和处理流程
- **脚本文件** (scripts/) - 可执行的辅助工具
- **资源文件** (resources/) - 数据、模板、文档等
- **描述文件** (SKILL.md) - 技能说明和使用指南

### 与Agent SDK的关系
- **Skills**: 基础模块化能力单元
- **Agent SDK**: 更高级的智能体开发框架
- **关系**: Skills是构建Agent的基础组件，两者互补而非替代

### Claude Code 定位
- **工具性质**: 终端中的智能编程助手
- **核心能力**: 
  - 代码库理解和上下文感知
  - 自然语言命令处理
  - 常规任务自动化
  - 复杂代码解释
  - Git工作流管理

## Claude Agent SDK 核心组件

### 1. Sub-Agents (子智能体)
- **用途**: 专门化任务处理
- **特点**: 独立功能模块，可组合使用
- **示例**: 
  - `frontend-developer`: 前端开发专家
  - `python-expert`: Python编程专家
  - `security-auditor`: 安全审计专家

### 2. Plugins (插件系统)
- **功能**: 扩展Claude的功能范围
- **集成**: 与外部工具和服务连接
- **类型**: 数据处理、API集成、专业工具

### 3. Skills (技能模块)
- **定义**: 特定任务的专业化能力
- **特点**: 可复用、可组合
- **开发**: 基于标准化的技能模板

### 4. Output Styles (输出样式)
- **作用**: 控制Claude的输出格式
- **应用**: 适配不同的使用场景
- **定制**: 根据项目需求调整

### 5. Hooks (钩子机制)
- **触发器**: 基于事件的自动化响应
- **用途**: 工作流自动化
- **配置**: 在设置中定义钩子命令

### 6. Slash Commands (斜杠命令)
- **交互方式**: 快速命令执行
- **语法**: `/command [arguments]`
- **自定义**: 创建项目特定命令

## Skills 工作原理

### 1. 动态加载机制
```python
# Claude Code动态加载Skills的过程
def load_skill(skill_path: str):
    # 1. 读取技能描述
    skill_config = read_skill_md(f"{skill_path}/SKILL.md")

    # 2. 加载核心指令
    instructions = read_instructions(f"{skill_path}/instructions.md")

    # 3. 加载资源文件
    resources = load_resources(f"{skill_path}/resources/")

    # 4. 加载脚本工具
    scripts = load_scripts(f"{skill_path}/scripts/")

    return {
        'config': skill_config,
        'instructions': instructions,
        'resources': resources,
        'scripts': scripts
    }
```

### 2. 技能调用方式
```bash
# 方式1: 直接技能调用
> /skill skill-name "具体的任务或问题"

# 方式2: 自然语言调用
> "请调用[技能名称]，帮我处理[具体任务]"

# 方式3: 自动识别调用
> "我需要分析这个AI项目的投资价值"
> # Claude自动识别并调用ai-investment-analyst技能
```

### 3. 技能执行流程
```yaml
1. 技能识别: Claude识别用户需求，匹配最适合的Skill
2. 动态加载: 加载Skill文件夹中的所有组件和资源
3. 指令执行: 基于instructions.md中的指令逻辑执行
4. 资源调用: 使用resources/中的数据、模板和文档
5. 脚本运行: 必要时执行scripts/中的辅助脚本
6. 结果整合: 整合所有执行结果和资源生成响应
7. 结果返回: 向用户返回专业、结构化的结果
```
