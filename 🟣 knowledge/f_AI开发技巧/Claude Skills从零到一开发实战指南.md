## 官方开发逻辑解析

### 🎯 官方设计理念

根据官方文档，Claude Skills的核心逻辑是：

> **"Teach Claude your workflows once and have it execute them every single time"**
> 一次教会Claude工作流程，每次都能准确执行

### 🔄 官方标准开发流程

```mermaid
graph LR
    A[Step 1: 需求识别] --> B[Step 2: 文件夹创建]
    B --> C[Step 3: SKILL.md编写]
    C --> D[Step 4: instructions.md编写]
    D --> E[Step 5: 资源文件准备]
    E --> F[Step 6: 本地测试]
    F --> G[Step 7: 打包上传]
    G --> H[Step 8: 生产验证]
```

### 📁 官方标准文件结构

```
skill-name/
├── SKILL.md              # 技能描述文件 (必需)
├── instructions.md       # 核心指令 (必需)
├── scripts/              # 可执行脚本 (可选)
│   ├── main.py
│   └── utils.js
├── resources/            # 资源文件 (可选)
│   ├── data.json
│   ├── templates/
│   └── examples/
└── tests/                # 测试文件 (可选)
    └── test_cases.md
```

```yaml

  总分 ≥ 15: 优先开发
```

```markdown
# 投资分析专家

- **版本**: v1.0.0
- **作者**: Your Name
- **分类**: business-analysis
- **标签**: 投资,分析,ROI,风险评估

## 功能描述
专业的投资分析技能，能够对项目进行全面的商业分析和投资建议。

### 主要用途
- 初创公司投资评估
- ROI计算和风险分析
- 市场机会评估
- 竞争格局分析

### 适用场景
- 天使投资决策支持
- VC投资尽职调查
- 企业战略投资分析
- 项目可行性评估

### 核心价值
- 结构化投资分析框架
- 多维度风险评估
- 数据驱动的决策支持
- 标准化报告输出
```

```
- 投资建议

### 示例输出
```

...
```

## 依赖项
- **知识来源**: 投资分析框架、行业数据库
- **分析工具**: SWOT分析、财务模型
- **数据源**: 公开市场数据、行业报告

## 性能指标
- **分析时间**: 3-8分钟
- **准确率**: 85%+
- **适用复杂度**: 中到高复杂度项目

## 版本历史
- v1.0.0: 初始版本，基础投资分析功能
```

### 🧠 Step 4: 编写instructions.md (核心指令)

#### instructions.md设计原则

1. **角色定位明确**: 清晰定义Claude的专业身份
2. **流程标准化**: 将复杂分析分解为标准步骤
3. **输出结构化**: 确保输出格式一致
4. **质量控制**: 包含验证和优化机制

#### instructions.md完整示例
```markdown
# 投资分析专家 - 核心指令

## 技能角色定位
你是一位经验丰富的投资分析师，具备以下专业能力：
- 10年以上VC投资经验
- 深度的行业研究和市场分析能力
- 精通的财务建模和估值技术
- 全面的风险评估和管理能力
- 丰富的初创公司辅导经验

## 工作原则
1. **客观中立**: 基于数据和事实进行分析，避免主观偏见
2. **全面深入**: 从多个维度进行全面分析，不遗漏关键因素
3. **实用导向**: 提供可操作的投资建议，而非泛泛而谈
4. **风险第一**: 始终将风险控制放在首位
5. **持续学习**: 结合最新市场动态和行业趋势

## 分析框架

### 第一步：理解项目概况 (5分钟)
- **项目基本信息**: 名称、行业、阶段、团队背景
- **商业模式**: 价值主张、目标用户、收入模式
- **技术亮点**: 核心技术、创新点、竞争优势
- **初步判断**: 快速评估项目潜力和匹配度

### 第二步：市场分析 (10分钟)
- **市场规模**: TAM、SAM、SOM分析
- **增长趋势**: 历史增长率、未来预测、驱动因素
- **竞争格局**: 主要竞争对手、市场份额、差异化策略
- **行业趋势**: 技术发展、政策环境、消费习惯变化

### 第三步：商业模式分析 (8分钟)
- **价值主张**: 解决什么问题，为谁创造价值
- **收入模式**: 定价策略、收费方式、收入结构
- **成本结构**: 主要成本项、规模效应、成本控制
- **盈利能力**: 毛利率、净利率、盈亏平衡点

### 第四步：团队评估 (7分钟)
- **创始人背景**: 教育经历、工作经验、成功案例
- **团队构成**: 技能互补性、行业经验、稳定性
- **执行能力**: 产品开发、市场推广、融资能力
- **股权结构**: 股权分配、投资人背景、激励机制

### 第五步：财务分析 (10分钟)
- **历史财务**: 收入增长、成本控制、现金流状况
- **财务预测**: 未来3年收入、成本、利润预测
- **关键指标**: CAC、LTV、 churn率、ARPU等
- **资金需求**: 资金用途、烧钱速度、融资时间点

### 第六步：风险评估 (8分钟)
- **市场风险**: 竞争加剧、需求变化、政策风险
- **技术风险**: 技术可行性、知识产权、技术迭代
- **团队风险**: 关键人员依赖、团队能力、执行力
- **财务风险**: 资金链、盈利能力、成本控制

### 第七步：投资建议 (5分钟)
- **投资评级**: A/B/C/D级，明确投资建议
- **估值分析**: 合理估值区间、投资金额、股权比例
- **退出机制**: IPO、并购、回购等退出方式
- **投后管理**: 需要提供的支持和帮助

## 输出标准

### 报告结构
```
【投资分析报告】
一、执行摘要 (200字)
二、项目概况 (300字)
三、市场分析 (400字)
四、商业模式 (300字)
五、团队评估 (300字)
六、财务分析 (400字)
七、风险评估 (300字)
八、投资建议 (200字)
```

### 质量要求
- **数据支撑**: 所有结论都要有数据或事实支撑
- **逻辑清晰**: 分析逻辑清晰，因果关系明确
- **结论明确**: 投资建议明确，不含糊其辞
- **可操作性**: 建议具体可操作，有明确的行动步骤

### 风险提示
- **不确定性说明**: 明确指出分析中的不确定因素
- **假设条件**: 说明分析所基于的关键假设
- **限制因素**: 说明分析的局限性和可能的影响因素

## 知识来源
基于以下知识资源：
- **投资理论**: VC投资理论、估值模型、风险管理
- **行业数据**: 最新行业报告、市场研究数据
- **财务知识**: 财务分析、估值方法、建模技术
- **案例库**: 成功/失败投资案例分析

## 持续改进
- **反馈收集**: 收集用户反馈，不断优化分析方法
- **市场跟踪**: 持续跟踪市场变化，更新分析框架
- **案例积累**: 积累更多实际案例，提升分析准确性
```

### 🎯 案例: 30分钟构建"项目文档生成器"

让我们在30分钟内构建一个实用的项目文档生成器Skill。

#### 第1-5分钟: 需求分析和结构设计
```yaml
需求分析:
  问题: 每次新项目都要写重复的文档结构
  价值: 节省30分钟/项目 × 每月2个项目 = 1小时/月
  复杂度: 中等 (需要理解不同项目类型)
  标准化: 高 (有明确的文档规范)

技能设计:
  名称: project-docs-generator
  功能: 根据项目类型自动生成标准化文档
  输入: 项目名称、类型、技术栈
  输出: 完整的项目文档结构
```

#### 第6-15分钟: 创建文件结构和SKILL.md
```bash
# 创建文件夹
mkdir -p ~/.claude/skills/project-docs-generator
cd ~/.claude/skills/project-docs-generator

# 创建SKILL.md
cat > SKILL.md << 'EOF'
# 项目文档生成器

## 基本信息
- **技能名称**: 项目文档生成器
- **版本**: v1.0.0
- **作者**: Your Name
- **分类**: development-tools
- **标签**: 文档生成,项目初始化,开发工具

根据项目类型和技术栈，自动生成标准化的项目文档结构。

### 主要用途
- 新项目快速初始化
- 标准化文档结构生成
- 开发规范制定
- 团队协作文档准备

### 适用场景
- 新项目启动
- 代码库初始化
- 开发规范建立
- 文档体系搭建

### 核心价值
- 节省30分钟/项目的文档准备时间
- 确保文档标准化和完整性
- 提高团队协作效率
- 建立专业的开发规范

## 使用方式
```
/skill project-docs-generator "React电商项目，使用TypeScript和Tailwind"
```

## 输入参数
- **项目名称**: 项目名称
- **项目类型**: web-app/mobile-app/api/library等
- **技术栈**: 主要技术框架和工具
- **文档类型**: readme/api-docs/user-guide等 (可选)
```

### ❌ 问题1: 技能无法加载

#### 症状
```
Error: Skill 'skill-name' not found or failed to load
```

#### 解决方案
```bash
# 检查文件结构
ls -la ~/.claude/skills/skill-name/

# 检查必需文件
ls -la ~/.claude/skills/skill-name/SKILL.md
ls -la ~/.claude/skills/skill-name/instructions.md

# 检查ZIP结构
unzip -l skill-name.zip

# 重新打包
cd ~/.claude/skills/
zip -r skill-name.zip skill-name/ -x "*.DS_Store"
```

### ❌ 问题4: 技能与项目集成困难

#### 症状

- 技能路径配置错误
- 团队成员无法访问共享技能

#### 解决方案
```bash
# 项目级技能配置
mkdir -p your-project/.claude/skills/
cp -r ~/.claude/skills/your-skill your-project/.claude/skills/

# 团队共享配置
git add your-project/.claude/skills/your-skill
git commit -m "Add shared skill: your-skill"

# 配置文件更新
echo "skills.enabled = true" >> your-project/.claude/settings.json
```
