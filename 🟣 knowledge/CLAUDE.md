## 5 通道搜索流程
参考 `05_方法论中心/AI_Context_实施方法论_掘金最佳实践_2025-10-14.md`。

| 通道 | 目标 | 推荐工具/路径 |
| --- | --- | --- |
| 核心主题深挖 | 解析关键机制、底层逻辑 | Tavily、knowledge-search、原始论文/报告 |
| 相关领域拓展 | 识别交叉领域、边界创新 | knowledge-graph、Jina-AI、方法论交叉引用 |
| 最新动态捕获 | 追踪近 6 个月资讯与案例 | Tavily、MediaCrawler（小红书/知乎/微博等） |
| 专家观点收集 | 聚合权威观点、访谈、演讲 | smithery-quote-finder、专业媒体 |
| 趋势信号识别 | 发现早期信号、模式 | 数据分析脚本、周报/指标库、`🔬 深度研究` |

执行步骤：
1. 在 checklist 中列明五通道任务。
2. 使用 `fd/rg/sg` 检查本地是否已存在相关资料。
3. 运行对应 MCP / 脚本抓取信息，并记录来源、时间、质量标签。
4. 将结果写入 `02_分析与洞察`，并在生成阶段引用。

## 质量控制
| 阶段 | 校验要点 |
| --- | --- |
| 搜索 | 权威性 > 完整性 > 时效性 > 多样性；记录可验证来源 |
| 批评 | 检查逻辑一致性、事实准确性、偏见与利益冲突 |
| 优化 | 信息整合、洞察提取、价值排序、可行性评估 |
| 验证 | 多方验证、专家咨询、实证检验、持续更新 |

- 输出前必须说明验证方式（示例：`来源：CB Insights，2025-09；交叉验证：Crunchbase`）。
- 结论形成需遵循“判断 → 趋势 → 结论”模式，并记录在对应方法论 README。
