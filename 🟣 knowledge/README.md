# 知识域总览

## 使命与焦点
- 建立“判断 → 趋势 → 结论”闭环，把散落信息沉淀为可复用方法论。
- 维护五通道搜索体系，支撑业务、技术、设计等域的决策与内容生产。
- 管理知识资产生命周期：采集、分析、生成、归档、复盘。

## 工作流对照
0. **草稿缓冲**：`🤖 AI生成 auto-generated/日期` 暂存生成内容，24 小时内完成校对与迁移。
1. **采集**：`01_Inbox` 记录来源与时间戳，标注“人工/自动生成”。
2. **分析**：迁移至 `02_分析与洞察`，应用五通道框架、补充引用。
3. **生成**：根据目标输出到 `03/07/08`，补 frontmatter 与指标。
4. **回写**：更新 `memory-bank`、方法论，总结关键洞察，通知业务/技术域。

## 协作依赖
- **技术域**：同步实现方案、性能数据，形成技术案例或方法论。
- **业务服务域**：将研究转换为客户提案、市场材料。
- **深度研究域**：输出长线研究时共享底层数据与推理。
- **设计域**：协同视觉化模板、品牌风格与传播素材。
- **自动化实验室**：与 `🧩 bmad` 协作，将重复性采集和报告生成沉淀为脚本并记录使用指南。
