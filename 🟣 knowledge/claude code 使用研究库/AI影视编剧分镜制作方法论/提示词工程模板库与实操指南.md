## 🎯 提示词工程核心原则

### 三大黄金法则
1. **一致性第一**: 角色外观、场景描述必须完全一致
2. **瞬间性描述**: 描述静态画面，而非持续动作
3. **时长控制**: 每个动作必须在5-10秒内完成

### 质量控制检查清单
```markdown
## 文生图提示词检查
- [ ] 角色描述是否完整？（年龄、性别、服装、发型）
- [ ] 景别是否符合视角要求？
- [ ] 场景描述是否具体？
- [ ] 风格是否统一？
- [ ] 光影是否合理？

## 图生视频提示词检查
- [ ] 时长是否在5-10秒内？
- [ ] 动作是否连贯？
- [ ] 是否有稳定性要求？
- [ ] 是否承接上一帧？
- [ ] 结尾是否有强调？
```

## 📚 常见问题解决方案

### 问题1: 角色不一致
```markdown
## 解决方案
1. **建立角色档案**: 详细记录每个角色的特征
2. **使用模板**: 每次使用相同的角色描述模板
3. **强调一致性**: 在提示词中加入"保持与前一镜头一致"
4. **后期修正**: 必要时使用图像编辑工具调整

## 预防措施
- 在项目开始前创建角色表
- 使用标准化的角色描述格式
- 保存成功的角色提示词模板
```

### 问题2: 动作不自然
```markdown
## 解决方案
1. **简化动作**: 将复杂动作拆分为简单步骤
2. **增加过渡**: 在动作间加入过渡描述
3. **使用修饰词**: 加入"缓慢地"、"轻轻地"等词
4. **参考真实**: 观察真实人物的动作方式

## 预防措施
- 动作描述要符合物理规律
- 避免过于复杂的复合动作
- 考虑AI工具的技术限制
```

### 问题3: 场景转换突兀
```markdown
## 解决方案
1. **明确场景标识**: 每个场景清楚标注
2. **增加过渡镜头**: 使用转场场景
3. **保持空间逻辑**: 确保空间转换合理
4. **统一光照**: 保持光源逻辑一致

## 预防措施
- 绘制场景布局图
- 记录每个场景的特征
- 建立场景转换规则
```
