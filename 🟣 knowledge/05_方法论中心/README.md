## 📋 核心定位

方法论中心是LaunchX三级开发体系的**方法论支撑核心**，为Level S（直接对话）、Level M（搜索/MCP驱动）、Level L（结构化执行）提供完整的方法论指导。经过系统性优化整合，从14个方法论域精简为7个核心域，基于三大核心能力体系重组，对应各大业务板块的核心目的，形成完整的方法论体系支撑整个系统的运作。

> 📌 **设计原则**：所有方法论专注逻辑策略和思维框架，避免代码实现细节；基于 LaunchX 已落地案例和复盘结论；外部资料仅用于对照优化，不直接写入正文。

## 📋 使用指南

### 🎯 如何快速找到需要的方法论？

**方法1：按问题类型查找**
1. 明确你要解决的具体问题类型
2. 查看上面的【应用场景分类】表格
3. 选择对应的推荐方法论域

**方法2：按能力需求查找**
1. 明确你需要提升的能力类型
2. 查看上面的【能力类型分类】表格
3. 选择对应的方法论域

**方法3：按项目阶段查找**
- **投资决策阶段**: 💰 投资决策方法论
- **设计优化阶段**: 🎨 设计系统方法论
- **知识管理阶段**: 📚 知识管理方法论
- **深度研究阶段**: 🔬 深度研究方法论

### 🚀 如何使用方法论？

**按开发级别选择**：
- **Level S（直接对话）**：选择快速决策方法论，适用于单问题或策略建议场景
- **Level M（搜索/MCP驱动）**：选择分析和研究方法论，适用于需查资产或外部资料的任务
- **Level L（结构化执行）**：选择系统化实施方法论，适用于涉及代码、流程、跨域影响的复杂任务
- **大型文件开发专项**：当文档>5,000词、涉及多域、需系统架构或包含复杂决策时，启动大型文件深度开发方法论[[专项方法论/大型文件深度开发方法论_V1.0_20251101.md:1]]

**新手路径**：
1. **任务级别识别**: 明确任务属于Level S/M/L中的哪个级别
2. **方法论选择**: 根据问题类型和开发级别选择合适的方法论域
3. **框架学习**: 理解方法论的核心框架和原则
4. **实际应用**: 在项目中具体应用方法论
5. **效果评估**: 评估应用效果并持续优化

**专家路径**：
1. **快速匹配**: 直接根据经验选择合适的方法论
2. **灵活调整**: 根据具体情况调整方法论应用
3. **深度应用**: 在多个项目中深度应用方法论
4. **经验沉淀**: 将应用经验沉淀为最佳实践
