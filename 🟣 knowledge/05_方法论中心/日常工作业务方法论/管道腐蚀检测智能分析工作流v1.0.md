# 管道腐蚀检测智能分析工作流v1.1

> **核心理念**: 基于MCP图像采集技术，实现从照片分析到专业检测报告的智能化工作流，确保数据的真实性和分析的专业性
>
> **版本**: v1.1 | **状态**: ACTIVE | **最后更新**: 2025-11-17

---

## 🚀 工作流概览

### v1.0五步智能分析流程

```
STEP1: 照片采集 → STEP2: 图像分析 → STEP3: 数据提取 → STEP4: 风险评估 → STEP5: 报告生成
```

### 核心创新点

1. **MCP图像深度采集**: 使用Playwright MCP工具进行4倍放大精确分析
2. **全网络扫描识别**: 完整识别管道网络和所有腐蚀点
3. **数据一致性验证**: 多维度数据交叉验证确保准确性
4. **中国国企语言适配**: 符合国企技术文档标准的语言风格
5. **三级风险分类**: 高危、中危、低危标准化评估体系

def step3_data_extraction(corruption_data):
    # 管道规格标准化
    pipeline_spec = {
        "diameter": "DN150",
        "material": "Q235B碳钢",
        "design_thickness": "5.0mm",

        "service_years": calculate_service_years()

    structured_data = []
    for point in corruption_data["corruption_points"]:

            "point_id": point["id"],
            "location": point["spatial_location"],
            "corrosion_depth": estimate_corrosion_depth(point),
            "remaining_thickness": calculate_remaining_thickness(point, pipeline_spec),
            "corrosion_percentage": calculate_corrosion_percentage(point, pipeline_spec),
            "risk_level": assess_risk_level(point),
            "network_position": classify_network_position(point)
        }
        structured_data.append(corrosion_record)

    # 数据一致性验证
    data_validation = validate_data_consistency(structured_data)

    return {
        "pipeline_specifications": pipeline_spec,

    }

def step4_risk_assessment(structured_data):
    # 应用GB/T 21447-2018标准
    risk_assessment = {
        "standard_compliance": apply_gb_standards(structured_data),
        "risk_classification": classify_risk_levels(structured_data),
        "structural_integrity": assess_structural_integrity(structured_data),
        "safety_impact": evaluate_safety_impact(structured_data)
    }

    # 三级风险分类
    risk_levels = {

            "criteria": "剩余壁厚 < 2.0mm 或 腐蚀率 > 60%",

        },
        "medium_risk": {
            "criteria": "剩余壁厚 2.0-3.5mm 或 腐蚀率 30-60%",

            "count": calculate_medium_risk_points(structured_data)
        },
        "low_risk": {
            "criteria": "剩余壁厚 > 3.5mm 或 腐蚀率 < 30%",

            "count": calculate_low_risk_points(structured_data)
        }
    }

    # 综合风险评估
    overall_risk = calculate_overall_risk_assessment(structured_data, risk_levels)

    return {
        "risk_classification": risk_levels,
        "overall_risk_level": overall_risk["risk_grade"],
        "critical_points": identify_critical_points(structured_data),
        "recommendations": generate_risk_recommendations(overall_risk)
    }

| 腐蚀率 | > 60% | 30-60% | < 30% |

## 🔥 用户反馈优先级分析与经验总结

### 📊 反馈优先级分级体系

基于项目执行过程中的用户反复纠正要求，建立8级优先级体系，指导后续工作流优化：

#### 🚨 Level 1 (最高优先级): 严禁假设性推算
**用户反复强调**: "禁止假设性推算"
**实施要求**:
- 所有数据必须基于实际MCP工具分析结果
- 严禁使用"假设"、"推算"、"可能"等不确定性表述
- 每个数据点必须有可追溯的照片来源
- 实际检测数据与推算数据必须明确区分

**典型用户反馈**:
- "测点3已完全穿透（0mm剩余壁厚），可见明显穿孔" - 强调实际观测结果
- "基于4倍放大照片确认" - 强调分析工具的实际应用

#### 🔍 Level 2: 全面数据采集完整性
**用户反复强调**: "扫描整个管道网络"
**实施要求**:
- 必须识别照片中所有可见腐蚀点
- 主干线和分支管道全覆盖
- 腐蚀密度和分布特征详细记录
- 空间分布模式分析

**典型用户反馈**:
- "识别出15个主要腐蚀聚集点"
- "主干线腐蚀点（9个），分支管道腐蚀点（6个）"

#### 🎯 Level 3: 专业建议与决策边界
**用户反复强调**: "明确区分检测结论与建议"
**实施要求**:
- 检测结论基于数据，建议基于专业判断
- 明确标注"最终决策权：是否更换管道由甲方决策"
- 技术建议必须具备可操作性
- 避免过度承诺或绝对性表述

**典型用户反馈**:
- "本报告仅陈述检测事实与可复查数据。是否更换管道由甲方决策，本团队不承担决策责任"

#### 📋 Level 4: 数据一致性强制要求
**用户反复强调**: "执行摘要与详细分析数据完全对齐"
**实施要求**:
- 执行摘要数字与详细表格严格一致
- 统计分类与个体数据匹配
- 风险等级与腐蚀数据科学对应
- 建议措施与风险评估结果一致

**典型用户反馈**:
- "平均剩余壁厚2.79mm" 在各章节中保持一致
- "33.3%严重腐蚀" 在统计表和分布分析中一致

#### 🏗️ Level 5: 全区域分析一致性
**用户反复强调**: "每个区域都要按相同标准分析"
**实施要求**:
- A区、B区、D区采用统一分析方法
- 相同的管道规格假设（DN150，Q235B碳钢，5.0mm壁厚）
- 统一的风险等级判定标准
- 一致的数据提取和报告格式

#### 📏 Level 6: 风险等级标准化
**用户反复强调**: "高危、中危、低危三级分类"
**实施要求**:
- 基于剩余壁厚和腐蚀率的双重标准
- 统一的数值判定阈值

**标准化阈值**:
- 高危: 剩余壁厚 < 2.0mm 或 腐蚀率 > 60%
