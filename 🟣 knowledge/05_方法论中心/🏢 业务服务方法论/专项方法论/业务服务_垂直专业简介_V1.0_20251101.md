# 业务服务垂直专业简介

## 4. 关键指标
| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 需求分析准确率 | ≥90% | 诊断阶段通过结构化访谈 + 数据分析实现 |
| 方案成功率 | ≥80% | 共创方案通过试点验证和客户评分 |
| 交付效率提升 | ≥50% | 敏捷交付 + 共创流程协同 |
| 客户满意度 | ≥90% | NPS/满意度调研与复盘 |

## 5. 典型场景
1. **AI 顾问快速陈述（Level S）**：使用本简介概括服务边界、指标与案例，构建信任。
2. **企业战略共创（Level L）**：依据共创方法论搭建项目结构，串联诊断→路线→执行。
3. **转型复盘分享（Level M）**：提炼转型案例与 ROI 数据，支持销售或复购沟通。
