# 深度研究垂直专业简介

## 1. 域定位
深度研究域专注多通道趋势分析、知识碎片挖掘与洞察输出，目标实现研究自动化率 ≥80%、洞察生成时间 ≤4 小时、趋势预测准确率 ≥85%、研究 ROI 27.5 倍[[🟣 knowledge/05_方法论中心/README.md:90-99]][[🟣 knowledge/05_方法论中心/🔬 深度研究方法论/专项方法论/深度研究方法论_整合版_V1.0_20251028.md]]。

## 2. 核心痛点与价值命题
| 痛点 | LaunchX 价值命题 | 方法论支撑 |
| --- | --- | --- |
| 趋势研究流程漫长、重复劳动多 | 整合版方法论提供 5 通道并发搜索 + 自动化分析框架 | 《深度研究方法论_整合版_V1.0_20251028》 |
| 技术/投资研究标准不统一 | 技术/投资方法论合集提供行业/技术专题研究模板 | 《深度研究_技术方法论合集_V1.0_20251028》《深度研究_投资方法论合集_V1.0_20251028》 |
| 碎片知识难以沉淀、复用 | 知识库碎片挖掘工具 + archived 碎片方法论构建碎片库 | 《深度研究_知识库碎片挖掘工具方法论_V1.0_20251028》 |
| 研究成果无法快速反馈业务 | 结合投资/业务方法论，输出可执行洞察与决策建议 | 与投资/业务服务方法论互链 |

## 3. 方法论体系
- **多通道研究闭环**：Collect → Normalize → Analyze → Deliver，结合 5 通道搜索与自动化分析[[🟣 knowledge/05_方法论中心/🔬 深度研究方法论/专项方法论/深度研究方法论_整合版_V1.0_20251028.md]]。
- **专题研究模板**：技术与投资合集提供标准结构与指标，便于 Level M/L 复用。
- **碎片治理**：碎片挖掘工具 + archived 碎片（20250823）形成反脆弱知识库。

## 4. 关键指标
| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 研究自动化率 | ≥80% | 自动化脚本/工具使用覆盖 |
| 洞察生成时间 | ≤4 小时 | 从 Collect 到 Deliver 的 SLA |
| 趋势预测准确率 | ≥85% | 预测与实际对比 |
| 研究 ROI | 27.5× | 洞察带来的业务/投资价值 |

## 5. 典型场景
1. **Level S（趋势速览）**：用简介快速说明研究能力、指标与输出形式。
2. **Level M（专题研究）**：采用技术/投资合集模板，完成行业或技术专题。
3. **Level L（综合研究项目）**：结合 Collect→Deliver 流程，生产高价值研究报告并沉淀碎片。
