# 消费 AI 投资策略

## 1. 投资定位
聚焦“AI 赋能内容/社交/创作”的消费级产品，筛选具备“分发即产品”特征、10 人以内即可验证商业模式的团队，实现快速收益与高转化[[🟣 knowledge/05_方法论中心/README.md:71-88]]。

## 2. 核心投资理念
- **分发即产品**：内容生产与渠道增长深度一体化，分发能力本身构成护城河。
- **小而美**：10 人以内、具备病毒式传播与即时变现能力的小团队。
- **族谱导向**：重点关注“分发驱动型 AI 消费公司”与“社区平台型”两个族谱。

## 3. 评估框架
| 维度 | 关键问题 | 指标参考 |
| --- | --- | --- |
| 分发势能 | 用户获取是否依赖创始人 IP、社区或算法？ | 自然增长占比、内容裂变系数 |
| 产品范式 | 产品提供“杠杆”还是“代理”？是否直接卖成果？ | 付费转化率、单位经济盈利能力 |
| 技术护城河 | 数据闭环、模型/工作流深度、成本效率如何？ | 数据增量、推理成本、自动化水平 |
| 商业验证 | 是否实现稳定现金流？ROI 能否量化？ | 月度现金流、获客成本、回本周期 |
| 团队画像 | 创始人媒体属性、执行力、跨内容/技术能力 | 社媒曝光、内容产能、迭代速度 |

## 4. 族谱速览
- **分发驱动型 AI 消费公司**：依托短视频/社媒场景快速增长，需验证长期留存与商业模式。
- **社区平台型**：构建 UGC/社区生态，关注内容供给质量与网络效应[[🟣 knowledge/05_方法论中心/💰 投资决策方法论/投资_全局投资方法论_V3.0_20251028.md]]。

## 5. 投后协同要点
- **增长实验**：短周期 A/B 测试、渠道投放、社媒内容共创。
- **内容引擎**：联动品牌传播方法论，建立内容生产 SOP。
- **商业化**：探索“卖成果”模式（订阅 + 闭环服务），量化收益分成。
