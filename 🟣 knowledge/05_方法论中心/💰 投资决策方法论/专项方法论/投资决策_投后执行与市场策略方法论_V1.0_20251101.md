# 投后执行与市场策略方法论

> **定位**：LaunchX 在完成投资后，通过标准化的反馈闭环与工具栈赋能 Pocketcorn 项目，实现持续的“增长势能”与收入分成目标。

## 1. 投后管理目标
- **增长势能验证**：MRR/GMV 持续增长、留存率提升。
- **成果可量化**：投后 3-6 个月内明确 ROI 贡献、收益分成。
- **反馈闭环**：形成“市场→产品→商业化”快速迭代机制。

## 2. 市场反馈体系
### 2.1 多渠道采集
- **产品内反馈**：内嵌评分、Bug 上报、NPS 调研。
- **行为数据**：Mixpanel/Amplitude 跟踪功能使用、漏斗转化。
- **社交/社区监听**：舆情监测（微博、知乎、GitHub 等）。
- **线下访谈**：深度访谈 + 焦点小组补充定性洞察。
- **一线团队输入**：销售/客服/合作伙伴定期回报。

### 2.2 分析与优先级
- **定量 + 定性结合**：A/B 测试、情感分析、标签化。
- **优先级矩阵**：影响范围 × 业务价值 × 实现成本 × 紧急程度。
- **跨部门评审**：投资、产品、运营、增长联合评估，确保一致行动。

### 2.3 闭环落地
- **产品迭代**：纳入产品 Roadmap，迭代后再次验证。
- **商业模式调整**：定价、服务模式根据反馈优化。
- **GTM 策略更新**：营销信息、投放渠道实时调整。
- **投资策略反哺**：反馈沉淀至“被投项目画像”，指导下一轮投资。

## 3. 投后执行工具栈

## 4. 投后行动流程
1. **投后启动**（T+0~7 天）  
   - 建立 CRM 卡片与协同看板  
   - 明确 KPI、收益分成规则  
   - 制定市场反馈与数据采集计划

2. **快速验证**（T+30 天）  
   - 启动最小闭环：产品迭代 → 数据验证 → 反馈回路  
   - 输出首份市场反馈报告与行动清单

3. **价值创造**（T+90 天）  
   - 通过工具栈落地增长实验、渠道共创  
   - 更新收益预测模型；审视 ROI 与现金流  
   - 组织季度复盘会议（投资/项目/增长团队参与）

4. **持续优化**（T+180 天+）  
   - 纳入 LaunchX 知识库与案例库  
   - 调整投资策略与孵化方案  
   - 评估二轮融资或资源加速需求

## 5. 风险与对策
- **反馈信息噪音**：建立标签与优先级制度，压减无效需求。
- **执行落地延迟**：看板透明化 + 投后 OKR，确保闭环。
- **收益核算误差**：标准化收益模型 + BI 校验。
- **合规风险**：电子合同 + 法务顾问双重审查。

- **执行节奏**：
  1. **T+7**：完成渠道选择与内容模板配置，输出首版Owned Media素材。
  2. **T+30**：启动创始人社交脚本+媒体协同，至少完成一次跨渠道推送与成效记录。
  3. **T+60**：复盘投后增长飞轮数据，判定是否需要追加内容预算或触发Pocketcorn代付。
- **验证机制**：每次流量投放需附带指标截屏或BI链接，并在投后例会上回写到FlowOps仪表盘，确保“给钱=给流量”具备可追溯证据。
