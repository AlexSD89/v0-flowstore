# 投资项目评估手册

> **定位**：为 SPELO 的 Plan/Execute 阶段提供操作手册，通过“假设驱动投研流程 + 四维评估清单 + 三位一体结论模板”完成项目尽调与投资决策。

## 1. 假设驱动投研流程
1. **提出假设**：基于垂直简介、族谱与市场趋势构建投资假设。
2. **Collect**：收集创始人、技术、商业模式、市场验证数据及外部反馈。
3. **Model/Compare**：使用四维评估清单验证假设，并与历史案例对比。
4. **Align/Deliver**：使用“三位一体”模板输出投资结论、风险提示与决策建议。

## 2. 四维评估清单
### 2.1 创始人基因
- 技术深度、商业敏锐度、领域专长、执行协作能力。
- 主理人媒体/IP 能力匹配 “分发即产品” 模式。

### 2.2 技术壁垒
- 专有/闭环数据？产生数据飞轮？
- 工作流嵌入深度、算法/成本优势。
- 依赖基础模型的程度：薄封装 vs 复杂系统（代理、多模型编排）。

### 2.3 商业模式
- “卖工具”还是“卖成果”？单位经济是否健康。
- 收益权转让 + 分红模式的契合度，回本周期。

### 2.4 市场验证
- 痛点价值（高频/高价值）；
- PMF 信号：留存、付费、复购、NPS；
- 竞争格局与族谱匹配度（工作流渗透者、社区平台型等）。

## 3. 三位一体结论模板
用于投资备忘录或投资委员会材料。
```markdown
## 三位一体评估摘要
- Technology Moat：……
- Product Paradigm：……
- Market Validation：……
- 族谱匹配：工作流渗透者 / 社区平台型 / 高壁垒服务者 / 全栈颠覆者 / 分发驱动型消费AI
- 风险提示：……
- 决策建议：投资 / 继续观察 / 放弃
```

## 4. 使用说明
- 适用于投资流程的尽调阶段，与《投资决策_投后执行与市场策略方法论》联动，确保投后指标与评估假设一致。
- 完成评估后，将结论回写至 Notion 档案和族谱数据库。
