# 投资案例复盘工作法

## 1. 目标与原则
- **知识资产化**：将个人经验转为组织可复用的投资洞察。
- **决策优化**：验证假设、识别偏差、优化流程。
- **反脆弱**：把失误转化为未来的防御手册。
- **原则**：对事不对人、开放坦诚、以学习为导向。

## 2. 复盘流程
### Step 1｜Kick-off（启动）
- 明确复盘项目、阶段、核心参与人、复盘目标。
- 约定资料范围（投资备忘录、尽调报告、董事会材料等）。

### Step 2｜回溯原假设
- 市场机会、产品/技术、团队、商业模式、竞争格局。
- 记录当时的核心假设与已识别风险。

### Step 3｜对照现实
- **公司发展**：产品路线、团队变化、融资节奏。
- **市场竞争**：行业演化、竞品策略。
- **商业表现**：单位经济、现金流、盈利路径。
- **关键事件**：正向/负向事件与影响。

### Step 4｜洞察与偏差分析
- 假设验证 & 错误判断的“为什么”。
- “Why Now?” 时机复盘，识别关键变量。
- 族谱匹配与演化路径（对应 LaunchX 项目族谱）。
- 投后管理反思（支持成效与改进点）。

### Step 5｜沉淀与行动
- 提炼可泛化的经验/反模式。
- 更新 SPELO / Pocketcorn 模型参数。
- 衍生 TODO（如投资标准、投后支持、工具更新）。
- 将复盘成果归档至 `knowledge/投资经验/` 与案例库。

## 3. 支撑工具
- **资料库**：投前文档、项目档案、知识资产。
- **分析工具**：BI 看板、行为分析、财务模型。
- **协作平台**：Notion/Confluence（复盘模板）、飞书会议纪要。

## 4. 输出模板
```markdown
## 投资案例复盘摘要（示例）
- 项目阶段：A 轮 / 已退出 / 失败清算
- 原始假设：……
- 实际演变：……
- 偏差原因：……
- 族谱类型：工作流渗透者 / 高壁垒服务者 …
- 投后反思：……
- 下一步行动：……
```

## 5. 指标与维护
- 每季度至少完成 Top 项目的复盘。
- 复盘完成率、偏差信息闭环率、方法论更新率纳入 KPI。
