# 投资决策垂直专业简介

## 1. 域定位
LaunchX 投资决策域聚焦「AI 赛道中的高潜企业识别与投资组合设计」，通过 SPELO 框架和 Pocketcorn 多维度评分体系，实现 85%+ 的投资准确率与 27.5 倍 ROI[[🟣 knowledge/05_方法论中心/README.md:219-236]][[🟣 knowledge/05_方法论中心/💰 投资决策方法论/投资_全局投资方法论_V3.0_20251028.md]]。

## 2. 核心痛点与价值命题
| 痛点 | LaunchX 价值命题 | 方法论支撑 |
| --- | --- | --- |
| AI 投资赛道噪音大、信息冗余 | SPELO（Strategy/Product/Economics/Leadership/Operations）全栈评估，过滤噪音 | 《投资_全局投资方法论_V3.0_20251028》 |
| 分发型 AI 企业估值波动 | 「分发即产品」理念 + Pocketcorn 7 维度评分，量化分发能力 | 《Pocketcorn投资模式专项方法论_V1.0_20251028》 |
| 投后执行缺乏工具化 | 市场反馈策略、执行工具库，对接投后价值创造 | `投资决策_项目_执行工具与技术解决方案方法论_V1.0_20250823.md` |
| 行业趋势把握困难 | 族谱分析 + 趋势监测，提供季度趋势输出 | 《AI投资趋势综合方法论_V1.0_20251028》 |

## 3. 方法论体系（可复用框架）
- **SPELO 决策闭环**：策略→产品→经济模型→团队领导力→运营能力；用于 Level L 投资决策 / 尽调[[🟣 knowledge/05_方法论中心/💰 投资决策方法论/投资_全局投资方法论_V3.0_20251028.md]]。
- **Pocketcorn 投资模型**：7 维度评分（市场、产品、分发、数据、运营、技术、合规），结合 AI 投资趋势矩阵，输出投资优先级[[🟣 knowledge/05_方法论中心/💰 投资决策方法论/专项方法论/Pocketcorn投资模式专项方法论_V1.0_20251028.md]]。
- **执行工具栈**：市场反馈策略、执行工具与技术解决方案、案例复盘等专题方法论，为投后运营提供 SOP[[🟣 knowledge/05_方法论中心/💰 投资决策方法论/专项方法论/投资决策_项目_市场反馈策略方法论_V1.0_20250823.md]]。

## 4. 关键指标与目标
| 指标 | 目标值 | 来源 / 说明 |
| --- | --- | --- |
| 投资准确率 | ≥85% | SPELO+Pocketcorn 多维评估[[🟣 knowledge/05_方法论中心/README.md:219-236]] |
| 风险评估命中率 | ≥90% | 风险识别框架 + 历史案例复盘 |
| 投资 ROI | ≥27.5× | Pocketcorn 核心案例复盘数据 |
| 决策效率 | +60% | SPELO 标准化表单 + MCP 调研工具组合 |

## 5. 典型场景
1. **早期项目尽调（Level L）**：使用 SPELO 表单 + Pocketcorn 评分，7 天内完成投资提案，输出风险及投后计划。
2. **季度趋势报告（Level M）**：基于《AI投资趋势综合方法论》输出季度热点赛道、估值区间与竞争态势。
3. **投后价值提升（Level M/L）**：调用执行工具方法论，为被投企业构建市场反馈机制、增长黑客行动计划。
