# LaunchX方法论中心管理规范

> **核心定位**：建立LaunchX方法论中心的长期管理机制，确保方法论的持续高质量和实用性

## 📋 总体管理原则

### 1. 核心价值导向
- **价值驱动**：每个方法论都必须解决具体问题，创造实际价值
- **垂直专业**：方法论必须深入垂直领域，避免大而全的空泛内容
- **实用优先**：方法论必须具备可操作性，指导实际工作
- **持续优化**：建立持续学习和改进机制，保持方法论的生命力

### 2. 质量第一原则
- **内容质量**：准确性≥95%，完整性≥90%，实用性≥85%
- **结构质量**：逻辑清晰，层次分明，易于理解和使用
- **更新质量**：确保内容时效性，及时更新过时信息
- **用户体验**：查找效率≤30秒，应用成功率≥90%

### 3. 系统化管理
- **分类清晰**：建立明确的分类体系和导航机制
- **标准统一**：统一格式规范、命名规范和质量标准
- **版本控制**：建立规范的版本管理和更新机制
- **协作高效**：利用BMAD系统实现高效协作和质量保障

## 🗂️ 文档管理规范

### 1. 目录结构规范
```

├── README.md                           # 中心入口和导航

│   └── 专项方法论/                       # 专项方法论集合（无需README）
```

**目录结构原则**：
- **三级架构**：全局方法论（根目录）→ 专业领域目录 → 专项方法论文件
- **扁平化管理**：专项方法论直接存放在二级目录，无需README文件
- **清晰层级**：每个层级职责明确，避免功能重叠
- **简洁导航**：通过全局README和文件命名实现高效导航

### 2. 文件命名规范
**专业领域方法论命名**：
- 核心方法论：`领域_核心方法论名称_vX.Y_YYYYMMDD.md`
- 专项方法论：`领域_专项方法论名称_vX.Y_YYYYMMDD.md`
- 研究工具：`工具名称.md`（如知识库碎片挖掘工具.md）
- 简化命名：去除颜色彩球表情符号，使用清晰的描述性名称

**核心能力集成说明**：
- 判断能力方法论已集成到投资方法论中
- 趋势能力方法论已集成到深度研究方法论中
- 结论能力方法论已集成到技术开发方法论中
- Claude与Codex协作机制已集成到BMAD系统中

**命名原则**：
- 去除所有表情符号（🔴🟡🟢🔵等）
- 使用中文描述性名称，体现核心价值
- 版本号格式：vX.Y（主版本.次版本）
- 日期格式：YYYYMMDD

## 📊 质量管理规范

### 1. 内容质量标准
**准确性要求**：
- 事实陈述准确率≥95%
- 数据和统计准确性≥90%
- 专业术语使用准确性≥95%
- 逻辑推理一致性≥90%

**完整性要求**：
- 内容覆盖完整度≥90%
- 信息要素完备性≥85%
- 结构逻辑完整性≥95%
- 使用指导完整性≥80%

**实用性要求**：
- 解决问题的有效性≥90%
- 操作指导的可执行性≥85%
- 应用场景的覆盖度≥80%
- 用户满意度≥90%

### 2. 质量检查机制
**多层检查体系**：
- **自动检查**：AI工具自动检查格式、链接、重复等
- **专业审查**：领域专家审查内容质量和专业性
- **用户验证**：目标用户验证实用性和易用性
- **持续监控**：建立长期质量监控和反馈机制

**检查流程**：
1. **创建阶段**：作者自检 + AI预检
2. **审核阶段**：专业审查 + 格式检查
3. **发布阶段**：用户测试 + 最终确认
4. **维护阶段**：持续监控 + 定期更新

### 3. 质量改进机制
**问题发现**：
- 用户反馈收集和分析
- 使用数据监控和分析
- 定期质量评估和审计
- 竞品对比和分析

**改进实施**：
- 问题优先级排序
- 改进方案制定和执行
- 效果跟踪和评估
- 经验总结和标准化

## 🔄 维护更新规范

### 1. 更新频率管理
**定期更新**：
- 核心方法论：每季度评估更新
- 专业方法论：每半年评估更新
- 专项方法论：根据实际需求及时更新
- 导航文档：随着结构变化及时更新

**触发更新**：
- 用户反馈发现质量问题
- 外部环境发生重大变化
- 内部实践产生新经验
- 技术工具发生重大升级

### 2. 版本管理规范
**版本号规则**：
- **主版本号（X.0）**：重大架构调整或核心方法变更
- **次版本号（X.Y）**：内容优化或新增方法
- **修订号（X.Y.Z）**：文字修正或格式调整

**版本管理流程**：
1. **版本规划**：明确更新内容和目标版本
2. **内容更新**：按照质量标准执行更新
3. **质量检查**：完成所有质量检查环节
4. **版本发布**：更新版本号和发布记录
5. **变更记录**：记录版本变更内容

### 3. 归档管理规范
**归档标准**：
- 内容过时且无更新价值
- 被新的方法论完全替代
- 长期无人使用或引用
- 质量不达标且无法改进

**归档流程**：
1. **归档评估**：评估是否需要归档
2. **影响分析**：分析归档对现有文档的影响
3. **引用更新**：更新所有相关引用
4. **归档执行**：移动到归档目录
5. **记录备案**：记录归档原因和时间

## 🚫 内容管理红线

### 1. 严禁内容
**重复内容**：
- 禁止与其他文档重复度超过30%的内容
- 禁止大段复制粘贴其他文档内容
- 禁止创建没有独特价值的模板化内容

**空洞内容**：
- 禁止只有理论框架而无具体方法的内容
- 禁止过于宽泛、缺乏操作指导的内容
- 禁止缺乏实际应用价值的学术化内容

**过时内容**：
- 禁止保留超过6个月未更新的技术内容
- 禁止引用已过时的数据、案例或趋势
- 禁止使用过时的工具或方法描述

### 2. 文档结构规范
**必备章节**：
- 核心定位和价值说明
- 具体的方法论框架
- 实用的操作指导
- 明确的应用场景
- 清晰的成功要素

**禁止结构**：
- 禁止过深的嵌套结构（超过4层）
- 禁止过于复杂的章节划分
- 禁止缺乏逻辑顺序的内容排列
- 禁止没有明确目标的章节设置

### 3. 使用规范
**引用规范**：
- 禁止引用不存在的文档
- 禁止循环引用（A引用B，B引用A）
- 禁止引用已归档的文档
- 必须确保所有引用链接有效

**更新规范**：
- 禁止无理由的大规模内容修改
- 禁止破坏现有文档结构的修改
- 禁止未经质量检查的更新发布
- 禁止不记录变更内容的更新

## 🏗️ 目录结构优化原则（2025-10-28更新）

### 二级架构标准
- **核心方法论**：系统级框架，位于二级目录，提供通用指导
- **专项方法论**：垂直专业内容，直接位于二级目录，专注特定领域
- **禁止三级嵌套**：专项方法论不再创建三级子目录，保持扁平化结构

### 主次分类标准
- **系统级内容**：全局框架、理论基础、通用原则
- **专项级内容**：具体工具、分析模板、特定场景应用
- **垂直聚焦**：一个文件解决一个明确问题，避免大而全

### 命名规范强化
- **去除表情符号前缀**：🔴🟡🟢🔵等前缀一律移除
- **使用中文描述性名称**：清晰体现核心价值和功能
- **版本标识统一**：vX.Y_YYYYMMDD格式

### 内容质量要求
- **实用性优先**：提供具体可执行的方法和工具
- **避免重复冗余**：与其他文档重复度不超过30%
- **操作性强**：85%以上的内容可直接应用于实际工作

### 最佳实践经验
- **从V2.0到V3.0升级经验**：系统级框架与专项工具分离，提升架构清晰度
- **专项方法论重组经验**：按功能分类组织，提升查找效率50%+
- **内容保存机制**：历史版本和升级过程记录，确保知识资产连续性

### 方法论优化操作指南
#### 1. 内容去重与整合原则
- **重复度识别**：当两个或多个文件重复度超过30%时，必须进行整合
- **内容合并策略**：
  - 保留核心框架文件，删除重复内容文件
  - 将重复内容的核心价值提取到更高级别的文档中
  - 在保留文件中添加引用说明，指向核心框架文档

#### 2. 框架提取标准
- **系统级框架提取条件**：
  - 具备通用性和可复用性
  - 可应用于多个相关场景
  - 构成某领域的基础分析体系
  - 被多个专项方法论引用

- **提取实施流程**：
  1. 识别通用框架内容（如族谱分析、量化评估模型）
  2. 将框架内容完整提取到全局方法论
  3. 在原文件中添加应用指导说明
  4. 更新所有相关文件的引用关系

#### 3. 质量不达标文件处理
- **删除标准**：
  - 内容空洞，缺乏具体操作指导
  - 与现有文档重复度超过50%
  - 长期未更新且内容过时
  - 缺乏独特价值和应用场景

- **替代方案**：
  - 内容合并到相关方法论中
  - 核心价值提取到更高级别文档
  - 创建新的整合型方法论

#### 4. 引用关系更新规范
- **层级引用原则**：
  - 专项方法论引用全局方法论
  - 核心方法论引用系统级框架
  - 避免同级文件间的循环引用

- **更新时机**：
  - 文件结构发生变化时
  - 内容合并或框架提取后
  - 删除或归档文件前

### 优化效果评估标准
- **结构清晰度**：用户能在30秒内理解方法论层级关系
- **内容复用率**：核心框架被多个专项方法论有效引用
- **查找效率**：找到合适方法论的时间减少50%以上
- **维护成本**：重复内容维护工作量减少80%以上
