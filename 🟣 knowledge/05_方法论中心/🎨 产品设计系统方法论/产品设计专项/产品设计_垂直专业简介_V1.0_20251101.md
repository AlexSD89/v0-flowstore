# 产品设计垂直专业简介

## 3. 方法论体系
- **诱饵式体验三层架构**：品牌叙事→互动设计→数据回路，覆盖从策略到实验验证的闭环[[🟣 knowledge/05_方法论中心/🎨 产品设计系统方法论/产品设计专项/产品设计_AI时代产品创新设计方法论_V1.0_20251028.md]]。
- **设计系统标准化**：组件库、规范、审查流程，保证多端体验一致性[[🟣 knowledge/05_方法论中心/🎨 产品设计系统方法论/产品设计专项/产品设计_设计_LaunchX设计系统方法论_V3.0_20250823.md]]。
- **图文一体化内容引擎**：内容模块化 + AI 生成策略，提高内容产出与转化[[🟣 knowledge/05_方法论中心/🎨 产品设计系统方法论/产品设计专项/产品设计_图文一体化内容设计方法论_V1.0_20251028.md]]。

## 4. 关键指标
| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 用户体验满意度 | ≥85% | 来自用户调研/NPS |
| 设计一致性 | ≥90% | 设计系统稽核 |
| 转化率提升 | ≥40% | A/B 测试 & 漏斗分析 |
| 创新设计度 | ≥80% | 设计评审与市场反馈 |

## 5. 典型场景
1. **产品策略对齐（Level S）**：使用本简介快速对齐产品体验目标、指标、案例。
2. **体验规划（Level M）**：结合诱饵式体验方法论制定旅程、指标与实验计划。
3. **多端协同交付（Level L）**：应用设计系统方法论与图文一体化策略执行复杂项目。
