# 图文一体化设计方法论 v1.0

## 01. 适用场景
- 品牌宣传页、报告、社交媒体素材（微博/小红书/知乎）。
- 运营快讯、产品发布、调研摘要需要“图文成稿”的场景。
- 与 Claude Code 协同生成初稿，再由设计/内容团队精修。

## 02. 内容结构模板
| 模块 | 说明 | 建议比例 |
| --- | --- | --- |
| 开篇画面 | 主视觉、标题、核心承诺 | 20% |
| 场景故事 | 痛点 / 期待 / 解决方案 | 25% |
| 功能亮点 | 3-4 个卖点 + 图标/插画 | 25% |
| 证据支撑 | 数据、案例、客户语录 | 15% |
| 行动引导 | CTA + 渠道二维码/链接 | 15% |

### 2.1 Markdown 模板
```markdown
## ⏱ 痛点 / 场景引入
> 用一句话抓住注意力

## 💡 解决方案主张
> 用两句话说明我们如何解决

### ✨ 核心亮点
1. 亮点一（附图）
2. 亮点二（附图）
3. 亮点三（附图）

### 📊 佐证数据
- 指标/客户案例

### 🚀 行动引导
> CTA：立即体验 / 获取白皮书
```

## 03. 视觉系统
- **版式**：采用 12 列栅格；移动端 4 列；优先单双列交替排版。
- **图文配比**：1:1 或 2:1（图：文），保持视觉呼吸空间。
- **图标/插画**：从 `🎨 设计美学资源库/Icon & Illustration/` 选择或使用 Figma 组件。
- **色彩策略**：主色参考品牌色板，图片可叠加渐变蒙版增强统一性。
- **动效原则**：微动效强调关键文案（淡入、滑入、光效），不超过 3 种。

## 04. 协作流程（设计 × 内容 × AI）
```
1. 内容初稿：使用 Claude 模板生成结构草稿
2. 资料收集：MediaCrawler、Tavily 获取最新案例/数据
3. 视觉设计：Figma 组合模板 + 组件
4. 复核 & 质检：品牌一致性、语气、数据来源
5. 导出：PNG/MP4/GIF + Markdown 正文 + frontmatter
6. 归档：内容至 `08_知识传播与品牌/`，素材至 `🎨 设计美学资源库/`
```

## 05. Claude Code 提示片段
```
以“图文一体化设计方法论 v1.0”为框架，生成一份用于【场景】的内容：
- 用户痛点：...
- 核心方案：...
- 需要 3 个亮点，每个亮点提供一句佐证数据
- 输出 Markdown，保留 CTA 段落
```
