## 📋 执行摘要
- Stanford HAI 2025 报告验证了 **推理成本在 2023-2025 年下降 280 倍**，已成为 AI 赛道资本重新定价的核心变量。
- 成本曲线重塑了竞争结构：基础层集中化、应用层民主化并存，小团队可凭成本效率与垂直化策略切入高价值场景。
- 对投前评估的启示：估值模型需引入“单位推理成本”“成本折旧速率”指标，重点关注能证明成本护城河的团队。

## 2. 对投资评估的三条核心启示
1. **成本效率优先于模型尺寸**  
   - 重点关注能证明 “推理成本/效果” 优势的公司：专用芯片、调度框架、推理中间件（如 FrugalML、Fireworks）、低延迟行业包。  
   - 在估值备忘录中新增指标：`Cost_per_call`, `Cost_decline_rate`, `Inference_margin`。

2. **应用层长尾将爆发**  
   - 成本门槛下降使垂直 SaaS、行业 Agent 出现“快速试错 + 规模复制”模式。  
   - 投资策略：优先看“成本敏感行业 + 刚需场景”——如客服、供应链优化、垂直知识服务。  
   - 需验证：是否具备流程化部署能力与行业数据闭环。

3. **基础层依旧集中但开放策略成趋势**  
   - 大厂 API 定价下调将压缩二次分销商利润，独立团队要通过增值能力（治理、安全、合规）构建护城河。  
   - 观察点：大模型厂商的推理优惠政策、生态合作条款、API 使用分级。

## 3. 投前尽调与估值模型调整
1. **尽调问卷新增**  
   - 请说明现阶段推理成本结构（模型、调度、硬件、缓存占比）以及两季度内的降本计划。  
   - 列出核心客户的成本节省案例：单位推理成本下降幅度、单位经济改善数据。  
   - 是否具备内部工具监控推理成本波动，并与 SLA/毛利绑定？

2. **估值模型调整**  
   - 在财务模型中加入“推理成本下降曲线”，设定乐观/基准/悲观三条场景。  
   - 对毛利率敏感性分析：若主流 API 均价季度下降 20%，公司付费策略如何变化？  
   - 若企业自建推理集群，占 Capex/Opex 比例如何变化？与公有云相比的盈亏平衡点。

3. **风险提示**  
   - 成本继续下探可能触发价格战，需评估公司对冲策略（订阅 → 使用量 → 结果付费）。  
   - 大模型厂商开放策略或新的专用芯片可能摊薄现有优势，关注技术锁定风险。

## 4. 投资组合建议
- **优先补充**：成本优化基础设施、可验证 ROI 的垂直 Agent 工具。  
- **保持跟踪**：具备行业数据壁垒且推理成本对盈利敏感的服务商。  
- **谨慎关注**：单纯依赖转售 API、缺乏差异化成本控制能力的团队。
