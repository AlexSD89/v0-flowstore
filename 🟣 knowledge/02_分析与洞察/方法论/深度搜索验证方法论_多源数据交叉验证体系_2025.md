### 第三阶段：定量评估体系

#### 3.1 准确性评估框架
```python
class PredictionAccuracyEvaluator:
    def __init__(self):
        self.categories = {
            "technical_predictions": 0.3,    # 技术预测权重30%
            "market_predictions": 0.3,       # 市场预测权重30%
            "policy_predictions": 0.2,       # 政策预测权重20%
            "business_predictions": 0.2      # 商业预测权重20%
        }

    def calculate_accuracy(self, predicted, actual, category):
        # 计算各类预测的准确度
        accuracy = self._compare_values(predicted, actual)
        weighted_accuracy = accuracy * self.categories[category]
        return weighted_accuracy

    def overall_assessment(self, results):
        # 综合评估所有类别的准确性
        total_accuracy = sum(results.values())
        return total_accuracy
```

#### 2.2 异常数据处理
```python
def detect_outliers(data_points):
    """
    检测和处理异常数据点
    """
    # 使用IQR方法检测异常值
    Q1 = np.percentile(data_points, 25)
    Q3 = np.percentile(data_points, 75)
    IQR = Q3 - Q1

    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR

    outliers = [x for x in data_points if x < lower_bound or x > upper_bound]
    return outliers
```
