# 📊 AI 项目研究分析 · 模块视图

## 模块使命
- 追踪全球 AI 项目，形成可复用的档案、洞察与指标库。
- 保持“线索 → 档案 → 分析 → 输出”的高速循环，为投资、业务、品牌提供事实底座。

## 数据分布地图
| 环节 | 路径 | 说明 |
| --- | --- | --- |
| 线索收集 | `01_Inbox/` · `🛠️@ai潜在学习项目总览.md` | 外部稿件、采访、会议纪要快速入池，24h 内迁移 |
| 档案沉淀 | `07_市场项目档案/` | 按行业/场景维护公司、案例、客户画像 |
| 分析框架 | `05_方法论中心/📚 知识管理方法论/` · `05_方法论中心/🛠️ 技术开发方法论/` | 分析范式、指标体系、写作模板 |
| 洞察输出 | `02_分析与洞察/` | 五通道校验后的结构化洞察、假设验证 |
| 研究成果 | `03_研究报告/` | 对外/内部正式报告、白皮书、演示材料 |
| 对外传播 | `08_知识传播与品牌/` | 渠道化内容，确保引用最新数据 |

## 标准流程
1. **线索入池**：将原始资料放入 `01_Inbox` 并记录来源与采集日期。
2. **查重与归档**：使用 `knowledge_audit.py` 报告与手动检索避免重复，在 `07_市场项目档案` 新建或更新条目。
3. **方法论对齐**：对照 `05_方法论中心` 的最新框架设置指标、标签、要素。
4. **结构化分析**：迁移至 `02_分析与洞察`，完成事实核验、趋势判断、交叉对比。
5. **成果发布**：将成熟内容编排到 `03_研究报告`（内部/外部版本），同步 `impact` 与 `related`。
6. **回写闭环**：在 README、周报、传播素材中更新引用，并在 `01_Inbox` 清空对应线索。

## 复查重点（2025-10-23）
- `07_市场项目档案` 内仍有大量缺失 frontmatter 的档案，需先批量补齐。
- `02_分析与洞察` 列表需重建索引，标注最新更新时间与责任人。
- 旧引用中仍存在 `knowledge/gen系列/`、`知识传播相关/` 等历史路径，需统一替换成现行目录。

## 质量标准
- 档案字段完整度 ≥ 95%，重要数据（估值、融资、关键指标）附来源与时间戳。
- 分析结论需列出交叉验证证据，遵循五通道流程。
- 任何报告发布后 24h 内更新 `related` 和 `impact` 字段，并在 `09_周报月报` 留痕。
