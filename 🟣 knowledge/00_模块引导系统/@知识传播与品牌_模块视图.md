- 将知识域与业务域的成果转译成各渠道可用的内容资产。
- 保证品牌语气、数据引用与视觉规范一致，并追踪传播效果。

## 标准工作流
1. **素材筛选**：从 `03_研究报告`、`07_市场项目档案`、`02_分析与洞察` 抽取最新判断，在传播域登记为待加工素材。
2. **策略匹配**：根据渠道目标查阅 `传播策略和风格` 中的指南，确定语气、结构与 CTA。
3. **生成与打磨**：结合模板、提示词与人工校对完成内容生产，遵循“去 AI 化”清单。
4. **发布与记录**：在渠道 README 中更新 `status`、发布时间、关键指标；必要时同步到 `09_周报月报`。
5. **数据回收**：收集阅读、互动、线索指标，写入传播周报并反馈给研究/业务团队。
6. **资产归档**：将成熟内容纳入 `08_知识传播与品牌` 对应目录，并在 `related` 字段关联原始研究。

## 复查重点（2025-10-23）
- `08_知识传播与品牌/三方文章/` 需新增 frontmatter 并标记引用来源。
- 渠道素材尚未建立按渠道分类的子目录，建议区分 `weibo` / `xhs` / `newsletter` 等。
- 对外物料更新后需同步 `🚀 Launchx业务服务/b_知识传播与品牌策略` 中的版本记录。

## 品牌一致性要求
- 数据引用必须回链到知识域文档，并注明更新时间。
- 语气参照 `传播策略和风格/深度内容传播策略与风格指南.md`，保留“专业 + 亲和”调性。
- 发布前通过同伴校对，检查 CTA、风险提示与法律合规条款。
