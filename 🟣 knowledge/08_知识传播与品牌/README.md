# 08_知识传播与品牌 · 输出规范

版本：2025-10-11 · 维护：Marketing Lab

## 1. 目录定位
承载 LaunchX 的对外传播素材、品牌策略和内容模板。所有对外输出需在此记录来源、状态与版本，确保可追溯与复用。

## 2. 目录结构
| 子目录 | 说明 |
| --- | --- |
| `传播策略和风格/` | 品牌语气、视觉规范、话术指南 |
| `三方文章/` | 对外投稿、媒体内容、合作案例 |
| `AI术语地图/` | 对外沟通常用术语解释 |
- 可根据渠道（微博/小红书/知乎等）建立子目录，配合 `memory-bank/support_modules/design/USEME.md` 的模板。

## 3. frontmatter 模板
```yaml
---
title: "20251012-渠道-内容主题"
owners: ["撰写人", "审核人"]
status: draft | review | scheduled | published
last_update: 2025-10-12
channel: weibo | xhs | zhihu | newsletter | media
related: ["🟣 knowledge/03_研究报告/...", "🎨 设计美学资源库/..."]
source: ["内部研究", "外部引用链接"]
impact: "触达新客户 / 品牌曝光 / 促进销售"
---
```

## 4. 工作流
1. 从 `03_研究报告`、`07_市场项目档案` 获取内容素材。
2. 结合 `🎨 设计美学资源库` 模板制作视觉稿。
3. 填写 frontmatter，明确渠道、状态、负责人。
4. 发布后更新 `status` 与 `last_update`，记录数据表现（阅读、转化）。
5. 在 `memory-bank/README.md` 或周报中标注“传播素材已更新”。

## 5. 品牌一致性
- 遵循 `传播策略和风格/` 中的语气、关键词、视觉规范。
- 需引用最新数据与来源，避免过期信息。
- 与 `memory-bank/support_modules/design/USEME.md` 的最佳实践同步更新。
