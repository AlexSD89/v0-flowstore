# 03_研究报告 · 输出规范

版本：2025-10-11 · 维护：Knowledge Lab

## 1. 目录定位
`03_研究报告` 汇总深度洞察、专题报告和综合分析，是“判断 → 趋势 → 结论”流程中的正式输出层。所有报告需可追溯、可验证、可复用。

## 2. 文件结构
- `行业/主题/年份` 等子目录可按需求设置，但需在 README 中列出索引。
- 推荐命名：`YYYYMMDD-主题-版本.md`，例如 `20251008-AI_Agent_趋势洞察-v1.md`。

## 3. frontmatter 模板
```yaml
---
title: "20251008-AI_Agent_趋势洞察-v1"
owners: ["分析人", "审核人"]
status: published | review | draft
last_update: 2025-10-08
related: ["🟣 knowledge/02_分析与洞察/...", "🟣 knowledge/05_方法论中心/..." ]
source: ["[[🟣 knowledge/01_Inbox/...]]", "外部链接"]
impact: "归纳行业趋势，指导投资与产品策略"
tests: "已验证：数据交叉核对/专家访谈"
---
```

## 4. 报告结构建议
```
1. 执行摘要（Summary / Testing / Next Steps）
2. 研究背景与问题陈述
3. 方法说明（引用 5 通道、数据来源、验证方式）
4. 核心洞察（分章节呈现，配图/图表）
5. 结论与建议（行动项 / 风险 / 下一步）
6. 附录：数据表、脚本、引用链接
```

## 5. 质量标准
- 至少引用两类以上来源，并注明出处与日期。
- 每条关键结论需说明验证方式（数据交叉、访谈、实验等）。
- 相关图表应说明生成脚本或 MCP 工具（如 `chart-server`）。
- Summary 中补充“引用更新”及“需要跟进的 TODO”。

## 6. 归档与传播
- 成品需同步到 `08_知识传播与品牌/`（若对外发布）并更新相关 README 索引。
- 在 `memory-bank/README.md` 或周报中记录新报告，以便 Codex/Claude 快速发现。
- 若报告更新，保留版本记录，旧稿可移至 `archive/`。
