# 01_Inbox · 原始资料收集指南

版本：2025-10-11 · 维护：Knowledge Lab

## 1. 定位
`01_Inbox` 是知识流水线的入口，承载外部报道、报告、访谈、抓取数据等“未经处理”的原始材料。所有内容需在 **24 小时内** 完成初步标注并迁移到下一阶段（`02_分析与洞察` 或淘汰）。

## 2. 目录结构
| 子目录 | 用途 |
| --- | --- |
| `markdown/` | 手工整理或 AI 转写的 Markdown 文件 |
| `snippets/` | 短篇摘要、亮点条目、关键信息片段 |
| `pdf_docs/` | PDF 等附件的转写正文或摘要 |
| `@概念标签数据汇总.md` | 与标签体系相关的临时记录 |
| `@工作清单_Input_to_Processed.md` | 待处理任务清单 |

> 附件或图片请存放在 `attachments/`（若需，可新建），并在 Markdown 中引用。

## 3. 文件要求
- **命名**：`YYYYMMDD-来源-主题.md`，如 `20251010-CBINsights-AI_Forecast.md`。
- **frontmatter**（最简模板）：
  ```yaml
  ---
  title: "20251010-CBINsights-AI_Forecast"
  owners: ["收集人"]
  status: parked
  source_link: "https://..."
  type: report | article | interview | dataset
  tags: ["AI", "Video", "Forecast"]
  ---
  ```
- **正文结构**：
  - 原文要点
  - 重要数据/引用（保留原文链接或页码）
  - 建议拆分或映射的条目（对应 `02_分析与洞察` 的分类）

## 4. 处理流程
1. **登记**：在 `@工作清单_Input_to_Processed.md` 列出新文件 + TODO
2. **提炼**：按照 `🟣 knowledge/CLAUDE.md` 的 5 通道要求标注关键信息
3. **迁移**：
   - 标签/映射 → `02_分析与洞察/00_数据库/`
   - 趋势片段 → `02_分析与洞察/02_综合洞察/a_趋势洞察/`
   - 档案/案例 → `02_分析与洞察/01_分析单元/`
4. **更新索引**：迁移完成后，在 Summary 或 README 中标注“已处理”
5. **清理**：如资料无价值，直接归档或删除，并更新工作清单

## 5. 与 AI 协作
- 采集中可指示 Claude:
  ```text
  请基于以下链接整理要点，按照 5 通道（核心主题/相关领域/最新动态/专家观点/趋势信号）记录，并列出推荐的标签/关系/趋势条目。
  ```
- 生成的 Markdown 需人工复核后放入对应目录。

## 6. 常见问题与解决
- **忘记迁移** → 使用 `@工作清单` 每日检查；Summary 标注未完成原因
- **来源缺失** → 必须补充链接或附件路径；无法确认时删除该记录
- **命名混乱** → 统一使用日期 + 来源 + 主题；必要时在命名后补短标签

保持此目录精简、时效，才能让 `02_分析与洞察` 高效运行。***
