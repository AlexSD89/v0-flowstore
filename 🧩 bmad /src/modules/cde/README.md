# CDE Module - Claude Development & Engineering

## 📋 模块概述

CDE (Claude Development & Engineering) 模块专注于工程技术领域的专业agents，提供从架构设计到代码实现的全方位技术支持。

## 🎯 专业领域

- **AI工程**: AI模型开发、算法优化、技术实现
- **后端架构**: 系统设计、技术架构、性能优化
- **前端开发**: 用户界面、交互体验、前端性能
- **移动开发**: iOS/Android应用开发、跨平台解决方案
- **语言专家**: Python、TypeScript等专业语言支持
- **数据工程**: 数据库优化、数据处理、性能调优
- **DevOps**: 自动化部署、基础设施、运维管理
- **安全审计**: 代码安全、系统安全、合规检查
- **API测试**: 接口测试、性能测试、集成测试
