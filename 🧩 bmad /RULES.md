# BMAD v5.3 - 系统规则与边界约束

> **最后更新**: 2025-10-14
> **适用对象**: Claude Code / AI Assistant
> **约束类型**: 系统边界、安全红线、合规要求

---

## 🚫 严禁操作 (系统红线)

### 1. 核心系统保护
- **❌ 禁止修改核心配置** - `bmad-core/config/` 下的系统配置文件
- **❌ 禁止绕过性能监控** - 必须使用 `synergy-monitor.js` 记录所有操作
- **❌ 禁止直接访问外部API** - 必须通过路由系统 `native-first-bmad-system.js`
- **❌ 禁止覆盖原始数据** - 所有数据操作必须先备份

### 2. Agent管理约束
- **❌ 禁止创建未授权Agent** - 只能使用已定义的10个原生Tasks
- **❌ 禁止绕过智能路由** - 不能手动选择Agent，必须使用自动路由
- **❌ 禁止修改Agent优先级** - 系统级Agent优先级不可调整
- **❌ 禁止并发超限** - 最大并发Agent数: 5个

### 3. 数据安全约束
- **❌ 禁止明文存储敏感信息** - API密钥、用户数据必须加密
- **❌ 禁止跨租户数据访问** - 严格的租户隔离机制
- **❌ 禁止未经验证的外部调用** - 所有外部调用必须验证白名单
- **❌ 禁止数据导出到未授权位置** - 数据导出需要审计记录

## 🔄 回滚策略

### 1. 自动回滚触发条件
- 性能指标下降超过20%
- 错误率超过5%
- 用户反馈异常超过3个
- 系统资源使用超过90%

### 2. 回滚执行步骤
```yaml
1. 立即停止所有新操作
2. 恢复最近的配置备份
3. 重启相关服务
4. 验证系统状态
5. 通知相关人员
```

### 3. 回滚后验证
- 检查系统功能完整性
- 验证性能指标恢复
- 确认用户功能正常
- 记录回滚原因和过程
