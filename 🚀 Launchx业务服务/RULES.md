# 业务服务域 RULES

## Claude增强业务规则

### 质量门槛要求
- **90%+数据驱动决策**：所有业务决策必须有充分的数据支撑，禁止经验判断
- **95%客户满意度**：客户沟通和服务必须达到95%+满意度标准
- **85%+方案复用率**：优先使用Claude智能匹配的方案模板，复用率<85%需说明原因
- **2-3周交付周期**：标准项目必须在2-3周内完成交付，复杂项目需明确延期理由

## 必做事项
- 所有客户互动需记录在案：时间、参与人、决策、后续行动。
- 对外输出必须标注数据来源、发布日期、适用范围，并与知识域核对事实。
- 方案发布前需完成：Claude智能需求分析 → 技术可行性确认 → 品牌视觉审校。
- 始终保持敏感信息访问控制，按客户级别管理权限。
- 草稿暂存仅限 `🤖 AI生成 auto-generated/日期`，24 小时内整理并归档至正式目录。
- **Claude能力集成检查**：确保90%+的Claude能力集成率和40%+的效率提升。

## 禁止事项
- 未经核实引用竞争对手或市场数据。
- 将客户隐私、报价、合同上传至公共目录；应存放于受控位置并注明访问规则。
- 代表公司做出未审批承诺或时间表。
- 绕过 `/spec → /plan → /do` 直接跳到执行阶段。
- **Claude能力缺失**：禁止不使用Claude专属能力的浅层业务分析。
- **经验主义决策**：禁止在没有数据支撑的情况下做出业务决策。

## 客户交付审批与风险管控

### 审批流程（Claude增强）
- **智能合规检查**：Claude自动检查输出内容的合规性和风险点
- **多级审批机制**：业务负责人→品牌负责人→法务负责人（如需）
- **审批记录数字化**：使用BMAD系统记录审批链条和决策依据
- **客户确认机制**：重要交付前必须获得客户书面或邮件确认

### 应急响应体系
- **风险预警触发**：客户满意度<80%、交付延期>7天、合规风险
- **自动应急启动**：Claude智能识别风险并自动触发应急预案
- **快速决策通道**：建立24小时响应的快速决策机制
- **回滚方案预置**：每个项目必须有完整的回滚计划和测试

### 客户关系管理
- **满意度实时监控**：Claude驱动的客户满意度跟踪系统
- **沟通记录标准化**：所有客户互动必须记录在统一的CRM系统
- **期望值管理**：明确项目范围、交付时间、质量标准
- **升级路径清晰**：客户投诉和问题的标准化升级流程

## 合规与安全
- 遵循 NDA / 合同条款，输出前确认共享范围。
- 会议录音、纪要需标注"内部/外部可见"，并按规定存档。
- 使用第三方工具（CRM、协作平台）需在 `memory-bank/support_modules/launchx/USEME.md` 登记使用说明与权限设置。
- 高频交付流程建议沉淀至 `🧩 bmad`，脚本更新时同步记录回滚方案。
