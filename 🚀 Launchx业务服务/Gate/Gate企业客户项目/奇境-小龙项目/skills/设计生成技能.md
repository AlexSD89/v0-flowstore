# 设计生成技能

## 🎯 技能概述
这是一个专门用于生成和优化H5页面、微报等设计内容的AI技能，基于客户需求和品牌标准自动创建高质量的设计方案。

## 📋 核心能力

### 1. 三段式设计迭代流程
- **初稿阶段**：风格探索与多版并行，生成v0初稿
- **修改阶段**：基于客户反馈进行精准修改，生成v1..vN修改版
- **终稿阶段**：法务/市场双把关确认，生成vF终稿

### 2. 渠道差异化设计
- **H5页面设计**：
  - 多屏滚动交互设计
  - 首屏抓取点优化
  - CTA按钮分布策略
  - 响应式适配方案
  - 顶部/底部安全区合规设计

- **微报设计**：
  - 浓缩表达和醒目披露
  - 风险限制性用语显著呈现
  - 防止字密度过高压缩失真
  - 确保平台压缩后可读性

### 3. 质量保障系统
- **设计审查**：层级/留白/对比度/排版一致性检查
- **品牌检查**：色板/字号/Logo规范自动验证
- **客户确认**：客户签名/法务确认流程集成

## 🚀 使用方法

### 输入要求
- 客户需求说明（文字或图片参考）
- 品牌VI规范和标准
- 渠道要求（H5/微报等）
- 合规要求和披露标准

### 输出结果
- **设计初稿**：2-3个不同风格的v0版本
- **修改版本**：基于反馈的精确修改版本
- **最终交付稿**：通过所有质量检查的终稿
- **质量报告**：详细的设计质量评分和改进建议

## 📊 质量标准
- **设计质量评分**：≥0.85（客户可调整阈值）
- **品牌一致性**：≥0.90（自动检查）
- **合规覆盖率**：100%（强制要求）
- **客户满意度预测**：≥0.90

## 🔧 可调参数
客户可以根据以下参数调整技能行为：
- **品牌一致性权重**：30%（已配置）
- **视觉吸引力权重**：25%（客户可调）
- **用户友好性权重**：20%（客户可调）
- **转化潜力权重**：15%（客户可调）
- **技术可行性权重**：10%（已配置）

## 📈 学习进化
该技能会基于每次使用的结果持续学习和优化：
- 学习客户的设计偏好和品牌要求
- 记录修改反馈模式和规律
- 优化设计生成算法和质量评分
- 积累行业特定的设计最佳实践

## 🔄 自动化工作流
1. **需求解析**：理解客户需求和渠道要求
2. **品牌匹配**：自动应用品牌VI标准
3. **多版生成**：并行生成多个设计方案
4. **质量检查**：自动执行多维度质量审查
5. **合规验证**：确保100%合规覆盖
6. **客户交付**：生成可直接使用的设计文件
