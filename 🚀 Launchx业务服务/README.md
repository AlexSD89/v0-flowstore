# 业务服务域总览

## 使命与范围
- 将知识、技术、设计资产转化为对外服务方案与交付成果。
- 管理客户沟通、项目推进、品牌传播，维护交付标准与满意度。
- 记录业务策略、案例沉淀、合作伙伴网络，为销售与运营提供支撑。

## 目录地图
| 目录 | 功能 |
| --- | --- |
| `Ⅰ_待处理信息` | 潜在线索、客户需求、初步调研记录 |
| `Ⅱ_对外业务` | 在执行项目、交付材料、客户回访 |
| `Ⅲ_公司运营` | 内部制度、运营指标、资源配置 |
| `Ⅳ_合作伙伴list` | 渠道、生态伙伴、供应商档案 |
| `a_企业AI转型服务策略与案例` | 行业方案、实施案例、SOP |
| `b_知识传播与品牌策略` | 公关计划、内容日历、品牌素材 |
| `公司介绍/` | 公司简介、Pitch Deck、FAQ |

## 交付工作流
0. **草稿缓冲**：将初版方案、会议速记暂存于 `🤖 AI生成 auto-generated/日期`，24 小时内整理并归档。
1. **线索入库**：在 `Ⅰ_待处理信息` 登记背景、痛点、优先级。
2. **方案共创**：与知识域、技术域联动，生成提案草稿、资源估算。
3. **执行交付**：在 `Ⅱ_对外业务` 记录里程碑、会议纪要、风险日志。
4. **复盘归档**：项目完成后回写案例至 `a_` 目录，更新伙伴、指标。

## 协同接口
- **知识域**：获取洞察、指标、行业研究，确认引用更新并保持方法论互链。
- **技术域**：评估可行性、估算工期，交付脚本或 Demo。
- **设计域**：输出视觉物料、品牌资产、一致的沟通模板。
- **自动化实验室**：对高频需求孵化自动化工具，缩短交付周期。

## 衡量指标
- 客户满意度、方案转化率、交付准时率。
- 内容触达/曝光数据（与品牌策略目录联动）。
- 项目复盘完成率（案例沉淀、回滚策略、经验教训）。
