# 质量保障技能

## 🎯 技能概述
这是一个专门用于确保AI输出质量的多维度评估技能，通过自动化质量检查确保所有输出都符合客户标准和合规要求。

## 📋 核心能力

### 1. 多维度质量评估
- **设计质量**：视觉设计、排版、色彩搭配等专业评估
- **品牌一致性**：品牌规范、VI标准、Logo使用等一致性检查
- **用户体验**：易用性、交互设计、信息架构等用户体验评估
- **技术可行性**：实现难度、技术风险、性能评估等可行性分析
- **合规性检查**：法务合规、披露要求、风险提示等合规性验证

### 2. 自动化质量门禁
- **实时质量监控**：每个输出都自动进行质量检查
- **阈值预警系统**：质量分数低于阈值自动预警
- **问题定位分析**：精确指出质量问题和改进建议
- **优化建议生成**：基于分析结果提供具体优化方案

### 3. 客户可配置标准
- **质量阈值调整**：客户可以个性化设置最低质量要求
- **权重配置**：各维度权重可以根据客户需求调整
- **行业特定标准**：支持不同行业的专门质量标准
- **品牌自定义规则**：支持客户特定的品牌质量要求

## 🚀 使用方法

### 输入要求
- 待评估的AI输出内容（设计稿、报告、代码等）
- 客户质量标准和品牌规范
- 行业合规要求和披露标准
- 可选的参考标准或对照样本

### 输出结果
- **质量评分报告**：各维度详细评分和总分
- **问题清单**：识别的质量问题和风险点
- **改进建议**：具体的优化方案和实施步骤
- **合规检查表**：法务合规要求的完整检查清单

## 📊 质量标准体系

### 默认权重配置
- **品牌一致性权重**：30%（确保品牌形象统一）
- **视觉吸引力权重**：25%（提升用户体验）
- **用户友好性权重**：20%（确保易用性）
- **转化潜力权重**：15%（支持业务目标）
- **技术可行性权重**：10%（确保可实施）

### 质量等级标准
- **优秀**：≥0.95（可直接交付）
- **良好**：0.85-0.94（小幅优化后交付）
- **合格**：0.70-0.84（需要优化后交付）
- **不合格**：<0.70（重新生成）

## 🔧 客户配置选项

### 质量阈值配置
- **最低通过分数**：默认0.85，客户可调整
- **优秀标准分数**：默认0.95，客户可设定
- **强制合规要求**：100%覆盖，不可调整
- **行业特定标准**：根据行业特点自动调整

### 评估重点配置
- **品牌导向**：强调品牌一致性，适用于品牌敏感项目
- **用户导向**：强调用户体验，适用于用户界面项目
- **合规导向**：强调合规性，适用于金融、法律项目
- **技术导向**：强调技术可行性，适用于技术复杂项目

## 📈 学习进化机制

### 客户偏好学习
- 记录客户的质量偏好和评判标准
- 学习行业特定的质量要求和最佳实践
- 建立客户个性化的质量画像模型
- 优化评分算法和权重配置

### 质量标准演进
- 基于历史数据优化质量评分模型
- 学习新的设计趋势和技术标准
- 持续更新行业合规要求和披露标准
- 积累跨项目的质量最佳实践

## 🔄 自动化工作流
1. **内容接收**：接收待评估的AI输出内容
2. **标准匹配**：自动匹配客户质量标准和行业要求
3. **多维度评估**：并行执行各维度质量检查
4. **综合评分**：计算质量总分和各维度分数
5. **问题诊断**：识别质量问题和风险点
6. **优化建议**：生成具体的改进方案
7. **结果输出**：生成完整的质量评估报告
