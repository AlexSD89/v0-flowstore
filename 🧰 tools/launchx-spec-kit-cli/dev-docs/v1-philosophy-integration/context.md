## 🎯 项目背景

### 核心问题
V4系统已完成V3成本优化哲学的融合(87.5%成本降低 + 95%哲学合规度)，现在需要融合V1的三种核心设计哲学：

1. **数据驱动的内容自动化** - 每日数据收集→智能分析→自动内容生产→精准投放
2. **多Agent协作论坛机制** - 论坛式协作+AI主持人引导的动态辩论评分
3. **动态规格迭代计划** - PRD→文案模板→自动执行→数据复盘的闭环迭代
