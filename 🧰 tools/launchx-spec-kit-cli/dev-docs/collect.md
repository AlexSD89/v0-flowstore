# Collect阶段 - 信息收集与需求分析

## 阶段目标

Collect阶段是LaunchX 5步认知法的起点，专注于全面收集信息、理解需求、明确约束条件和识别可用资源。

## 核心活动

### 1. 需求收集
- 用户需求分析
- 功能需求识别
- 非功能需求梳理
- 约束条件明确

### 2. 信息搜集
- 现有资产检索
- 最佳实践调研
- 技术方案探索
- 竞品分析

### 3. 资源评估
- 团队能力评估
- 时间资源分析
- 技术栈选择
- 风险识别

## 在Serena中的实现

### Memory集成
- 搜索相关的历史Memory
- 收集最佳实践模板
- 记录需求分析过程

### 智能增强
- AI驱动的需求分析
- 自动化资源推荐
- 智能风险评估

## 输出物

### context.md更新
- SESSION PROGRESS状态更新
- 需求背景和上下文
- 资源清单和约束条件
- 关键决策点和风险评估

### Memory记录
- 需求分析过程
- 信息收集结果
- 资源评估报告

## 质量标准

- 需求覆盖率 ≥ 95%
- 信息准确率 ≥ 90%
- 风险识别完整度 ≥ 80%

## 成功指标

- 需求理解准确性
- 信息收集完整度
- 资源评估合理性
- 后续阶段输入质量

---

*Collect阶段为整个项目奠定信息基础，确保后续阶段有充分的输入和明确的指导。*
