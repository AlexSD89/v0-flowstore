## 🔧 API直接调用示例

### 检查登录状态
```bash
curl -s http://localhost:18060/api/v1/login/status | jq .
```

### 获取登录二维码
```bash
curl -s http://localhost:18060/api/v1/login/qrcode | jq '.data.img' | head -c 100
```

### 发布内容（需要先登录）
```bash
curl -X POST http://localhost:18060/api/v1/publish \
  -H "Content-Type: application/json" \
  -d '{
    "title": "测试标题",
    "content": "测试内容",
    "images": ["/path/to/image.jpg"],
    "tags": ["测试"]
  }'
```

## ⚠️ 重要注意事项

### 登录限制
- 小红书可能有登录频率限制
- 同一账号不建议在多个网页端同时登录
- 可以使用移动App端查看账号状态

### 使用规范
- 标题不超过20个字
- 正文不超过1000个字
- 建议每天发帖量控制在50篇以内
- 推荐使用本地图片路径而非HTTP链接

### 故障排除
```bash
# 检查服务状态
curl http://localhost:18060/health

# 检查端口占用
lsof -i :18060

# 查看MCP日志
tail -f nohup.out  # 或查看MCP服务器输出
```
