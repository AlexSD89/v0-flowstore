# 小红书 MCP - 本地使用说明

> 基于 [官方 xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp) 项目的本地部署版本

## 🚀 快速开始

### 1. 检查二进制文件
```bash
# 确认二进制文件存在
ls -la xiaohongshu-*-darwin-arm64

# 设置执行权限
chmod +x xiaohongshu-*-darwin-arm64
```

### 2. 登录小红书
```bash
# 启动登录工具
./xiaohongshu-login-darwin-arm64

# 或者指定Chrome路径
./xiaohongshu-login-darwin-arm64 -bin "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

### 3. 启动MCP服务器
```bash
# 启动MCP服务器
./xiaohongshu-mcp-darwin-arm64

# 服务器将在 http://localhost:8080 启动
```

## 🔧 Claude Code CLI 集成

### MCP配置
在Claude Code的MCP配置中添加：

```json
{
  "mcpServers": {
    "xiaohongshu": {
      "command": "/path/to/xiaohongshu-mcp-darwin-arm64",
      "args": []
    }
  }
}
```

### 使用示例
```bash
# 通过Claude Code调用
codex "检查小红书登录状态"
codex "发布一条关于AI的内容到小红书"
```

## 📋 可用功能

### HTTP API端点
- `GET /health` - 健康检查
- `GET /api/v1/login/status` - 检查登录状态
- `GET /api/v1/login/qrcode` - 获取登录二维码
- `POST /api/v1/publish` - 发布图文内容
- `POST /api/v1/publish_video` - 发布视频内容
- `GET /api/v1/feeds/list` - 获取Feeds列表
- `POST /api/v1/feeds/detail` - 获取Feed详情

### 示例API调用
```bash
# 检查登录状态
curl http://localhost:8080/api/v1/login/status

# 发布内容
curl -X POST http://localhost:8080/api/v1/publish \
  -H "Content-Type: application/json" \
  -d '{
    "title": "测试标题",
    "content": "测试内容",
    "tags": ["测试", "API"],
    "images": []
  }'
```

## 🐛 故障排除

### 常见问题
1. **Chrome启动失败**: 检查Chrome安装路径
2. **登录状态丢失**: 重新运行登录工具
3. **API调用失败**: 确认MCP服务器正在运行
4. **权限问题**: 确保二进制文件有执行权限

### 调试方法
```bash
# 查看MCP服务器日志
./xiaohongshu-mcp-darwin-arm64

# 检查端口占用
lsof -i :8080

# 测试API连接
curl http://localhost:8080/health
```
