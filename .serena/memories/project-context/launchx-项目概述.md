## 内容

LaunchX是一个混合协作AI系统，集成了5步认知法、Dev Docs系统、Skills生态和Hooks质量保障。

核心组件：
- 5步认知法：Collect → Model → Compare → Align → Deliver → Archive
- Dev Docs系统：plan.md + context.md + tasks.md
- Skills生态：专业能力工具包
- Hooks系统：自动化质量保障

项目结构采用模块化设计，支持多种AI客户端和开发工具的集成。
