# Memory-Bank 自动化内容管理系统使用指南

> **核心目标**：建立每周自动化的内容管理流程，确保Memory-Bank系统的高效运行和内容质量。

## 🎯 系统概述

Memory-Bank自动化内容管理系统是一个完整的解决方案，用于自动化处理内容的整个生命周期，从创建到归档。

### 🔄 管理周期
- **频率**：每周自动运行（建议：周日02:00）
- **模式**：自动化检查 + 手动确认
- **目标**：保持内容质量和系统效率

### 📊 管理范围
- **文件数量**：当前15个Markdown文件
- **存储大小**：约500KB
- **质量标准**：frontmatter合规、内容完整性
- **重复率控制**：识别并处理重复内容

## 🛠️ 核心工具集

### 1. 内容生命周期管理器
**文件**：`scripts/content-lifecycle-manager.sh`

**功能**：
- 访问频率分析
- 重复内容检测
- 内容质量评估
- 自动归档处理

**使用方法**：
```bash
# 仅生成报告（推荐）
bash scripts/content-lifecycle-manager.sh

# 自动处理模式（谨慎使用）
bash scripts/content-lifecycle-manager.sh --auto-process
```

**输出**：
- 处理报告：`logs/lifecycle/lifecycle_report_YYYY-MM-DD.md`
- 详细日志：`logs/lifecycle/lifecycle_YYYY-MM-DD.log`

### 2. 访问频率分析器
**文件**：`scripts/access-frequency-analyzer.py`

**功能**：
- 文件访问时间分析
- Git历史记录追踪
- 内容价值评估
- 访问频率分类

**使用方法**：
```bash
# 完整分析
python3 scripts/access-frequency-analyzer.py --memory-bank "../" --summary

# 自定义输出
python3 scripts/access-frequency-analyzer.py --memory-bank "../" --output custom_analysis.json
```

**输出**：
- 分析报告：`access_analysis_YYYYMMDD_HHMMSS.json`
- 控制台摘要

### 3. 重复内容检测器
**文件**：`scripts/duplicate-detector.sh`

**功能**：
- 文件名相似性检测
- 重复组识别
- 自动归档建议

**使用方法**：
```bash
# 标准检测
bash scripts/duplicate-detector.sh --target "../"

# 自定义阈值
bash scripts/duplicate-detector.sh --target "../" --threshold 0.7
```

**输出**：
- 检测报告：`logs/duplicate_report_YYYYMMDD_HHMMSS.md`

### 4. 每周自动化管理器
**文件**：`scripts/weekly-content-automation.sh`

**功能**：
- 六阶段自动化流程
- 通知系统
- 周报生成
- 日志清理

**使用方法**：
```bash
# 完整自动化
bash scripts/weekly-content-automation.sh

# 预览模式
bash scripts/weekly-content-automation.sh --dry-run

# 强制执行
bash scripts/weekly-content-automation.sh --force
```

**输出**：
- 周报：`logs/weekly/weekly_report_YYYY-MM-DD.md`
- 综合日志：`logs/weekly/weekly_automation_YYYY-MM-DD.log`

## 📅 每周自动化流程

### 执行时机
- **推荐时间**：每周日02:00
- **Cron配置**：
```bash
# 每周日凌晨2点自动执行
0 2 * * 0 /path/to/memory-bank/scripts/weekly-content-automation.sh
```

### 执行阶段

#### 阶段1：路径对齐检查
- 验证所有路径引用一致性
- 检查@AT引用有效性
- 确保文档结构完整性

#### 阶段2：访问频率分析
- 分析文件访问模式
- 识别低频访问内容
- 生成优化建议

#### 阶段3：重复内容检测
- 检测文件名相似性
- 识别重复内容组
- 提供合并建议

#### 阶段4：内容生命周期管理
- 评估内容质量
- 检查frontmatter合规性
- 生成处理建议
- **智能任务分解**：基于ZAI能力进行自动任务分析和分解
- **预测性风险评估**：提前识别和处理潜在风险

#### 阶段5：周报生成
- 统计管理结果
- 生成处理建议
- 规划下次管理

#### 阶段6：日志清理
- 清理30天前的日志
- 优化存储空间
- 保持系统整洁

## 📊 质量控制

### 质量指标
- **frontmatter合规率**：≥90%
- **重复内容率**：≤20%
- **低频访问比例**：≤30%
- **内容完整性**：≥85%

- [ ] 所有文档都有标准frontmatter
- [ ] 无明显重复内容
- [ ] 长期未访问内容已归档
- [ ] 内容质量评分达标

### 处理策略
#### 高优先级问题
- frontmatter缺失
- 路径引用错误
- 大量重复内容

#### 中优先级问题
- 内容价值偏低
- 访问频率过低
- 存储空间过大

#### 低优先级问题
- 文件命名不规范
- 目录结构优化
- 文档格式更新
